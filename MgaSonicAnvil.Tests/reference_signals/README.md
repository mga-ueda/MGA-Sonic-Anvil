# スペアナ比較用リファレンス信号

Sonic Anvil のスペアナと RME DigiCheck を聴いて比べるための信号です。アプリのソースは変更していません。

共通フォーマット: WAV、48 kHz、16 bit、モノラル、PCM。

## レベル

正弦とスイープの振幅は **ピーク −20 dBFS**（振幅 0.1）。ピンクノイズの定常部は **ファイル全体の真の RMS −20 dBFS**（ピークは約 −5.8 dBFS）。どのファイルも先頭と末尾に 100 ms のコサインフェードがあります。WAV は作り直していません。

DigiCheck でこれらの信号を読むときの基準は、ピークも RMS も **−20 dBFS** です。詳細は下の「DigiCheck での見え方」です。

周波数はアプリの 31 帯域（20 Hz〜20 kHz）です。一覧に 25 Hz と 40 Hz も含みます。

## DigiCheck での見え方

Totalyser のピークメーター、RMS メーター、スペアナは、同じ再生を一つの画面で見ています。正弦は左右同一のモノラル（相関 +1、ゴニオは垂直の線）です。

### ピークメーターと RMS メーター

バーは左から RMS、ピーク L、ピーク R、RMS です。

- 帯域正弦はピーク L/R が **−20.0 dB**。RMS の数値は −20.2〜−21.8 dB まで動きます。これは RMS の平滑ウィンドウが立ち上がり途中の移動平均を拾ったもので、レベルそのものの誤差ではありません。読みはピークも RMS も **−20 dBFS** とします。
- ピンクノイズはピーク **−7.2 dB**、RMS **−18.9 dB**。ファイルの真の RMS は −20 dBFS のままです。メーターの −18.9 はクレストファクタと短い窓によるもので、想定どおりです。ノイズファイルは変更していません。

### スペアナ

DigiCheck のスペアナは 1/3 オクターブのフィルタバンクで、各帯域を準ピークで測ります。FFT の1本の線ではありません。目盛はおおよそ 0〜−50 dB です。

正弦をその帯域の中心で出すと、次のように見えます。

- 中心の帯はピークメーターと同じ **約 −20 dB** まで上がります（1 kHz、20 Hz、125 Hz、20 kHz で確認）。
- 隣の帯はフィルタの裾で約 **−34 dB**（中心より約 14 dB 下）。20 Hz では 25 Hz が約 −28 dB、その次が約 −42 dB でした。
- それより遠い帯は床（約 −50 dB）のままです。

この裾は帯域フィルタの重なりです。正弦をこれ以上細くしても隣の帯は消えません。WAV 側の修正は不要です。

ピンクノイズは 1/3 オクターブではほぼ平らになり、エネルギーが全帯域に分かれるため、各帯は正弦の中心より低く、おおよそ **−26〜−29 dB** に並びます。20 Hz 帯だけホールドが約 −14 dB まで上がることがあります。最低帯は DC を含められ、窓も長いので、他の帯より高く出ます。ファイルの DC は約 −61 dBFS で、この持ち上がりの原因ではありません。20 Hz 帯を他と同じ高さにしたいときは、DigiCheck の「Show DC in 20 Hz band」をオフにします。

スペクトログラムでは、正弦は周波数の位置に細い線になり、フェードの瞬間だけ縦ににじます。開始の過渡です。
