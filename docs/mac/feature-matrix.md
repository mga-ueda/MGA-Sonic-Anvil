## マイルストーン（Mac）

1. **M0** — 空ウィンドウが開く  
2. **M1** — ファイルを開いて波形が見える  
3. **M2** — 再生できる  
4. **M3 以降** — 編集・Wwise など。Windows 追従は共有できた層だけ
