MGA Sonic Anvil Manual

Hear, cut, and tidy audio, add markers and loops, then send a Wave file to Wwise.

1. What this app does

Edit waveforms and send them to Wwise in one window.

Fade, match loudness, delete unused parts, copy / paste, markers, regions, loops, and a spectrogram. Listen, decide, and apply.

Wwise gets a single Wave file. The original wave is written to Originals and imported as Interactive Music. Markers ending in -A / -L / -E and the sample loop are used (not Custom Cues). See WAAPI EXPORT.

You can save an open file as Wave or MP3. Right-click a tab to write the current edits to another file.

New file: Ctrl+N. After opening, record with Ctrl+R. Before recording, you are always asked whether to use Silent Skip (skip silence). Recording uses the current file format and overwrites from the playhead (Undo restores it). It does not start if no file is open.

Recording stays as raw audio. MP3 is only when you save or export. Unsaved work in tabs that were still open comes back on the next launch. A closed tab can be reopened with Ctrl+Shift+T until you quit the app.

Speaker layouts (mono through Atmos) and which channels play are switched in Settings and the SPEAKER menu at the bottom of the window.

2. Quick start

  1. Drop a Wave / AIFF / MP3, or press Ctrl+O. M4A is player-only. In the player, PDF / MOV / MP4 / AVI / MKV / WebM / MPG are listed too when that setting is on (PDF on by default; video types off by default; AVI / MKV / WebM / MPG only when ffmpeg is available; they cannot be opened in the editor). Several files open as tabs. Dropping a folder adds every supported file inside it (unsupported types are skipped). The status bar shows progress. Esc stops a multi-file load and keeps files already opened. The Open dialog remembers its last folder, separate from save / export. Ctrl+N opens an empty tab. Choose the format each time; the last choice is remembered. Channels are the speakers you enabled, plus Mono.
  2. Listen, cut, fade, and place markers or a loop on the waveform. For files with many channels, enable layouts on Settings → Shown first, then pick one with SPEAKER at the bottom. Record with Ctrl+R (a prompt asks whether to use Silent Skip).
  3. Save with Ctrl+S as Wave or MP3 (you cannot write AIFF). With several tabs selected, Save and Save As (Ctrl+Shift+S) act on every selected file. Save overwrites files that already have a location; unsaved or AIFF files ask for a folder and write Wave. Save As asks for a folder, writes each file as Wave, and the tabs then point at those files (unlike Export, the tab follows the new file). Ctrl+Shift+M is MP3-only: it writes a file and keeps the current tab (the written MP3 is not opened). MP3 is rebuilt from 16-bit audio. Three or more channels, or a remapped speaker, write the same stereo mix you hear now (see MP3 downmix; no prompt). A valid LAME location in Settings is used; empty or invalid uses Windows (default 192 kbps). Markers are not written to MP3.
  4. To send it to Wwise, turn on WAAPI above the level meter, pick a destination, and press EXPORT.

Settings and open tabs are stored in this PC’s user folder (%LocalAppData%\MGA\MGA Sonic Anvil\). Nothing is written next to the app. Quitting while still in player mode does not remember the playlist. Reopen Closed Tab (Ctrl+Shift+T) is only for tabs closed before you quit.

Audio

  • Default Wave format — 48 kHz / 24-bit / Stereo by default. Used for new files. Channels are enabled speakers plus Mono, which is always available.
  • Auto speaker selection — off by default. See details.
  • Speaker layout — mono through Atmos, including game-oriented variants such as Quad, LCRS, 2.1, and 5.1 Side. You do not add your own. The file itself stays numbered. Each speaker is assigned a file channel (Ch), and only those lanes show L / C / LFE and so on. The default is 1, 2, 3…. Switching layouts without OK asks whether to save the current one.
  • API and device — WaveOut / WASAPI / ASIO, and the audio device.
  • Record / playback ports and Ch — speaker names come from the layout, port names from the device. Ch is shared by record and playback. Off leaves the speaker unused. Record has level meters.
  • Test tone — per-playback-port Sine -20 dB (1 kHz, or 80 Hz on LFE) plus an English spoken channel-name Voice (not on LFE).
  • Stereo playback with no ports chosen still mixes the speakers to left and right.

Playback

  • Entering selects and plays the first track (the same when you start the app with files).

  • Space or transport Play plays that track only and stops when it ends.

    • Starts from the seek bar / playhead, or the same video’s dim preview position.
    • While playing, returns to the start. During real video playback, seeks to the start and stops without showing the playlist (does not resume).
    • Enter pauses in place (chrome stays hidden). While stopped, video / PDF match Space (real playback / bright view).
    • Escape / Q return to background playback (same to leave bright PDF view).
    • Whether playback advances at the end is controlled by Auto next (Alt+N; off by default). Double-click starts playback and advances only when Auto next is on.
  • While stopped, selecting a track shows its waveform without playing. Selecting PDF / video also shows a dim back-stage preview (video: dim + mesh + silent 1/3-speed loop; PDF: dim only, no mesh and no frosted glass). Adding tracks fades them in over 1 second; when they start moving with the audio they appear immediately. Clearing the list fades them out over 1 second.
  • Alt+R toggles shuffle (playlist Random). No repeats until the playlist has played once. Works on an empty list. Off by default. Leaving player turns it off. Not saved. R restarts the current track from the beginning.

Folder-name jump (incremental search)

This is the “type to find” pattern used in Explorer and similar trees. Unlike Ctrl+F, it only moves the tree selection — it does not add anything to the playlist.

  1. Focus the folder tree (F1, etc.).

  2. Type letter keys to jump to a folder whose display name contains what you typed (prefix or mid-name; case and fullwidth/halfwidth are ignored).

    • Example: N reaches namco or NINTENDO; MAY reaches a folder with May in the middle of the name.
    • Keep typing to accumulate characters and narrow the match (repeating D builds dddd).
    • A toast in the center of the tree shows what you typed. About 1 s after you stop typing, the toast disappears and the typed buffer is forgotten.
    • Matching characters get a yellow highlight. After the toast goes away, the highlight stays so you can walk hits with ↑ / ↓.

  3. Esc, and also Space / ← / →, clear the typed buffer and yellow highlight (Space / arrows then perform their tree actions). Adding to the playlist / starting playback, or moving focus out of the tree, also ends it.

While the tree has focus, N / P / R / J / K / M / I / O feed folder-name jump (not previous/next track, transport letters, or temp markers / A-B; the numpad still controls playback). Shuffle is Alt+R; auto next is Alt+N; Auto Play is Alt+P.

Bounce

With two or more tabs selected, “Bounce Selected Files (J)” mixes their waveforms together into a new Wave and opens it in the tab to the right of the selection. Ctrl+Shift+B does the same.

  • The length is the longest tab. Bounce runs only when every file matches the leftmost selected tab’s sample rate, channel count, and bit depth. A different file cancels the bounce with no conversion, and the dialog names the files that do not match.
  • Markers and regions are carried over in place. A marker at the same position with the same comment is kept only once.
  • It asks where to save first. Default name Bounce.wav. The dialog starts in the last bounce folder. If there is none yet, it uses the folder of the first selected tab that has a file, else the last export folder. The chosen location is kept for the next bounce.

16-bit bounce is not recommended. Use 24-bit or higher. 16-bit bounce is still allowed.

The bounce path does not dither. At 16-bit, fades and reverb tails are plain rounding.

Before the bounce is written, the summed float32 samples are scanned for values beyond ±1. If any exceed full scale, a warning states how far over they are (for example, 1 dB over). There are two choices: cancel the bounce, or lower the entire mix by the detected overage and then bounce.

Silent Skip

Status bar, left of SPEAKER. Alt+S. Off by default.

  • Skips silent stretches during playback, and while recording writes only audio above the threshold.
  • Each recorded burst gets a short fade from the Editing tab in Settings (default 20 ms) at both ends so it does not click.
  • Hold ← / → during playback to shuttle without skipping.
  • When the level falls, silence is written immediately and stops at the silence insert duration on skip (default 500 ms; unused on playback). It is not dumped when sound returns.
  • Starting a recording always asks whether to turn Silent Skip on. The checkbox starts from the status-bar switch. OK updates the status bar, Cancel leaves it. The prompt shows the current threshold and silence insert duration (changeable in Settings).
  • The region checkbox is enabled only when Silent Skip is on. Checking that adds a region to each recorded stretch separated by a pad. Silence does not get a region. Brief dips in the waveform are not split. A continued take gets regions for the new audio only. Off by default. Remembered. Adding regions is chosen when you start recording.
  • The threshold and silence insert duration are on the Editing tab in Settings (threshold default −60 dB). Not shared with Silence & Hit Detection (waveform right-click → Edit → Silence & Hit Detection / Ctrl+D), including its cut fades.

Gapless playback

Settings → Player, first item. On by default.

Use this when tracks should play as one continuous piece. Splitting a live set or classical album into one MP3 or M4A per track can add a tiny silence at the start and end of each file. When on, that silence is skipped so the next track joins smoothly. It does not skip every quiet stretch (that is Silent Skip).

  • Files with no length information (older files, Windows MP3) play as they are.
  • If the information is wrong, a few tens of milliseconds can be missing at the start or end. If the silence is already gone, it is not cut again.
  • Long gaps that were written into the file (for example two seconds between tracks) are not removed.
  • Even when on, a slight gap can remain. It may not match a CD exactly.
  • When off, the extra silence is included. The waveform length on screen does not change either way.

4. Playback

  • Space — play / stop. Stop returns to the start position. During real video playback it seeks to the start and stops (does not resume) without showing the playlist (Escape / Q returns to the 1/3-speed background; in the F8 / argument-launch mini, Escape / Q quits the app; resuming from that preview continues from the current position). During bright PDF view, Escape / Q returns to the dim preview (Space / Enter do not leave). Transport Play is the same.
  • Enter — pause in place. While stopped, video / PDF match Space (real playback / bright view). During real video playback it pauses in place without showing the playlist.
  • ← / → — while stopped, seek (about 1 px of the view; 1 sample when dots are shown). Hold during playback for 3× shuttle at the original pitch (−4 dB while held). Release restores speed and volume. Silent Skip does not run while you hold. Player mode does not shuttle with the arrows (, / .). During real video playback or frame pause, ← / → pause and step one frame (hold repeats after an initial wait).
  • Ctrl+Space — from 3 seconds earlier.
  • Alt+Enter — restart from the playback start (while the tile search box has focus, closes tiles that did not match instead).
  • Alt+S — Silent Skip. Skip silent stretches during playback, and while recording write only audio above the threshold (off by default; threshold is in Settings, default −60 dB). Hold ← / → during playback to shuttle without skipping. Recording always asks whether to turn Silent Skip on (the checkbox starts from the status-bar switch; OK updates it). The prompt shows the current threshold and silence insert duration (changeable in Settings). The region checkbox is enabled only when Silent Skip is on (off by default; remembered).
  • With Auto next on, player continuous playback prepares the next track. Tiny silences at the start and end of MP3 / M4A are reduced by gapless playback (Player tab in Settings; on by default). A slight gap can still remain when it is on.
  • Ctrl+drag — scrub. Every channel is mixed to left and right (the level meter moves on L/R only).
  • G — type NOW POS in the status bar. Enter jumps. Copy / paste allowed. Right-click switches time / samples.
  • J — skip 5 s back, K — skip 5 s forward (0.75 s crossfade; hold repeats after a short wait)
  • , — rewind, . — fast-forward (±3× at original pitch; −4 dB while held; works while stopped and leaves you stopped at the new position)
  • Z or numpad . — center. Toggles center-lock while playing; clears it when stopped (the . key is fast-forward).
  • L — loop from 3 seconds before the end of the selection (or the sample loop / -L).
  • Q — in the editor, range metronome. Metronome clicks at equal-divide markers/regions. Toggle with the button or Q (off by default; never auto-on). Also available from waveform right-click → Playback. In the player during real video playback / frame pause / bright PDF view, same as Escape — returns to the dim preview (in the F8 / argument-launch mini, Escape / Q quits the app; range metronome does not run in the player).
  • Tab — solo a channel. Other lanes go gray and stay muted. Again moves to the next channel; Shift+Tab goes backward. Past the last clears solo. Click a channel name on the left to solo (click the same name again to clear; Ctrl+click adds; Shift+click mutes / unmutes). The time selection does not change. Waveform edits apply only to that channel. Works while playing or stopped.
  • Ctrl+N — new file. Opens an empty tab. Choose the format each time (the last choice is remembered). Channels are the speakers enabled on Shown, plus Mono (always available).
  • Ctrl+R — record. A prompt appears every time asking whether to turn Silent Skip on (the checkbox starts from the status-bar switch; OK updates it; the prompt shows the current threshold and silence insert duration, changeable in Settings; the region checkbox is enabled only when Silent Skip is on; off by default; remembered). Records in the current file format from the seek bar. Audio after that point is overwritten (Undo restores it; audio past the take stays; a longer take extends the file). It does not start if no file is open (create one with Ctrl+N or open a file first). Recording stays as raw audio; MP3 is only on save / export. An unsaved take left open is kept as a working copy and comes back on the next launch. A closed tab can be reopened with Ctrl+Shift+T in this launch only. Press again, or Space / Enter / Esc, to stop. While recording, the waveform background turns reddish. New audio appears immediately as a rough waveform, then settles into the usual drawing. With Silent Skip on, only audio above the threshold is written. Each recorded burst gets a short fade from the Editing tab in Settings (default 20 ms) at both ends. Silence is inserted when the level falls and stops at the record max (default 500 ms). Checking the region box adds one for each recorded stretch and each silent pad when you stop. Record ports, playback ports, and Ch are assigned inside that layout (Ch is shared by record and playback; Off leaves the speaker unused).

5. Selection and editing

Drag to select. Double-click selects a span (between markers). Triple-click always selects all. Esc or a move without Shift clears it. Fade / volume / pitch / normalize / reverse / time stretch with nothing selected uses the whole file in time. While a channel is soloed, those edits apply only to the audible lanes. You can also type the selection start / length / end in the status bar. After a selection edit (fade, normalize, delete, and so on), the playhead returns to the start of the selection.

  • FADE IN I / FADE OUT O — pick a curve, Space to preview, Enter to apply. 1–9 select a curve.
  • X — fade around seek bar: from the playhead, fade out only the visible part before / fade in only the visible part after (linear).
  • V — on a single tab, shows the loudness curve and opens volume. Type a dB value, or use ↑↓ / wheel by 0.1 dB (Shift 1 / Ctrl 3 / Ctrl+Shift 6). Space previews, Enter applies. The menu shows how whole-file Integrated LKFS / RMS / Peak will change. The Short Term curve and the stopped meter follow the same dB. Closing the volume popup leaves the curve. Shift+V closes the curve.
  • E — while the loudness curve is up, switch to the pen (again to leave it). The button at the top right of the curve and a right-click on the curve do the same. Dragging does not change the time selection, and the original curve stays visible. Releasing the mouse sets the volume to the drawn height. Moving back in time erases the later part of the stroke, so each time has one level. A short fade joins both ends. Ctrl+Z undoes that stroke. Esc clears the pen before leaving the curve.
  • Match Loudness (player context menu, or V with multiple editor tabs) — simple whole-file gain to a target LKFS (defaults to Settings). Not the curve-based volume picker used for a single editor file. In the player, files are saved in place afterward and cannot be undone. Non–Wave/AIFF files are skipped; if none qualify, a notice is shown.
  • P — pitch. ↑↓ / wheel by a semitone (Shift or Ctrl for an octave). Space previews, Enter applies. Range is ±2 octaves. Keep length is on by default (Tab moves to the checkbox). Off also changes length, like playback speed. A dim overlay shows progress while it runs.
  • T — time stretch (pitch stays). Uses the selection, or the whole file. Destination time and ratio (%) stay linked. ↑↓ / wheel (time: 1 s / Shift 10 s / Ctrl 1 min / Ctrl+Shift 10 min; ratio: 0.1 / Shift 1 / Ctrl 10 / Ctrl+Shift 25%). Tab switches fields. Space previews, Enter applies. Range is 10–1000%. A dim overlay shows progress while it runs.
  • NORMALIZE N — fit the peak to -0.1 dB.
  • R — reverse. Uses the selection, or the whole file. Audio only; markers / regions / loops stay put.
  • Waveform right-click → Audio → Normalize Waveform per Region — fit each region's peak to −0.1 dB. A short fade from the Editing tab in Settings (default 20 ms, to zero) is applied at each region's start and end to avoid a click.
  • DELETE — delete the selection and close the gap. Selected markers / regions go with it.
  • Shift+Delete — replace the selection with silence. Length stays the same, and markers / regions / loops do not move. The dialog matches Insert Silence: it shows the selection length in seconds and asks whether to apply the default fade on both sides (on by default; the click-prevention fade from Settings). The audio just before the selection fades to zero, and the audio just after fades up from zero. Enter applies, Esc cancels. Also on right-click → Edit → Mute Selection. With no selection, a notice appears. Already-silent audio is left as is. While a channel is soloed, only the audible lanes are silenced.
  • Waveform right-click → Edit → Insert Silence (Ctrl+Ins) — inserts the given number of seconds at the click, or at the playhead when opened from the key, pushing later audio, markers, regions, and loops back. Type the seconds, or use ↑↓ / wheel (0.1 s, Shift 1 s, Ctrl 10 s, Ctrl+Shift 60 s). Enter inserts. Range is 0.001–600 s. “Default fade on both sides” is on by default and applies the Settings click-prevention fade (default 20 ms): out to zero just before the insert, in from zero just after. With several tabs selected, the clicked file uses that position (the playhead for the key) and the other selected files use each playhead, for the same duration.
  • Waveform right-click → Edit → Silence & Hit Detection (Ctrl+D) — uses the selection if any, otherwise the whole file. The dialog sets open / close thresholds (linkable; default −5 dB, then remembers your last values; independent of Silent Skip), minimum time to next gate, minimum time to close, pre / post-roll, and cut fade in / out. Actions: delete silence, add regions to audio, add markers to audio, or mark hit points. Link is Alt+L, actions are Alt+D / R / M / H, scope is Alt+S / A. The apply button is OK. “Add regions / markers to audio” places cues on gated audible spans. “Mark hit points” places a marker on each rise that clears the threshold and comes up from the dip before it (a flat sustain gets none). Only the hit threshold and the minimum time between hits apply in that mode (spacing never goes below 10 ms; existing markers inside the analyzed range are replaced). Scope: start & end only, or entire (scope is disabled for hit points). Drag the red ±threshold lines on the waveform, or use the mouse wheel on the waveform / number fields (0.1 dB, Shift for 1 dB; ↑↓ same). Cut fades apply only when deleting silence (independent of the click-prevention fade in Settings; default 20 ms). Fades are disabled for regions / markers / hit points. Minimum time to next gate is disabled for start & end only (for hit points that field is the spacing and stays enabled). With several tabs selected, skips the settings UI and only asks whether to apply the current settings to every selected file (whole file each). Does not empty a file that is entirely silence. Region add is unavailable on formats that do not allow regions (e.g. MP3).
  • Ctrl+X / C / V — cut / copy / paste (markers in range included; a matching region is included too).
  • U — edit history. ↑↓ move, Enter apply, Esc cancel. Uses the same fill as the sample-rate convert picker list. Clicking the list left of loudness also opens it.
  • History copy & paste — inside the history, Ctrl+click to select steps (Shift+click or Shift+↑↓ for a range, Ctrl+A for all), then Ctrl+C. Press Ctrl+V in another file to apply the same edits (its history window does not need to be open). The copy stays until you copy something else, so you can switch tabs and press Ctrl+V on each file. Pasting onto several selected tabs, or a slow step such as pitch, shows a dim overlay with progress. Ctrl+C with no selection copies every step up to the current position. Ranges line up by playback time, and matching loudness is done again on the target. The only step you cannot copy is Original (it is not an edit; Ctrl+A leaves it uncolored).
  • History paste skips or surprises — each step is tried on the target; ones that do not fit are skipped (“Applied 3 of 5”). Examples that skip: adding a marker at a time that already has one, a delete / fade whose range falls off a shorter file, Delete Silence when the target has no silence, converting to the rate / bit depth / channel count the target already has, a marker comment where that marker is missing, and regions / loops onto an MP3. Dragging or nudging markers / regions / loops, and hold-to-subdivide, copy the layout at that moment. Pasting only the move onto another take replaces that take’s markers (include the adds through the moves if you want the same sequence). Times clamp to the end of a shorter file. An edit made with a channel soloed applies to the same channel index. Record / waveform-paste history carries the audio that was inserted. After Ctrl+C on the waveform, Ctrl+V pastes audio, not history.
  • Applying to the selected files — with two or more tabs selected (Ctrl+click / Shift+click / Ctrl+Shift+A), fade in / fade out, normalize, normalize per region, volume (curve picker for one file; Match Loudness simple adjust when several tabs are selected), pitch, time stretch, reverse, insert silence, Silence & Hit Detection, sample-rate / bit-depth / channel conversion, Save (Ctrl+S), and Save As (Ctrl+Shift+S) run on every selected file (each whole file, using that file’s own solo). 6. Markers / regions / loops

  • M / Ins — marker at the playhead when there is no selection. The same frame cannot take another. With a selection, the first press places start and end (or the midpoint if both ends already have markers); further presses replace them with thirds, then fourths, and so on (hold uses the same repeat timing as marker nudge; one history entry until you release).
  • Shift+L — set the selection as the sample loop (same range again clears it).
  • Shift+R — set the selection as a region. If both ends already have a region, the first press divides it in two; the same range again divides it in three, and so on (clear with right-click / Delete; hold uses the same repeat timing, one history entry until you release).
  • Ctrl+top-row digits, or Ctrl+numpad digits — jump to the start of that region number (regions count from 1, separate from marker numbers; two digits OK; the player does the same when the file has regions. Unmodified numpad stays transport).
  • Click a flag to select an edge. Shift+click for a range, Ctrl+click to add. Drag or ←/→ to move (Shift ×3).
  • Double-click a comment / region name. -A lime, -L blue, -E red (only when you write it; the span after a loop or sample loop is not painted red automatically). -R is gray. See 9-3 for what EXPORT does with them.
  • Ctrl+Shift+R — rename.
  • Right-click, or Ctrl+Del, deletes markers. Delete all markers and delete all regions are on Timeline.

Markers, regions, and loops are stored in the Wave file when you save. MP3 cannot take regions or a loop. Markers are allowed, but they are not written when you save as MP3.

7. Spectrogram / loudness analysis

A cycles spectrogram / overlay. V shows the loudness curve and opens volume. Closing that volume popup leaves the curve up. Esc, Shift+A, or Shift+V returns to the waveform. Esc clears the pen cursor, open prompts, and the selection first. The VIEW loudness button toggles the view only. L loops from 3 seconds before the end of the selection (or the sample loop / -L).

The loudness view draws how loud the sound is over time (Short Term). A faint band sits ±1 LU around the curve. Peak level is drawn on the same height so you can compare. Background colors match the meter: blue through the target, orange for the next 3 LU, red above that. The left numbers are loudness (LKFS); the white line is the target in Settings. The pen button at the top right of the curve, E, or a right-click on the curve switches to the pen (again to leave it). While the pen is on, dragging does not change the time selection: the stroke immediately sets the volume to the height you draw, with a short fade back to the previous level at both ends. If the stroke goes above 0 dBFS, you can lower the whole stroke or discard it and draw again. Ctrl+Z undoes the stroke in progress and each finished stroke. That still works after the volume popup is cancelled. A right-click on a marker, region, or loop still opens the menu.

Overlay draws the waveform shape on top of the spectrogram. Dark areas can be lifted with the bar on the left or Alt+↑ / ↓ so they stay readable. Low frequencies take more vertical space (below 100 Hz is barely visible). The top of the scale is 24 kHz. When the whole file fits on screen, the picture is sharp. When zoomed in, it stays smooth so scrolling does not feel heavy.

8. Format conversion

  • S — sample rate
  • B — bit depth
  • C — file channel count (Mono / Stereo; this is not the speaker layout)

Presets are 8 / 11.025 / 16 / 22.05 / 32 / 44.1 / 48 / 96 kHz, bit depths 4 / 8 / 16 / 24, and channels Mono / Stereo. Custom Hz is 1000–384000. The menu sits just off the cursor. Highlighting a value updates the estimated file size. A dim overlay blocks the window while converting. Confirmed fields stay red until you save. Sample rate and bit depth always rebuild from the original audio (or after an edit such as fade). 48 kHz → 24 kHz then 11 kHz is rebuilt from 48 kHz, not through 24 kHz. Space previews rate and bit depth only. 4-bit is for listening. Wave writes 8 / 16 / 24-bit, and keeps 32-bit when the file already is. A 4-bit document is written as 16-bit. 32-bit is not a conversion preset.

9. WAAPI EXPORT (Wave-only)

Keep one-shot and loop material on a single Wave, then send it to Wwise. You do not have to split files first. EXPORT writes that wave as one file into Originals and trims clips to each range. It creates one Interactive Music playlist. -A / -L / -E shape ranges and entry / exit points; markers are not Custom Cues. There is no bar / tempo overlay and no multi-wave switching.

Fades and other edits are written into the wave before it is handed over. Markers and the sample loop are saved into the Wave file.

9-1. Steps

  1. Start Wwise Authoring.
  2. Turn on WAAPI above the level meter (Alt+W).
  3. Select a destination object in Wwise. Keep Target can pin the path.
  4. The export folder must be under Originals of the connected project.
  5. EXPORT or Ctrl+Shift+E. Enabled only while WAAPI is connected.
  • Play -E (Alt+E, while WAAPI is on) — keep playing after the exit. Preview in this app plays that tail twice on a loop wrap, so two playheads appear. EXPORT keeps playing after the exit on a transition.
  • Auto Active — bring Wwise to the front after EXPORT.
  • Project name — click, use waveform right-click → Wwise → Launch Project, or press Alt+Ctrl+Shift+W, to open or bring Wwise to the front. Works with WAAPI off: the bar is shown, then the project launches. If no project is remembered, it stays on the bar and reports that it cannot launch.

9-2. How ranges are built

Earlier items win.

  1. Sample loop (the loop already in the Wave, or Shift+L) — before the loop is Intro, the loop is -L. EXPORT treats leftover audio after the loop as -E (the waveform is not painted red). This beats markers.
  2. Markers ending in -A / -L / -E — each starts a range that runs to the next such marker (or the end). Markers without that ending do not split ranges. EXPORT treats a marker right after -L with no ending as -E (the comment on the waveform is left as-is and is not painted red. Existing -A / -L / -E / -R are left alone).
  3. Exactly two markers with no ending — the span between them is treated as a loop.
  4. Regions (Shift+R) — used as-is when there is no sample loop and no special markers.
  5. If none of the above apply, the whole file is one range.

9-3. Name endings

EndingMeaning
-LLoop. Loops in preview and becomes an infinitely looping Music Segment in Wwise.
-EAfter the Exit Cue (the tail). Bundled into the same Music Segment as the preceding -L so it can overlap the next piece on a transition.
-ABefore the Entry Cue (pickup). Bundled into the same Music Segment as the next range.
-RA mark used by another import tool. This app ignores it.

Markers are not written as Wwise Custom Cues. -A / -L / -E only shape ranges and entry / exit points.

9-4. What Wwise gets

  • One music playlist (named after the file). Plays in order; each range is one item.
  • Music segments. One range keeps the file name; several become _a / _b…. Loop ranges loop forever. -A and -E share a segment with their neighbor; only the entry / exit points move. Markers are not Custom Cues.
  • The source wave is not split. Every clip uses the same WAV and trims to the range.
  • The first range starts quickly. Prefetch and later look-ahead come from the Wwise tab in Settings (default 500 ms). Streaming is always on.
  • Tempo is set to 120 / 4/4 (there is no bar management).
  • With Play -E on, the tail after the exit still plays on a transition.

An existing container of the same name is replaced. A WAV of the same name under Originals is overwritten without asking. Always verify the result in Wwise.

11. Settings and language

Settings are the gear at the top left, or Ctrl+Shift+O. Tabs are General / Shown / Audio / Player / Editing / Export · Paths / Wwise. Details for each item are under Layout → Settings. Esc closes the window.

  • Language is on General. The default is Auto (Japanese if the PC is Japanese, otherwise English). The Japanese UI may still show some English labels.
  • The manual is ?, or in the browser. It follows the UI language.
  • Settings and open tabs are stored in this PC’s user folder (%LocalAppData%\MGA\MGA Sonic Anvil\). Nothing is written next to the app.
  • MP3 uses LAME when the path in Settings is valid; otherwise Windows writes it (128–320 kbps, default 192). It writes the stereo mix you hear now (see details). The written MP3 is not opened in the current tab. LAME is not included with this app.
  • Closing the app remembers open tabs and window position. Player and editor sizes are separate. Unsaved edits come back on the next launch. Quitting in player mode does not remember the playlist.
  • Only one copy of the app runs. A second start brings the existing window forward and opens the files you passed (mp3 / m4a start the player).
  • On startup, you are told if a newer version exists. Yes opens the download page (nothing is downloaded automatically). No skips that version. Offline, it continues quietly.

11-1. Auto speaker selection

A checkbox on Settings → Audio, under Default Wave format. It is off by default. When on, the app switches to an enabled layout that matches the number of channels in the current file. It runs when you open a file, bring a tab to the front, create a new file, or convert the channel count. It looks at the count only; it does not guess 5.1 from the file type.

  • When it helps — 1–2 channels use Stereo. 6 channels pick 5.1 when that layout is enabled. If only one enabled layout has that count, it is used. With only Stereo enabled, a 6-channel file is left as-is.
  • Watch out — If the current layout already has the same count, it stays. Switching stops playback and recording, and uses that layout’s device. If Stereo is headphones and 5.1 is another interface, the output jumps when you change tabs. Leave this off if you want to keep hearing a 6-channel file mixed down to Stereo.

11-2. MP3 downmix

Saving or exporting MP3 writes the stereo mix you hear with the current speaker layout. It does not follow raw file channel order. Wave export keeps the channel count. There is no prompt.

Speaker orderGoes toHow it is mixed

This matches 5.1 (L / R / C / LFE / Ls / Rs). Atmos height speakers or unusual layouts can come out unbalanced.

12. Scope
