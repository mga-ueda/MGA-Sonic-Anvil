MGA Sonic Anvil Manual

Hear, cut, mark, and loop game audio — then hand a Wave-only structure to Wwise.

1. What this app does

A waveform editor and Wave-only EXPORT into Wwise Interactive Music, in one window.

Fade, normalize, ripple-delete, copy / paste, markers / regions / sample loop, and a spectrogram — decide by ear and commit.

EXPORT talks to Wwise in Wave-only mode. It writes the source wave into Originals and imports it as a Music Playlist Container (-A / -L / -E and the sample loop; markers are not Custom Cues).

You can save an open wave as Wave or MP3. Right-click a tab to export the current edits as Wave or MP3.

Create a new file with Ctrl+N or open a file, then record with Ctrl+R. A prompt always asks whether to turn Silent Skip on. Recording uses the current file format and starts at the seek bar, overwriting audio after that point (Undo restores it). It does not start if no file is open. Recording stays PCM; MP3 is only when you save or export. An unsaved take left open comes back on restart. A closed tab can be reopened with Ctrl+Shift+T in this launch only. Speaker layouts (mono through Atmos) and the Ch map are switched in Settings and the status-bar SPEAKER menu.

2. Quick start

  1. Drop a Wave / AIFF / MP3, or press Ctrl+O (M4A is player-only; multiple files open as tabs; dropping a folder adds every supported file inside it and skips unsupported extensions; the status bar shows progress; Esc stops a multi-file load and keeps files already opened; the Open dialog remembers its last folder, separate from save / export). Ctrl+N opens an empty tab (choose the format each time; the last choice is remembered; channels are enabled speakers plus Mono).
  2. Listen, cut, fade, and place markers or a loop on the waveform. For multichannel work, enable layouts on Settings → Shown first, then pick one with SPEAKER on the status bar. Record with Ctrl+R (a prompt asks whether to turn Silent Skip on).
  3. Save with Ctrl+S as Wave or MP3 (AIFF export is not supported). With several tabs selected, Save and Save As (Ctrl+Shift+S) act on every selected file. Save overwrites files that already have a path; untitled or AIFF files ask for a folder and write Wave. Save As asks for a folder, writes each file as Wave, and points the tabs at those files (unlike Export, the tab follows the new file). Ctrl+Shift+M is MP3-only. Writing an MP3 is like Save As: it writes a file and keeps the current tab (the written MP3 is not opened). MP3 is re-encoded from 16-bit PCM. Three or more channels, or a remapped speaker Ch, write the same stereo fold you hear with the current layout (coefficients; no prompt). A valid LAME path in Settings is used; empty or invalid falls back to Windows (default 192 kbps). Markers are not written.
  4. To send it to Wwise, turn on WAAPI above the level meter, pick a destination, and press EXPORT.

Settings live in %LocalAppData%\MGA\MGA Sonic Anvil\. Nothing is written next to the exe. Closing the app also stores open tabs, unsaved edits, unsaved recordings, and edit history (when the operations can be replayed) there. Quitting while still in player mode does not remember the loaded files. Reopen Closed Tab (Ctrl+Shift+T) is only for tabs closed in this launch. It is forgotten after quit.

About bounce — the mix is a plain 32-bit float sum. Unlike a DAW bounce it runs no plugins, automation, or sends, which is why it is fast (only tabs with a different sample rate get resampled, using sinc interpolation). The summing itself loses no quality and is essentially the same as a DAW's internal summing bus. It applies no gain staging, though: loud waveforms stacked together can exceed 0 dBFS and will clip when written to the Wave file. With enough headroom it can stand in for a DAW mixdown, but since there is no limiter, dither, or other finishing, we don't actively recommend that. Lower the source levels beforehand, or check the peaks on the waveform and level meter after bouncing.

4. Playback

  • Space — play / stop. Stop returns to the start position.
  • Enter — pause in place. On the player list, play / restart from the beginning.
  • ← / → — while stopped, seek (about 1 px of the view; 1 sample when dots are shown). Hold during playback for 3× shuttle at the original pitch (−4 dB while held). Release restores speed and volume. Silent Skip does not run while you hold. Player mode does not shuttle with the arrows (numpad 1 / 3).
  • Ctrl+Space — from 3 seconds earlier.
  • Alt+Enter — restart from the playback start (while the tile search box has focus, closes tiles that did not match instead).
  • Alt+S — Silent Skip. Skip silent stretches during playback, and while recording write only audio above the threshold (off by default; threshold is in Settings, default −60 dB). The prompt shows the current threshold and silence insert duration (changeable in Settings). The region checkbox is enabled only when Silent Skip is on (off by default; remembered).
  • Ctrl+drag — scrub. Every channel is downmixed to L/R (the level meter moves on L/R only).
  • G — type NOW POS in the status bar. Enter jumps. Copy / paste allowed. Right-click switches time / samples.
  • Z or . (the numpad . is the same) — center. Toggles center-lock while playing; clears it when stopped.
  • L — loop from 3 seconds before the end of the selection (or the sample loop / -L).
  • Tab — solo a channel. Other lanes go gray and stay muted. Again moves to the next channel; Shift+Tab goes backward. Past the last clears solo. Click a channel name on the left to solo (click the same name again to clear; Ctrl+click adds; Shift+click mutes / unmutes). The time selection does not change. Waveform edits apply only to that channel. Works while playing or stopped.
  • Ctrl+N — new file. Opens an empty tab. Choose the format each time (the last choice is remembered). Channels are the speakers enabled on Shown, plus Mono (always available).
  • Ctrl+R — record. A prompt appears every time asking whether to turn Silent Skip on (the checkbox starts from the status-bar switch; OK updates it; the prompt shows the current threshold and silence insert duration, changeable in Settings; the region checkbox is enabled only when Silent Skip is on; off by default; remembered). Records in the current file format from the seek bar. Audio after that point is overwritten (Undo restores it; audio past the take stays; a longer take extends the file). It does not start if no file is open (create one with Ctrl+N or open a file first). Recording stays PCM; MP3 is only on save / export. An unsaved take left open is kept as a working copy and comes back on the next launch. A closed tab can be reopened with Ctrl+Shift+T in this launch only. With Silent Skip on, only audio above the threshold is written. Each recorded burst gets a short fade from the Editing tab in Settings (default 20 ms) at both ends. Record ports, playback ports, and Ch are assigned inside that layout (Ch is shared by record and playback; Off leaves the speaker unused).

5. Selection and editing

Drag to select. Double-click selects a span (between markers). Triple-click always selects all. Esc or a move without Shift clears it. Fade / volume / pitch / normalize / reverse / time stretch with nothing selected uses the whole file in time. While a channel is soloed, those edits apply only to the audible lanes. You can also type the selection start / length / end in the status bar.

  • FADE IN I / FADE OUT O — pick a curve, Space to preview, Enter to apply. 1–9 select a curve.
  • X — fade around seek bar: from the playhead, fade out only the visible part before / fade in only the visible part after (linear).
  • V — shows the loudness curve and opens volume. Type a dB value, or use ↑↓ / wheel by 0.1 dB (Shift 1 / Ctrl 3 / Ctrl+Shift 6). Space previews, Enter applies. The menu shows how whole-file Integrated LKFS / RMS / Peak will change. The Short Term curve and the stopped meter follow the same dB. Esc or Shift+V closes the curve.
  • P — pitch. ↑↓ / wheel by a semitone (Shift or Ctrl for an octave). Space previews, Enter applies. Range is ±2 octaves. Keep length is on by default (Tab moves to the checkbox). Off also changes length, like playback speed. A frosted-glass overlay shows progress while it runs.
  • T — time stretch (pitch stays). Uses the selection, or the whole file. Destination time and ratio (%) stay linked. ↑↓ / wheel (time: 1 s / Shift 10 s / Ctrl 1 min / Ctrl+Shift 10 min; ratio: 0.1 / Shift 1 / Ctrl 10 / Ctrl+Shift 25%). Tab switches fields. Space previews, Enter applies. Range is 10–1000%. A frosted-glass overlay shows progress while it runs.
  • NORMALIZE N — fit the peak to -0.1 dB.
  • R — reverse. Uses the selection, or the whole file. Audio only; markers / regions / loops stay put.
  • Waveform right-click → Audio → Normalize Waveform per Region — fit each region's peak to −0.1 dB. A short fade from the Editing tab in Settings (default 20 ms, to zero) is applied at each region's start and end to avoid a click.
  • DELETE — ripple-delete the selection. Selected markers / regions go with it.
  • Waveform right-click → Edit → Delete Silence — ripple-delete frames below the Silent Skip threshold (the selection, or the whole file). The threshold is on the Editing tab in Settings (default −60 dB). A ~50 ms peak window is used. That fixes a bug where troughs of a near-threshold tone were stripped and the pitch drifted slightly. Splice points get a short fade from the Editing tab in Settings (default 20 ms) so they do not click. The whole file cannot be emptied.
  • Ctrl+X / C / V — cut / copy / paste (markers in range included; a matching region is included too).
  • U — edit history. ↑↓ move, Enter apply, Esc cancel. Clicking the list left of loudness also opens it.
  • History copy & paste — inside the history, Ctrl+click to select steps (Shift+click or Shift+↑↓ for a range, Ctrl+A for all), then Ctrl+C. Press Ctrl+V in another file to re-apply the same processing (its history window does not need to be open). The copy persists until you copy something else, so you can switch tabs and press Ctrl+V repeatedly to apply it to multiple files. Pasting onto several selected tabs, or a slow step such as pitch shift, shows a frosted-glass overlay with an overall bar and a bar per tab. Ctrl+C with no selection copies every step up to the current position. Ranges are mapped by time across sample rates, and gain-type edits such as normalize are recomputed on the target. The only step you cannot copy is Original (it is not an edit; Ctrl+A leaves it uncolored).
  • History paste skips or surprises — each step is tried on the target; ones that do not fit are skipped (“Applied 3 of 5”). Examples that skip: adding a marker at a time that already has one, a delete / fade whose range falls off a shorter file, Delete Silence when the target has no silence, converting to the rate / bit depth / channel count the target already has, a marker comment where that marker is missing, and regions / loops onto an MP3. Dragging or nudging markers / regions / loops, and hold-to-subdivide, copy the layout at that moment. Pasting only the move onto another take replaces that take’s markers (include the adds through the moves if you want the same sequence). Times clamp to the end of a shorter file. An edit made with a channel soloed applies to the same channel index. Record / waveform-paste history carries the audio that was inserted. After Ctrl+C on the waveform, Ctrl+V pastes audio, not history.
  • Applying to the selected files — with two or more tabs selected (Ctrl+click / Shift+click / Ctrl+Shift+A), fade in / fade out, normalize, normalize per region, volume, pitch, time stretch, reverse, delete silence, sample-rate / bit-depth / channel conversion, Save (Ctrl+S), and Save As (Ctrl+Shift+S) run on every selected file (each whole file, honoring each file's own channel solo). 6. Markers / regions / loops

  • M / Ins — marker at the playhead when there is no selection. The same frame cannot take another. With a selection, the first press places start and end (or the midpoint if both ends already have markers); further presses replace them with thirds, then fourths, and so on (hold uses the same repeat timing as marker nudge; one history entry until you release).
  • Shift+L — set the selection as the sample loop (same range again clears it).
  • Shift+R — set the selection as a region. If both ends already have a region, the first press divides it in two; the same range again divides it in three, and so on (clear with right-click / Delete; hold uses the same repeat timing, one history entry until you release).
  • Click a flag to select an edge. Shift+click for a range, Ctrl+click to add. Drag or ←/→ to move (Shift ×3).
  • Double-click a comment / region name. -A lime, -L blue, -E red (only when you write it; the span after a loop or sample loop is not painted red automatically). -R is not colored. See 9-3 for what EXPORT does with them.
  • Ctrl+Shift+R — rename.
  • Right-click, or Ctrl+Del, deletes markers. Delete all markers and delete all regions are on Timeline.

7. Spectrogram / loudness analysis

A cycles spectrogram / overlay. V shows loudness analysis (the Short Term curve) and opens volume input. Esc, Shift+A, or Shift+V returns to the waveform from any view (Esc first cancels typing or the selection). The VIEW loudness button toggles the view only. L loops from 3 seconds before the end of the selection (or the sample loop / -L). Loudness analysis draws the Short Term LKFS curve. The white width is ±1 LU around the curve (1 LU = 1 LKFS; the same “approaching” window as the meter), drawn as a translucent fill. The waveform is a Mid-mix peak-dBFS line on the same vertical axis as LKFS (0 dBFS = 0 on the scale). At sample-level zoom it connects each sample with a line, same as the regular waveform. dBFS and LKFS are not the same, but peak and loudness can be compared at the same height. The background bands use the same blue / orange / red as the meter (red from 0 to the target, orange for the next 6 LU, blue below). The curve is primary cyan / orange / red; the red segment is a little thicker. The left scale is LKFS (waveform dB in the regular view). The white line is the Settings target. Overlay draws the waveform shape on top of the spectrogram (no translucent wash). It does not paint -A / -L / -E, sample-loop, or region fills (flags and lines stay; spectrogram-only and loudness analysis also skip those fills). The overlay waveform is also a single Mid-mix of the channels. At sample-level zoom it uses the same dots and connecting lines as the regular waveform. At amplitude zoom 1 it uses the middle half; amplifying fills the full height. Colors are display-normalized so the file's peak reads as 0 dBFS (the audio itself is untouched); the gain is measured once at load / edit analysis time, never in real time. Dark bins are lifted so they stay readable, without crushing the highlights. In spectrogram / overlay, drag the bar on the left or hold Alt+↑ / ↓ to change the lift. The frequency axis is logarithmic and tighter toward the bass (below 100 Hz is barely visible). The top of the scale is 24 kHz. When the whole file fits on screen — such as a short SE at fit — each screen column runs its own FFT and draws sharp, without interpolation. Any zoomed view draws smoothly interpolated columns from the full-file cache, keeping zooming and follow-scroll light. Scrolling shifts columns and computes only what is missing.

8. Format conversion

  • S — sample rate
  • B — bit depth
  • C — file channel count (Mono / Stereo; this is not the speaker layout)

Presets are 8 / 11.025 / 16 / 22.05 / 32 / 44.1 / 48 / 96 kHz, bit depths 4 / 8 / 16 / 24, and channels Mono / Stereo. Custom Hz is 1000–384000, nudged with ↑↓ / wheel by 1 Hz (Shift 10 / Ctrl 100 / Ctrl+Shift 1000). The menu sits just off the cursor. Highlighting a value updates the status size to the estimate. A frosted-glass overlay blocks the UI while converting. Confirmed fields stay red until you save. Sample rate and bit depth always convert from the PCM captured at load (or after a content edit such as fade). 48 kHz → 24 kHz then 11 kHz is rebuilt from 48 kHz, not cascaded through 24 kHz. Space previews rate and bit depth only (channels apply with Enter; 1–2 pick a row). 4-bit is for quantized audition. Wave writes 8 / 16 / 24-bit, and IEEE float when the document is already 32-bit. A 4-bit document is written as 16-bit. 32-bit is not a conversion preset.

9. WAAPI EXPORT (Wave-only)

The same assembly as Wwise IM Importer’s Wave-only mode. Keep one-shot and loop material on a single master waveform instead of pre-separating files. EXPORT writes that wave as one file into Originals and maps ranges with MusicClip trim. It creates one Music Playlist Container. -A / -L / -E shape ranges and Entry / Exit Cues; markers are not Custom Cues. There is no bar / tempo overlay, no multi-wave Switch, and no XML marker-track mode.

This app is also a waveform editor, so fades and other edits are baked into the source before it is handed over. Markers and the sample loop are written into the WAV on save.

9-1. Steps

  1. Start Wwise Authoring.
  2. Turn on WAAPI above the level meter (W).
  3. Select a destination object in Wwise. Keep Target can pin the path.
  4. The export folder must be under Originals of the connected project.
  5. EXPORT or Ctrl+Shift+E. Enabled only while WAAPI is connected.
  • Play -E (Alt+E, while WAAPI is on) — play after the Exit Cue. In-app preview double-plays -E on a loop wrap so two playheads appear. EXPORT writes Play post-exit on the Music Playlist Container default transition rule (Any to Any).
  • Auto Active — bring Wwise to the front after EXPORT.
  • Project name — click, or press Alt+Ctrl+Shift+W, to open or focus Wwise Authoring. Works with WAAPI off: the bar is shown, then the project launches. If no .wproj is remembered, it stays on the bar and reports that it cannot launch. Even if the .wproj association is the Launcher, the matching Wwise.exe is started directly.

9-2. How ranges are built

Earlier items win.

  1. Sample loop (the WAV smpl chunk, or Shift+L) — before the loop is Intro, the loop is -L. EXPORT treats a remainder after the loop as -E (the waveform is not painted red). This beats markers.
  2. Suffixed markers (-A / -L / -E) — each starts a region that runs to the next suffixed marker (or the end). Unnamed and named markers do not split ranges. EXPORT treats a suffix-less marker right after -L as -E (the comment on the waveform is left as-is and is not painted red. Existing -A / -L / -E / -R are left alone).
  3. Exactly two unsuffixed markers — the span between them becomes an implicit loop.
  4. Regions (Shift+R) — used as-is when there is no sample loop and no special markers.
  5. If none of the above apply, the whole file is one range.

9-3. Suffixes

SuffixMeaning
-LLoop. Loops in preview and becomes an infinitely looping Music Segment in Wwise.
-EAfter the Exit Cue (the tail). Bundled into the same Music Segment as the preceding -L so it can overlap the next piece on a transition.
-ABefore the Entry Cue (pickup). Bundled into the same Music Segment as the next range.
-RThe exclude suffix used by Wwise IM Importer. This app does not support that behavior.

Markers are not written as Wwise Custom Cues (same as Wwise IM Importer Wave-only). -A / -L / -E only shape ranges and Entry / Exit Cues.

9-4. What Wwise gets

  • One Music Playlist Container (named after the file). Sequential play; each range is a Playlist Item.
  • Music Segments. One range keeps the file name; several become _a / _b…. Loop ranges use Loop Count 0 (infinite). -A and -E share a Segment with their neighbor; only the Entry / Exit Cues move. Markers are not Custom Cues.
  • The source wave is not split. Every clip references the same WAV and uses Begin / End Trim for the range.
  • The first Segment is Zero Latency, 50 ms look-ahead, and Prefetch from the Wwise tab in Settings (default 500 ms). Later Segments use Look-ahead from the same tab (default 500 ms). Stream is always on.
  • Tempo 120 / 4/4 is overridden (there is no bar management).
  • With Play -E on, Play post-exit is set on the playlist default rule (Any to Any).

An existing container of the same name is replaced. A WAV of the same name under Originals is overwritten without asking. Always verify the result in Wwise.

11-1. Auto speaker selection

A checkbox on Settings → Audio, under Default audio format. It is off by default. When on, the app switches to an enabled speaker definition that matches the active file's channel count. It runs when you open a file, bring a tab to the front, create a new file, or convert the channel count (including Undo / Redo). It looks at the count only; it does not guess 5.1 from a file header.

  • Convenience — 1–2 ch uses Stereo. 6 ch picks 5.1 when that definition is enabled. If exactly one enabled definition has that count, it is used (5.1 Side alone for 6 ch). The same rule applies to every count (7.1 for 8 ch, and so on). With only Stereo enabled, a 6 ch file is left as-is.
  • Caveats — If the current layout already has the same count, it stays (5.1 Side is not reset to 5.1). If several layouts share that count and the usual one is not enabled, nothing changes. Switching stops playback and recording, and applies that definition's device and port map. If Stereo is headphones and 5.1 is another interface, the output jumps when you change tabs. Leave this off if you want to keep hearing a 6 ch file folded to Stereo.

11-2. MP3 downmix

Saving or exporting MP3 folds what you hear with the current speaker layout and Ch map (the same path as stereo playback with no port map). It does not follow raw file channel order. File channels are gathered onto speakers first; unassigned speakers stay silent, and file channels that no speaker reads are omitted. If the layout has three or more speakers, those slots are then folded to L/R with the coefficients below. A Stereo layout writes only the two assigned lanes. Mono files stay mono. Solo / mute are not written. Wave export keeps the channel count. There is no prompt or warning.

Speaker orderDestinationGain
1stL1
2ndR1
3rdL and R1/√2 (about 0.707, −3 dB). Treated as center
4thL and R1/√2. LFE is included
5thL1/√2
6thR1/√2
7thL1/√2

The coefficients follow speaker order after the Ch map, not layout names. That matches 5.1 (L / R / C / LFE / Ls / Rs). Layouts with a different order, such as Quad or 3.0, use the same approximation as playback.

Atmos heights or objects (9.1.6 and the like), Ambisonics, and stem packs can produce an unintended mix under this fold. A dedicated fold-down or binaural path is not supported today. It will be considered if there is demand.

12. Scope

  • This does not cover everything Interactive Music can do. EXPORT is Wave-only (markers / sample loop).
  • In-app preview is an approximation. Dual playheads for Play -E may not match Wwise exactly. Always verify after EXPORT.
  • AIFF export is not supported. Choose Wave or MP3. Wave writes 8 / 16 / 24-bit, and IEEE float when the document is already 32-bit (4-bit is for quantized audition and is saved as 16-bit. 32-bit is not a conversion preset).
  • Multichannel MP3 is the stereo fold of the current speaker layout. Dedicated mixes for Atmos heights / objects, Ambisonics, or stem packs are not supported today. They will be considered if there is demand.
  • EXPORT changes the Wwise project. Back up or use version control first.
