MGA Sonic Anvil Manual

Hear, cut, and tidy audio, add markers and loops, then send a Wave file to Wwise.

1. What this app does

Edit waveforms and send them to Wwise in one window.

Fade, match loudness, delete unused parts, copy / paste, markers, regions, loops, and a spectrogram. Listen, decide, and apply.

Wwise gets a single Wave file. The original wave is written to Originals and imported as Interactive Music. Markers ending in -A / -L / -E and the sample loop are used (not Custom Cues). See WAAPI EXPORT.

You can save an open file as Wave or MP3. Right-click a tab to write the current edits to another file.

New file: Ctrl+N. After opening, record with Ctrl+R. Before recording, you are always asked whether to use Silent Skip (skip silence). Recording uses the current file format and overwrites from the playhead (Undo restores it). It does not start if no file is open.

Recording stays as raw audio. MP3 is only when you save or export. Unsaved work in tabs that were still open comes back on the next launch. A closed tab can be reopened with Ctrl+Shift+T until you quit the app.

Speaker layouts (mono through Atmos) and which channels play are switched in Settings and the SPEAKER menu at the bottom of the window.

2. Quick start

  1. Drop a Wave / AIFF / MP3, or press Ctrl+O. M4A is player-only. Several files open as tabs. Dropping a folder adds every supported file inside it (unsupported types are skipped). The status bar shows progress. Esc stops a multi-file load and keeps files already opened. The Open dialog remembers its last folder, separate from save / export. Ctrl+N opens an empty tab. Choose the format each time; the last choice is remembered. Channels are the speakers you enabled, plus Mono.
  2. Listen, cut, fade, and place markers or a loop on the waveform. For files with many channels, enable layouts on Settings → Shown first, then pick one with SPEAKER at the bottom. Record with Ctrl+R (a prompt asks whether to use Silent Skip).
  3. Save with Ctrl+S as Wave or MP3 (you cannot write AIFF). With several tabs selected, Save and Save As (Ctrl+Shift+S) act on every selected file. Save overwrites files that already have a location; unsaved or AIFF files ask for a folder and write Wave. Save As asks for a folder, writes each file as Wave, and the tabs then point at those files (unlike Export, the tab follows the new file). Ctrl+Shift+M is MP3-only: it writes a file and keeps the current tab (the written MP3 is not opened). MP3 is rebuilt from 16-bit audio. Three or more channels, or a remapped speaker, write the same stereo mix you hear now (see MP3 downmix; no prompt). A valid LAME location in Settings is used; empty or invalid uses Windows (default 192 kbps). Markers are not written to MP3.
  4. To send it to Wwise, turn on WAAPI above the level meter, pick a destination, and press EXPORT.

Settings and open tabs are stored in this PC’s user folder (%LocalAppData%\MGA\MGA Sonic Anvil\). Nothing is written next to the app. Quitting while still in player mode does not remember the playlist. Reopen Closed Tab (Ctrl+Shift+T) is only for tabs closed before you quit.

Color settings

Overlapping-circles button in VIEW, or Ctrl+Shift+C

Tune the app colors (dark UI; no light/dark switch). The first open is centered on the app; the position and size are remembered.

Settings

Gear at the top left, or Ctrl+Shift+O

  • In Settings, New, and save-confirm dialogs, Tab also moves to the buttons.
  • Ctrl+Tab goes to the next tab, Ctrl+Shift+Tab to the previous. Esc closes it.
  • Width follows the Audio tab. Tabs are General / Shown / Audio / Player / Editing / Export / Wwise.

General

  • UI language — Auto / Japanese / English. Auto is Japanese if the OS is Japanese, otherwise English.
  • UI scale — 100–200%. Extra enlargement on top of Windows display scaling; you cannot shrink. Affects the main window only. Menus, Settings, and edit history stay at 100%. Applies as soon as you change it. Cancel restores it.
  • Multiple files — how to arrange two or more files after opening them: keep tabs / side by side / stacked / grid. Default is keep tabs.
  • File associations — Wave / AIFF / MP3 / M4A. M4A is player-only. Check to open that type with this app; uncheck to remove. Types already using this app start checked. The change applies immediately.

Shown

  • Speaker definitions — checklist of definitions to enable. Stereo only by default. The definition in use stays listed until you switch away. At least one must stay enabled. The status-bar SPEAKER menu uses the same list.
  • Playlist columns — choose WAVE and MP3 sets separately (only columns that make sense for that format; the file name is always shown; an empty playlist hides every column). WAVE / AIFF-only lists use the WAVE set, MP3 / M4A-only lists use the MP3 set. Mixed lists start with both sets combined. While mixed, dragging a header to reorder or right-clicking to show/hide is remembered only for that mixed list and does not change the WAVE / MP3 settings. Changing the WAVE / MP3 settings goes back to combining both sets. Each set can be reset. WAVE starts as file / rate / bits / Ch / time / date / parent folder / waveform. MP3 starts as file / title / album / artist / composer / time / track / disc / year / genre / date / comment / parent folder (waveform off). Empty columns hide and come back when a value appears. Jacket stays hidden for WAVE / AIFF only and appears when MP3 / M4A is present. Drag a header to reorder; right-click to turn columns on or off.
  • Waveform width — choose separately for WAVE and MP3 at the bottom of each column checklist. S (short) / M (medium) / L (long). WAVE and MP3 both default to L. M is 2× S, L is 3× S. WAVE / AIFF-only lists use the WAVE width, MP3 / M4A-only lists use the MP3 width, and mixed lists use the wider of the two. Reset to defaults also restores that side's width. Waveforms fill in after the list paints, as rough bars.

Audio

  • Default Wave format — 48 kHz / 24-bit / Stereo by default. Used for new files. Channels are enabled speakers plus Mono, which is always available.
  • Auto speaker selection — off by default. See details.
  • Speaker layout — mono through Atmos, including game-oriented variants such as Quad, LCRS, 2.1, and 5.1 Side. You do not add your own. The file itself stays numbered. Each speaker is assigned a file channel (Ch), and only those lanes show L / C / LFE and so on. The default is 1, 2, 3…. Switching layouts without OK asks whether to save the current one.
  • API and device — WaveOut / WASAPI / ASIO, and the audio device.
  • Record / playback ports and Ch — speaker names come from the layout, port names from the device. Ch is shared by record and playback. Off leaves the speaker unused. Record has level meters.
  • Test tone — per-playback-port Sine −20 dB (1 kHz, or 80 Hz on LFE) plus an English spoken channel-name Voice (not on LFE).
  • Stereo playback with no ports chosen still mixes the speakers to left and right.

Player

Gapless playback is first (on by default; see Gapless playback). Then the left tree roots. Default is Music. Add, remove, and reorder top to bottom.

Editing

  • Loudness target — LKFS.
  • Silence threshold (Silent Skip / Delete Silence) — default −60 dB, from −120 to 0. Used for playback skip, the record gate when on, and Delete Silence.
  • A mono level meter of the assigned record ports sits beside it. The bar is peak. The red line and number are avg. floor, not peak. The Editing tab also monitors input.
  • Silence insert duration on skip — default 500 ms. Longer gaps are shortened. 0 drops all silence. 0 to 10000. Unused on playback.
  • Click-prevention fade — default 20 ms, from 1 to 100. Used by normalize per region, Delete Silence, and Silent Skip recording splices.
  • Default fade curves.
  • Adding regions is chosen when you start recording.

Export

  • MP3 — Windows bit rate when not using LAME / LAME path / LAME options.
  • Parallel export count — default Auto = a quarter of the CPU cores. The dropdown max is half the cores.

Wwise

Music Track timing for EXPORT. Streaming is always on. Prefetch Length and Look-ahead Time both start at 500 ms (0 to 10000). Prefetch is on the first track; look-ahead is on later tracks. The first track’s look-ahead stays 50 ms.

Overview

Top strip

The bright area is the current view. Drag to move (scrubs the center); wheel zooms around the playhead.

Waveform

The edit surface

Time ruler, marker / region flags, playhead, and mouse guide. Triple-click selects all.

Channels

  • Click a channel name on the left to solo. Click the same name again to clear. Ctrl+click adds. Shift+click mutes / unmutes.
  • Tab solos a channel. Again moves to the next. Shift+Tab goes backward. Past the last clears it.
  • The time selection does not change. Fade / volume / normalize / reverse / pitch / time stretch / copy / delete apply only to that channel. Muted lanes go gray. Works while playing.

Fullscreen

  • F11 — waveform area fullscreen, like a browser. Hides tabs, transport, meters, Tips, WAAPI, channel names, the dB scale, the window frame, and the taskbar. Keeps the overview and status bar. Works while tiled. F11 again restores.
  • F12 — fullscreen with only the title bar hidden. Tabs, transport, meters, Tips, WAAPI, channel names, and the dB scale stay. Spectrum, loudness, level meter, and vector scope are 1.5× on top of Windows display scaling and UI scale. Works while tiled. F12 again restores.

Player mode

F10 on the waveform. Not fullscreen. F10 again restores.

Screen

  • Tabs are hidden. File list on top (folder tree left, list center) and a short fixed-height waveform below. The overview is hidden.
  • Groups default to parent folder, with a jacket beside each group. Playback and skip do not rebuild the list.
  • While the playlist is empty, every list column stays hidden (clearing a visible list fades the headers in 1 second), and the level meter, spectrum, loudness, gonio, and surround meter stay hidden (they start hidden when you enter player). An empty playlist focuses the library (folder tree).
  • F9 shows only the playlist and waveform (to save desktop space; from any mode).
    • Library, Favorites, meters, analyzers, transport, and status bar stay hidden. Alt+S Silent Skip and Alt+A Always on Top still work.
    • F9 again returns to the editor (stops playback, then keeps only the selected files and clears tab multi-selection).
    • F10 returns to the normal player and keeps playback going.
  • Window position and size are remembered separately from normal mode and restored on switch.

Playback

  • Entering selects and plays the first track (the same when you start the app with files).
  • Enter or transport Play restarts from the beginning and continues to the next track. Space plays that track only and stops when it ends.
  • While stopped, selecting a track shows its waveform without playing. Adding tracks fades them in over 1 second; when they start moving with the audio they appear immediately. Clearing the list fades them out over 1 second.
  • R toggles shuffle. No repeats until the playlist has played once. Works on an empty list. Off by default. Leaving player turns it off. Not saved.
  • Playback starts as soon as sound can play. It does not wait for the waveform to finish drawing.
  • Continuous playback prepares the next track and joins without stopping. Tiny extra silence at the start and end of MP3 / M4A is reduced by gapless playback (Player tab in Settings; on by default). A slight gap can still remain when it is on.
  • Arrow keys do not shuttle. The numpad (NumLock on) works from any pane.
    • 0 — play / pause
    • 1 — rewind, 3 — fast-forward (−4 dB while held)
    • 4 — previous track, 5 — restart, 6 — next track
    • 7 / 9 — skip 5 s back / forward with a 0.75 s crossfade (hold repeats after a short wait)
  • Top-row 0–9 still jump by view percent.

List and focus

  • ↑↓ select files. Home / End jump to the first / last track. PageUp / PageDown page the list (multi-select allowed; while playing, releasing switches to that track; while stopped, selection only).
  • F1 or Ctrl+← / Ctrl+↑ focuses the tree, F2 or Ctrl+↓ Favorites, F3 or Ctrl+→ the playlist.
  • F5 refreshes the folder tree and moves focus there (re-reads folders from disk; keeps expansion and selection when possible; works from the playlist, Favorites, or waveform too).
  • Tab cycles tree → Favorites → playlist (Shift+Tab reverse). The active pane shows a brighter fade at the top.
  • Ctrl+F activates search for the focused library / playlist. Space = AND, | = OR. Enter applies and returns focus. Esc discards the typed text.

Library

  • Opened files are listed without loading every waveform at once. Names, times, and similar info are read when files are added. Playlist columns are chosen separately for WAVE and MP3 in Settings → Shown. Empty columns hide automatically; waveform width is on the same Shown tab.
  • The tree on the left starts at Music and remembers the last folder, which folders were expanded, and the split with Favorites.
  • Splitters and scrollbars appear when the pointer nears them, then fade out after about 3 s of no movement. Selecting a folder does not add it to the list.
  • * expands all under the selection. / collapses it.
  • With the tree focused, type the start of a folder name to jump to it. Keep typing to narrow. About 1 s idle starts over. This does not add to the playlist.
  • Enter on the tree clears the playlist, then adds that folder recursively. While searching, only visible folders: matching files when the hit is a file name, or everything in a folder whose name matched. Depth-first. Playback starts with the first file registered.
  • Shift+Enter, double-click, or dropping a folder onto the list adds them recursively.

Waveform

The waveform only seeks and selects. No right-click, menu key, or Shift+F10 menu. No marker / region / loop overlay. Selection is inverted and translucent. No zoom. Display-resolution peaks only. Short files stay dense. Spectrogram / loudness-curve views stay off. Edit commands are blocked and grayed out.

Jacket and background

  • Jacket images load when a row is selected. A No Image placeholder is used when none is embedded. WAVE / AIFF-only playlists hide the jacket frame entirely (it appears when MP3 / M4A is present).
  • Drop an image on the jacket to replace it on MP3 only (written into the file). WAVE / AIFF / M4A cannot be replaced.
  • When a jacket is set, it is stretched to fill the whole player window (aspect may change) and used as a heavily blurred background, including the transport, meters, and status bar.

Entering and leaving

  • If you start the app with an MP3 or M4A, it opens in player mode with those files listed. Player mode does not show the multi-file dim overlay.
  • WAAPI is off. If it was on, leaving player turns it back on. Files from other modes are listed.
  • Leaving player mode stops playback first, then keeps only the selected files and clears tab multi-selection. Quitting while still in player mode does not remember the loaded files.

Loading

  • A slow single-file load shows Now Loading ... in the center.
  • Two or more files get a dim overlay with an overall bar and a bar per file. Esc stops the load and keeps files already opened.

Close this / others / right / left / all, bounce, select all, reopen, file times, and tiling use the same wording and access keys as the tab menu (acting on the active tab). It also has “Save All Tabs as Wave / MP3” (always every tab — not the same as the tab menu’s “Save Selected Files as …” when every tab is selected) and “Next Tab (N) / Previous Tab (V)”. Rename / duplicate / delete live under waveform → File; export and separate live under waveform → Export.

Bounce

With two or more tabs selected, “Bounce Selected Files (J)” mixes their waveforms together into a new Wave and opens it in the tab to the right of the selection. Ctrl+Shift+B does the same.

  • The length is the longest tab. Format follows the leftmost selected tab.
  • Markers and regions are carried over in place. A marker at the same position with the same comment is kept only once.
  • It asks where to save first. Default name Bounce.wav. The dialog starts in the folder of the first selected tab that has a file, else the last export folder.

Export

  • Export writes the current edits to another file (unsaved tabs stay unsaved). One tab opens a Save dialog; several tabs ask for a folder.
  • Overwrite is confirmed when the destination already exists: Yes = overwrite, No = skip those files, Cancel = stop. A long list shows the count and the first names only.
  • Separate export always asks for a folder. Markers need two or more spans; regions need at least one (tabs that do not qualify are skipped). Names append _1 (or _01 and so on so the digits match the count).
  • Channel export writes Wave from the current speaker layout and Ch map (not file channel order or names; unassigned speakers are skipped). Names use the layout labels such as _L / _C / _LFE. It asks for a folder.
  • Batch names use the source file name (or the tab title if unsaved). A clash gets 2 and up. The last export folder is remembered (separate from Open).
  • While it runs, a dim overlay blocks the UI and shows an overall bar plus a bar for every song encoding in parallel (more columns when they would not fit).
  • Ctrl+Shift+Alt+M saves every tab as MP3 (waveform right-click → Tabs; keeps the current tabs; there is no key for batch Wave).

Multi-select

  • Ctrl+click toggles, Shift+click selects a range, and Ctrl+A while the pointer is over the tab bar or a tile file-name strip selects all. Selected tabs and tile strips are highlighted. Esc deselects.
  • Ctrl+Shift+A selects every tab regardless of the pointer position or tiling. While the tile search filter is active, only the tabs the search matched. Tile strips use the same multi-select.
  • With a selection, the right-click menu keeps Close Other / Right / Left, and becomes “Close Selected/All Tabs” / “Bounce Selected Files” / “Duplicate Selected Files” / “Delete Selected Files” / “Paste Copied Edits to Selected/All Tabs” / “Export Selected Tabs as Wave / MP3” / “Export Selected Tabs Separated by Markers / Regions” / “Export Selected Tabs by Channel”. When every tab is selected, those labels switch to “Save / Export Selected Files …”. Wave / MP3 become “Save Selected Files as …”.
  • Ctrl+V applies the copied edit history to every selected tab at once. A dim overlay blocks the UI and shows an overall bar plus a bar per tab.

When the bar is full

When tabs no longer fit, inactive tabs shrink first. Scroll arrows appear only if a title would fall below 6 characters.

Tiling

Shows several tabs on one screen for comparison.

Arrangement

  • Ctrl+T cycles side by side → stacked → grid → off. Arrangements that would look identical for the current file count, or would not fit the waveform area, are skipped. If side-by-side or stacked would not fit, grid is tried. If grid would not fit either, the shortcut does nothing.
  • You can also pick one directly from waveform right-click → Tabs, or from the tab right-click menu: “Keep Tabs (B)” / “Side by Side (1)” / “Stacked (2)” / “Grid (3)”. Two or more tabs. Arrangements that would not fit stay disabled. The check marks the current arrangement.
  • Tiling switches every tab to the analysis view of the current tab (waveform / spectrogram / overlay / loudness).
  • Switching arrangements does not stop playback. Closing a tab while tiled removes its pane. When one tab remains, the view returns to normal.
  • Shrinking the window until side-by-side or stacked no longer fits tries grid, then returns to tabs if grid would not fit either.
  • The Multiple files setting on the General tab picks the default arrangement applied after opening two or more files (default is keep tabs; if side-by-side or stacked would not fit, grid is tried; if grid would not fit either, it is not applied).
  • The arrangement at quit is remembered and restored on the next launch when several tabs are restored (falls back to grid if needed; not restored if grid would not fit either).

Selection

  • Clicking a tile or playing makes it active. Its file-name strip turns blue, and only that tile shows the cyan playhead (inactive strips stay unfilled).
  • Ctrl+click / Shift+click the strip to select tiles the same way as tabs. Ctrl+A over a strip selects every tab. Selected strips use the same highlight as the active one.
  • Right-click the file-name strip for the same menu as a tab.

Search

While tiled, Ctrl+F opens a tab-name search. A search box appears in the center of the waveform area (it shows how to match all words or any word). The list updates as you type. Tiles that do not match are darkened and covered with a dim overlay.

  • Words separated by spaces must all match, and | means any group may match (for example bgm loop|se = contains both bgm and loop, or contains se; capital letters do not matter).
  • Enter confirms the condition and closes the box. The filter stays. Ctrl+F again reopens it with the same condition.
  • Esc cancels by restoring the text from when the box was opened, then closes the box. Clear the text to remove the filter.
  • Alt+Enter closes tiles that did not match (keeps unsaved edits; no prompt; clears the filter).
  • Ctrl+Shift+F — only while a search word is set — silently empties the search word and confirms, removing the filter without showing the box.
  • Covered tiles cannot be used. Clicking does not activate them, and Ctrl+Tab / Ctrl+PageUp / PageDown skip them.
  • Changing the text to narrow the filter makes the first matching waveform active (tab order, from the top-left tile). If that file is already active, it stays. If nothing matches, the active file is left unchanged. Clearing the text to remove the filter also leaves the active file.
  • Confirming the search never selects tabs by itself. Changing or confirming the search text also clears any leftover tab multi-selection. Select explicitly with Ctrl+Shift+A, which selects only the tabs the search matched while the filter is active.
  • If a new tab added while the filter is active (a bounce or duplicate) has a name that does not match, it is neither brought to the front nor selected — it just stays dimmed. Leaving tile view also resets the search.

Transport

  • Top row is playback and zoom. Second row is fade / normalize / delete / new / save / MP3 output, Tips on/off, and manual ?.
  • Range metronome (K) — metronome clicks at equal-divide markers/regions. Toggle with the button or K (off by default; never auto-on). Also available from waveform right-click → Playback.
  • The company logo and license sit under the buttons (license to the right of the logo). The logo opens the company site. GitHub opens the repository, MIT License the full text, LAME the project site. The Wwise® / Audiokinetic® trademark line is included.

Silent Skip

Status bar, left of SPEAKER. Alt+S. Off by default.

  • Skips silent stretches during playback, and while recording writes only audio above the threshold.
  • Each recorded burst gets a short fade from the Editing tab in Settings (default 20 ms) at both ends so it does not click.
  • Hold ← / → during playback to shuttle without skipping.
  • When the level falls, silence is written immediately and stops at the silence insert duration on skip (default 500 ms; unused on playback). It is not dumped when sound returns.
  • Starting a recording always asks whether to turn Silent Skip on. The checkbox starts from the status-bar switch. OK updates the status bar, Cancel leaves it. The prompt shows the current threshold and silence insert duration (changeable in Settings).
  • The region checkbox is enabled only when Silent Skip is on. Checking that adds a region to each recorded stretch separated by a pad. Silence does not get a region. Brief dips in the waveform are not split. A continued take gets regions for the new audio only. Off by default. Remembered. Adding regions is chosen when you start recording.
  • The threshold and silence insert duration are on the Editing tab in Settings (threshold default −60 dB). Waveform right-click → Edit → Delete Silence uses the same threshold.

Gapless playback

Settings → Player, first item. On by default.

Use this when tracks should play as one continuous piece. Splitting a live set or classical album into one MP3 or M4A per track can add a tiny silence at the start and end of each file. When on, that silence is skipped so the next track joins smoothly. It does not skip every quiet stretch (that is Silent Skip).

  • Files with no length information (older files, Windows MP3) play as they are.
  • If the information is wrong, a few tens of milliseconds can be missing at the start or end. If the silence is already gone, it is not cut again.
  • Long gaps that were written into the file (for example two seconds between tracks) are not removed.
  • Even when on, a slight gap can remain. It may not match a CD exactly.
  • When off, the extra silence is included. The waveform length on screen does not change either way.

Always on Top

Right of Silent Skip, left of SPEAKER

Keeps the window in front. Toggle with Alt+A.

Spectrum / loudness / meters / vector scope

A view of the playback output.

Loudness

Sits left of the spectrum. Short Term / Integrated / Momentary Max, Loudness Range, True Peak. Target LKFS is in Settings. Blue = headroom, orange = approaching, red = over.

  • While playing, values are live from the output and the numbers are colored.
  • While stopped, they are an offline read of the whole file. Short Term is the file maximum. The color is the value fill and the text stays the default color. Edits such as volume re-measure.
  • Left of loudness is the edit-history list. As many rows as fit; older rows clip. Click opens edit history with U. The strip itself does not select.

Spectrum and channel color

  • The spectrum mixes every channel into one band display.
  • Waveform channel names come from the speaker-to-Ch map (L / C / LFE and so on on assigned lanes). Unassigned lanes stay numbered from 1. The default is 1, 2, 3….
  • For three or more channels, names are white on a rounded color badge in a common appearance order (16 colors for Atmos 9.1.6). The waveform lanes take a light wash of the same colors. The level-meter bars use the same colors.

Stereo and mono

Cyan gradient. The inner two bars are Peak (red lamps clip), the outer two are RMS (both have hold lines). Numbers below are Peak then RMS. The meter does not show channel names.

Three or more channels

  • The vector scope is replaced by a surround view that uses the same map (channel names come from the layout you picked, not from the file).
  • Energy uses the same channel colors as the waveform. Size is channel level. The outline texture is that channel's recent waveform (the tip is now, the flanks are a few milliseconds earlier).
  • One thin dark-gray outline wraps the overall spread. The outline holds peaks briefly, then falls slowly.
  • The level meter shows one Peak bar per channel, with Peak hold and a slower RMS hold.

Width and the bar

  • Drag the left edge of the column to widen it. The default is the minimum. It stops when the bars reach full thickness. The width is remembered on the next launch.
  • After stop, the display slowly fades. WAAPI above the level meter toggles the bar.

Tips

Above the WAAPI bar. Fixed height.

  • Hover a control to see its description; overflow scrolls. Tips appear right away. Moving to another control waits a moment before switching.
  • Click the heading or body to lock (cyan frame, Tips (Locked)). Click again to unlock. The text does not change while locked or while the pointer is on the panel.
  • Transport buttons also show a short tooltip (with the shortcut; wraps, no ellipsis). Other controls have no floating tooltip.

WAAPI bar

Connection, destination, Play -E, Auto Active, EXPORT.

Click the project name, or press Alt+Ctrl+Shift+W, to open or bring Wwise to the front. Shows the bar first even if WAAPI is off. If no project is remembered, it only shows the bar and reports that it cannot launch.

Status bar

  • File position — with two or more files open, the front shows the position and count, e.g. 1 / 10 Files.
  • Format — name is on the tab. Sample rate / bit depth / channels turn red after conversion until you save. MP3 / M4A also show bit rate. Size is MB (MiB / B), and turns red as an estimate after conversion or a range delete that changes length.
  • Silent Skip and Always on Top — left of SPEAKER. Silent Skip is Alt+S. Always on Top is Alt+A. Skips silence on playback, and records only above the threshold. Threshold is in Settings.
  • SPEAKER — switches the speaker layout. Same list as Shown. The definition in use stays listed until you switch away. Auto speaker selection, off by default, switches to a matching enabled definition.
  • Times — current / selection start / selection length / selection end / total. All but total are editable. Wheel / ↑↓ nudge: time by 1 s / Shift 10 s / Ctrl 1 min / Ctrl+Shift 10 min, samples by 1 / Shift 10 / Ctrl 100 / Ctrl+Shift 1000. Right-click switches time and samples.

The selected tabs are stacked into a new Wave. Plugins and effects are not applied. It is fast, but loud files stacked together can clip — lower the levels first, or check the peaks afterward. Files of different length are lined up before stacking.

4. Playback

  • Space — play / stop. Stop returns to the start position. In player mode, plays only the selected track and stops when it ends (does not continue the playlist).
  • Enter — pause in place. On the player list, restart from the beginning and continue to the next track when it ends (transport Play does the same continuous playback).
  • ← / → — while stopped, seek (about 1 px of the view; 1 sample when dots are shown). Hold during playback for 3× shuttle at the original pitch (−4 dB while held). Release restores speed and volume. Silent Skip does not run while you hold. Player mode does not shuttle with the arrows (numpad 1 / 3).
  • Ctrl+Space — from 3 seconds earlier.
  • Alt+Enter — restart from the playback start (while the tile search box has focus, closes tiles that did not match instead).
  • Alt+S — Silent Skip. Skip silent stretches during playback, and while recording write only audio above the threshold (off by default; threshold is in Settings, default −60 dB). Hold ← / → during playback to shuttle without skipping. Recording always asks whether to turn Silent Skip on (the checkbox starts from the status-bar switch; OK updates it). The prompt shows the current threshold and silence insert duration (changeable in Settings). The region checkbox is enabled only when Silent Skip is on (off by default; remembered).
  • Player continuous playback prepares the next track. Tiny silences at the start and end of MP3 / M4A are reduced by gapless playback (Player tab in Settings; on by default). A slight gap can still remain when it is on.
  • Ctrl+drag — scrub. Every channel is mixed to left and right (the level meter moves on L/R only).
  • G — type NOW POS in the status bar. Enter jumps. Copy / paste allowed. Right-click switches time / samples.
  • Z or . (the numpad . is the same) — center. Toggles center-lock while playing; clears it when stopped.
  • L — loop from 3 seconds before the end of the selection (or the sample loop / -L).
  • K — range metronome. Metronome clicks at equal-divide markers/regions. Toggle with the button or K (off by default; never auto-on). Also available from waveform right-click → Playback.
  • Tab — solo a channel. Other lanes go gray and stay muted. Again moves to the next channel; Shift+Tab goes backward. Past the last clears solo. Click a channel name on the left to solo (click the same name again to clear; Ctrl+click adds; Shift+click mutes / unmutes). The time selection does not change. Waveform edits apply only to that channel. Works while playing or stopped.
  • Ctrl+N — new file. Opens an empty tab. Choose the format each time (the last choice is remembered). Channels are the speakers enabled on Shown, plus Mono (always available).
  • Ctrl+R — record. A prompt appears every time asking whether to turn Silent Skip on (the checkbox starts from the status-bar switch; OK updates it; the prompt shows the current threshold and silence insert duration, changeable in Settings; the region checkbox is enabled only when Silent Skip is on; off by default; remembered). Records in the current file format from the seek bar. Audio after that point is overwritten (Undo restores it; audio past the take stays; a longer take extends the file). It does not start if no file is open (create one with Ctrl+N or open a file first). Recording stays as raw audio; MP3 is only on save / export. An unsaved take left open is kept as a working copy and comes back on the next launch. A closed tab can be reopened with Ctrl+Shift+T in this launch only. Press again, or Space / Enter / Esc, to stop. While recording, the waveform background turns reddish. New audio appears immediately as a rough waveform, then settles into the usual drawing. With Silent Skip on, only audio above the threshold is written. Each recorded burst gets a short fade from the Editing tab in Settings (default 20 ms) at both ends. Silence is inserted when the level falls and stops at the record max (default 500 ms). Checking the region box adds one for each recorded stretch and each silent pad when you stop. Record ports, playback ports, and Ch are assigned inside that layout (Ch is shared by record and playback; Off leaves the speaker unused).
  • Stereo playback with no port map still downmixes the speakers to L/R. Mono with two or more ports plays the same signal on L and R.

5. Selection and editing

Drag to select. Double-click selects a span (between markers). Triple-click always selects all. Esc or a move without Shift clears it. Fade / volume / pitch / normalize / reverse / time stretch with nothing selected uses the whole file in time. While a channel is soloed, those edits apply only to the audible lanes. You can also type the selection start / length / end in the status bar.

  • FADE IN I / FADE OUT O — pick a curve, Space to preview, Enter to apply. 1–9 select a curve.
  • X — fade around seek bar: from the playhead, fade out only the visible part before / fade in only the visible part after (linear).
  • V — shows the loudness curve and opens volume. Type a dB value, or use ↑↓ / wheel by 0.1 dB (Shift 1 / Ctrl 3 / Ctrl+Shift 6). Space previews, Enter applies. The menu shows how whole-file Integrated LKFS / RMS / Peak will change. The Short Term curve and the stopped meter follow the same dB. Esc or Shift+V closes the curve.
  • P — pitch. ↑↓ / wheel by a semitone (Shift or Ctrl for an octave). Space previews, Enter applies. Range is ±2 octaves. Keep length is on by default (Tab moves to the checkbox). Off also changes length, like playback speed. A dim overlay shows progress while it runs.
  • T — time stretch (pitch stays). Uses the selection, or the whole file. Destination time and ratio (%) stay linked. ↑↓ / wheel (time: 1 s / Shift 10 s / Ctrl 1 min / Ctrl+Shift 10 min; ratio: 0.1 / Shift 1 / Ctrl 10 / Ctrl+Shift 25%). Tab switches fields. Space previews, Enter applies. Range is 10–1000%. A dim overlay shows progress while it runs.
  • NORMALIZE N — fit the peak to -0.1 dB.
  • R — reverse. Uses the selection, or the whole file. Audio only; markers / regions / loops stay put.
  • Waveform right-click → Audio → Normalize Waveform per Region — fit each region's peak to −0.1 dB. A short fade from the Editing tab in Settings (default 20 ms, to zero) is applied at each region's start and end to avoid a click.
  • DELETE — delete the selection and close the gap. Selected markers / regions go with it.
  • Waveform right-click → Edit → Delete Silence — delete quiet parts below the Silent Skip threshold (the selection, or the whole file). The threshold is on the Editing tab in Settings (default −60 dB). Splice points get a short fade (default 20 ms) so they do not click. The whole file cannot be emptied.
  • Ctrl+X / C / V — cut / copy / paste (markers in range included; a matching region is included too).
  • U — edit history. ↑↓ move, Enter apply, Esc cancel. Uses the same fill as the sample-rate convert picker list. Clicking the list left of loudness also opens it.
  • History copy & paste — inside the history, Ctrl+click to select steps (Shift+click or Shift+↑↓ for a range, Ctrl+A for all), then Ctrl+C. Press Ctrl+V in another file to apply the same edits (its history window does not need to be open). The copy stays until you copy something else, so you can switch tabs and press Ctrl+V on each file. Pasting onto several selected tabs, or a slow step such as pitch, shows a dim overlay with progress. Ctrl+C with no selection copies every step up to the current position. Ranges line up by playback time, and matching loudness is done again on the target. The only step you cannot copy is Original (it is not an edit; Ctrl+A leaves it uncolored).
  • History paste skips or surprises — each step is tried on the target; ones that do not fit are skipped (“Applied 3 of 5”). Examples that skip: adding a marker at a time that already has one, a delete / fade whose range falls off a shorter file, Delete Silence when the target has no silence, converting to the rate / bit depth / channel count the target already has, a marker comment where that marker is missing, and regions / loops onto an MP3. Dragging or nudging markers / regions / loops, and hold-to-subdivide, copy the layout at that moment. Pasting only the move onto another take replaces that take’s markers (include the adds through the moves if you want the same sequence). Times clamp to the end of a shorter file. An edit made with a channel soloed applies to the same channel index. Record / waveform-paste history carries the audio that was inserted. After Ctrl+C on the waveform, Ctrl+V pastes audio, not history.
  • Applying to the selected files — with two or more tabs selected (Ctrl+click / Shift+click / Ctrl+Shift+A), fade in / fade out, normalize, normalize per region, volume, pitch, time stretch, reverse, delete silence, sample-rate / bit-depth / channel conversion, Save (Ctrl+S), and Save As (Ctrl+Shift+S) run on every selected file (each whole file, using that file’s own solo). The right-click menu names change accordingly, e.g. “Normalize Selected Files (N)” and “Save Selected Files (S) / Save Selected Files As (A)”. Save overwrites files that already have a path; untitled or AIFF files ask for a folder and write Wave. Save As asks for a folder, writes each as Wave, and points the tabs at those files (unlike Export, the tab follows the new file). Curve and dB previews play on the active file; Enter applies to all selected files. Time stretch converts the target into a ratio and applies it per file. Files the edit cannot apply to (no regions, no silence, already in that format, and so on) are skipped; if everything is skipped you get a note. While running, a dim overlay shows overall and per-file progress and blocks input (the tile-search overlay stays and this stacks on top). Export and history paste follow the same rule: with tabs selected, waveform right-click → Export's “Export Wave / MP3”, “Separate by Markers / Regions” and “Export by Channel” become “… Selected Tabs” and export the selected tabs in one go, and Edit → “Paste Copied Edits” becomes “Paste Copied Edits to Selected Tabs” (or “Paste Copied Edits to All Tabs” when everything is selected), same as Ctrl+V. Duplicate and Delete File also switch to “Duplicate Selected Files (U)” (Ctrl+Shift+D too) and “Delete Selected Files (D)” and run on every selected file (one confirmation; each copy opens next to its own tab; files that could not be deleted are listed at the end). Waveform right-click → Tabs also has “Select All Tabs (A)” (same as Ctrl+Shift+A). Fade around seek bar (X) and cut / copy / paste / delete stay on the active file only.
  • Ctrl+Z / Ctrl+Y (Ctrl+Shift+Z also redo) — undo / redo.

6. Markers / regions / loops

  • M / Ins — marker at the playhead when there is no selection. The same frame cannot take another. With a selection, the first press places start and end (or the midpoint if both ends already have markers); further presses replace them with thirds, then fourths, and so on (hold uses the same repeat timing as marker nudge; one history entry until you release).
  • Shift+L — set the selection as the sample loop (same range again clears it).
  • Shift+R — set the selection as a region. If both ends already have a region, the first press divides it in two; the same range again divides it in three, and so on (clear with right-click / Delete; hold uses the same repeat timing, one history entry until you release).
  • Click a flag to select an edge. Shift+click for a range, Ctrl+click to add. Drag or ←/→ to move (Shift ×3).
  • Double-click a comment / region name. -A lime, -L blue, -E red (only when you write it; the span after a loop or sample loop is not painted red automatically). -R is gray. See 9-3 for what EXPORT does with them.
  • Ctrl+Shift+R — rename.
  • Right-click, or Ctrl+Del, deletes markers. Delete all markers and delete all regions are on Timeline.

Markers, regions, and loops are stored in the Wave file when you save. MP3 cannot take regions or a loop. Markers are allowed, but they are not written when you save as MP3.

7. Spectrogram / loudness analysis

A cycles spectrogram / overlay. V shows the loudness curve and opens volume. Esc, Shift+A, or Shift+V returns to the waveform. The VIEW loudness button toggles the view only. L loops from 3 seconds before the end of the selection (or the sample loop / -L).

The loudness view draws how loud the sound is over time (Short Term). The white band around the curve is a small “getting close to the limit” zone, like the meter. Peak level is drawn on the same height so you can compare. Blue / orange / red match the meter. The left numbers are loudness (LKFS); the white line is the target in Settings.

Overlay draws the waveform shape on top of the spectrogram. Dark areas can be lifted with the bar on the left or Alt+↑ / ↓ so they stay readable. Low frequencies take more vertical space (below 100 Hz is barely visible). The top of the scale is 24 kHz. When the whole file fits on screen, the picture is sharp. When zoomed in, it stays smooth so scrolling does not feel heavy.

8. Format conversion

  • S — sample rate
  • B — bit depth
  • C — file channel count (Mono / Stereo; this is not the speaker layout)

Presets are 8 / 11.025 / 16 / 22.05 / 32 / 44.1 / 48 / 96 kHz, bit depths 4 / 8 / 16 / 24, and channels Mono / Stereo. Custom Hz is 1000–384000. The menu sits just off the cursor. Highlighting a value updates the estimated file size. A dim overlay blocks the window while converting. Confirmed fields stay red until you save. Sample rate and bit depth always rebuild from the original audio (or after an edit such as fade). 48 kHz → 24 kHz then 11 kHz is rebuilt from 48 kHz, not through 24 kHz. Space previews rate and bit depth only. 4-bit is for listening. Wave writes 8 / 16 / 24-bit, and keeps 32-bit when the file already is. A 4-bit document is written as 16-bit. 32-bit is not a conversion preset.

9. WAAPI EXPORT (Wave-only)

Keep one-shot and loop material on a single Wave, then send it to Wwise. You do not have to split files first. EXPORT writes that wave as one file into Originals and trims clips to each range. It creates one Interactive Music playlist. -A / -L / -E shape ranges and entry / exit points; markers are not Custom Cues. There is no bar / tempo overlay and no multi-wave switching.

Fades and other edits are written into the wave before it is handed over. Markers and the sample loop are saved into the Wave file.

9-1. Steps

  1. Start Wwise Authoring.
  2. Turn on WAAPI above the level meter (W).
  3. Select a destination object in Wwise. Keep Target can pin the path.
  4. The export folder must be under Originals of the connected project.
  5. EXPORT or Ctrl+Shift+E. Enabled only while WAAPI is connected.
  • Play -E (Alt+E, while WAAPI is on) — keep playing after the exit. Preview in this app plays that tail twice on a loop wrap, so two playheads appear. EXPORT keeps playing after the exit on a transition.
  • Auto Active — bring Wwise to the front after EXPORT.
  • Project name — click, or press Alt+Ctrl+Shift+W, to open or bring Wwise to the front. Works with WAAPI off: the bar is shown, then the project launches. If no project is remembered, it stays on the bar and reports that it cannot launch.

9-2. How ranges are built

Earlier items win.

  1. Sample loop (the loop already in the Wave, or Shift+L) — before the loop is Intro, the loop is -L. EXPORT treats leftover audio after the loop as -E (the waveform is not painted red). This beats markers.
  2. Markers ending in -A / -L / -E — each starts a range that runs to the next such marker (or the end). Markers without that ending do not split ranges. EXPORT treats a marker right after -L with no ending as -E (the comment on the waveform is left as-is and is not painted red. Existing -A / -L / -E / -R are left alone).
  3. Exactly two markers with no ending — the span between them is treated as a loop.
  4. Regions (Shift+R) — used as-is when there is no sample loop and no special markers.
  5. If none of the above apply, the whole file is one range.

9-3. Name endings

EndingMeaning
-LLoop. Loops in preview and becomes an infinitely looping Music Segment in Wwise.
-EAfter the Exit Cue (the tail). Bundled into the same Music Segment as the preceding -L so it can overlap the next piece on a transition.
-ABefore the Entry Cue (pickup). Bundled into the same Music Segment as the next range.
-RA mark used by another import tool. This app ignores it.

Markers are not written as Wwise Custom Cues. -A / -L / -E only shape ranges and entry / exit points.

9-4. What Wwise gets

  • One music playlist (named after the file). Plays in order; each range is one item.
  • Music segments. One range keeps the file name; several become _a / _b…. Loop ranges loop forever. -A and -E share a segment with their neighbor; only the entry / exit points move. Markers are not Custom Cues.
  • The source wave is not split. Every clip uses the same WAV and trims to the range.
  • The first range starts quickly. Prefetch and later look-ahead come from the Wwise tab in Settings (default 500 ms). Streaming is always on.
  • Tempo is set to 120 / 4/4 (there is no bar management).
  • With Play -E on, the tail after the exit still plays on a transition.

An existing container of the same name is replaced. A WAV of the same name under Originals is overwritten without asking. Always verify the result in Wwise.

11. Settings and language

Settings are the gear at the top left, or Ctrl+Shift+O. Tabs are General / Shown / Audio / Player / Editing / Export / Wwise. Details for each item are under Layout → Settings. Esc closes the window.

  • Language is on General. The default is Auto (Japanese if the PC is Japanese, otherwise English). The Japanese UI may still show some English labels.
  • The manual is ?, or in the browser. It follows the UI language.
  • Settings and open tabs are stored in this PC’s user folder (%LocalAppData%\MGA\MGA Sonic Anvil\). Nothing is written next to the app.
  • MP3 uses LAME when the path in Settings is valid; otherwise Windows writes it (128–320 kbps, default 192). It writes the stereo mix you hear now (see details). The written MP3 is not opened in the current tab. LAME is not included with this app.
  • Closing the app remembers open tabs and window position. Player and editor sizes are separate. Unsaved edits come back on the next launch. Quitting in player mode does not remember the playlist.
  • Only one copy of the app runs. A second start brings the existing window forward and opens the files you passed (mp3 / m4a start the player).
  • On startup, you are told if a newer version exists. Yes opens the download page (nothing is downloaded automatically). No skips that version. Offline, it continues quietly.

11-1. Auto speaker selection

A checkbox on Settings → Audio, under Default Wave format. It is off by default. When on, the app switches to an enabled layout that matches the number of channels in the current file. It runs when you open a file, bring a tab to the front, create a new file, or convert the channel count. It looks at the count only; it does not guess 5.1 from the file type.

  • When it helps — 1–2 channels use Stereo. 6 channels pick 5.1 when that layout is enabled. If only one enabled layout has that count, it is used. With only Stereo enabled, a 6-channel file is left as-is.
  • Watch out — If the current layout already has the same count, it stays. Switching stops playback and recording, and uses that layout’s device. If Stereo is headphones and 5.1 is another interface, the output jumps when you change tabs. Leave this off if you want to keep hearing a 6-channel file mixed down to Stereo.

11-2. MP3 downmix

Saving or exporting MP3 writes the stereo mix you hear with the current speaker layout. It does not follow raw file channel order. Wave export keeps the channel count. There is no prompt.

Speaker orderGoes toHow it is mixed
1stLFull
2ndRFull
3rdL and RA little quieter (center)
4thL and RA little quieter (includes LFE)
5th–8thOdd to L, even to RA little quieter
9th and upOdd to L, even to RQuieter still

This matches 5.1 (L / R / C / LFE / Ls / Rs). Atmos height speakers or unusual layouts can come out unbalanced.

12. Scope

  • This does not cover everything Interactive Music can do. EXPORT is a single Wave (markers / sample loop).
  • In-app preview is a guide. Always check the result in Wwise after EXPORT.
  • You cannot write AIFF. Choose Wave or MP3. Wave writes 8 / 16 / 24-bit, and keeps 32-bit when the file already is (4-bit is for listening and is saved as 16-bit).
  • Multichannel MP3 is the stereo mix you hear now.
  • EXPORT changes the Wwise project. Back up first.
