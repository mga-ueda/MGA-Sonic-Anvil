MGA Sonic Anvil マニュアル

音を聴きながら切って整え、目印とループを付けて、Wwise へ Wave で渡すアプリです。

1. このアプリでできること

波形の編集と、Wwise への書き出しが、ひとつの画面でできます。

フェード、音量のそろえ、いらない部分の削除、コピー／貼り付け、マーカー、リージョン、ループ、スペクトログラム。聴きながら決めて、そのまま確定できます。

Wwise へは、1 本の Wave として渡せます。 元の波形をプロジェクトの Originals に書き、Interactive Music のプレイリストとして取り込みます。名前の末尾が -A / -L / -E の目印と、サンプルループを使います（Wwise の Custom Cue にはしません）。くわしくは WAAPI EXPORT です。

開いている音は Wave または MP3 で保存できます。タブを右クリックすると、今の編集内容を別ファイルへ書き出せます。

新しいファイルは Ctrl+N。開いたあと Ctrl+R で録音できます。録音の前に、無音を飛ばす Silent Skip を使うか毎回聞きます。録音は今のファイルの形式で、再生位置から上書きします（元に戻すで戻せます）。ファイルが無いときは始まりません。

録音そのものは Wave のままです。MP3 になるのは保存や書き出しのときだけです。保存せずに終了しても、開いたままだったタブは次に起動したときに戻ります。閉じたタブは、アプリを閉じる前なら Ctrl+Shift+T で開き直せます。

スピーカーの配置（モノラル〜Atmos）と、どのチャンネルを出すかは、設定と画面下の SPEAKER で切り替えます。

2. クイックスタート

  1. Wave / AIFF / MP3 をドラッグするか、Ctrl+O で開きます。

    • M4A はプレイヤー専用です。複数開くとタブで並びます。
    • プレイヤーでは、設定がオンなら PDF / MOV / MP4 / AVI / MKV / WebM / MPG もプレイリストに載せます（PDF は既定オン。動画は既定オフ。AVI / MKV / WebM / MPG は ffmpeg があるときだけ。エディタでは開きません）。
    • フォルダをドロップすると、中の対応ファイルをすべて追加します（開けない種類は無視します）。
    • たくさん開くときは、画面下に進み具合が出ます。Esc で止められ、すでに開いた分は残ります。
    • 開く場所は前回を覚えます。保存先とは別です。

    Ctrl+N で空のタブを作れます。形式は毎回選べ、前回の選択を覚えます。チャンネルは、設定で有効にしたスピーカーと、いつも選べるモノラルです。

  2. 波形の上で聴きながら切る・フェードする・マーカーやループを置きます。チャンネルが多いファイルは、先に設定の表示項目で配置を有効にし、画面下の SPEAKER で選びます。Ctrl+R で録音できます（開始前に Silent Skip を使うか確認します）。

  3. 必要なら Ctrl+S で Wave または MP3 に保存します（AIFF では書き出せません）。

    • タブを複数選んでいるときは、保存も名前を付けて保存（Ctrl+Shift+S）も、選んだファイル全部に行います。
    • すでに場所があるファイルは上書きします。まだ保存していないものや AIFF は、フォルダを選んで Wave で保存します。
    • 名前を付けて保存はフォルダを選び、各ファイルを Wave で書いて、タブがその新しいファイルを指すようになります。書き出しと違い、保存後のファイルが今のタブになります。
    • Ctrl+Shift+M は MP3 専用です。ファイルを出すだけで、今のタブはそのままです（書き出した MP3 は開きません）。
    • MP3 はいったん 16 bit の音から作り直します。3 チャンネル以上、またはスピーカーの割り当てを変えているときは、今聴いている左右 2 本にまとめた音を書きます（くわしくは MP3 のダウンミックス。確認は出しません）。
    • 設定で LAME の場所が正しければそれを使い、空欄や無効なら Windows で書き出します（既定 192 kbps）。マーカーなどは MP3 には書きません。
  4. Wwise へ渡すときは、レベルメーター上の WAAPI をオンにし、作成先を選んで EXPORT します。

設定や、開いていたタブ、保存していない編集は、このパソコンのユーザー用フォルダ（%LocalAppData%\MGA\MGA Sonic Anvil\）に残ります。アプリの横には書きません。プレイヤーのまま終了したときは、リストの曲は覚えません。閉じたタブの再開（Ctrl+Shift+T）は、アプリを閉じる前に閉じたものだけです。

アプリの配色を調整します（ダーク固定。ライト切替はありません）。初回はアプリの中央に開き、位置とサイズを覚えます。

設定

左上の歯車、Ctrl+Shift+O

  • 設定・新規・保存確認などのダイアログでは Tab でボタンへも移動できます。
  • Ctrl+Tab で次のタブ、Ctrl+Shift+Tab で前のタブ。Esc で閉じます。
  • 幅はオーディオタブの内容に合わせます。タブは一般／表示項目／オーディオ／プレイヤー／編集／書き出し・パス／Wwise です。

一般

  • 表示言語 …… Auto／Japanese／English。Auto は、パソコンが日本語なら Japanese、それ以外は English です。
  • 表示倍率 …… 100〜200%。Windows の拡大に加えて、さらに大きくします。小さくはできません。効くのはメイン画面だけです。右クリックメニューや設定などの別ウィンドウ、編集履歴は 100% のままです。選んだ瞬間に変わり、キャンセルで戻します。
  • 複数ファイル …… 2 つ以上開いたあとの並べ方。タブのまま／左右／上下／上下左右。最初はタブのままです。
  • 関連付け …… 音声は Wave / AIFF / MP3 / M4A（M4A はプレイヤー専用）。動画は MP4 / MOV / AVI / MKV / WebM / MPG / MPEG（プレイヤー専用。ffmpeg が無いときは灰色表示ですがチェックはできます）。チェックすると、その種類をこのアプリで開くようにします。外すと解除します。すでにこのアプリになっている種類はチェック済みです。OK を待たず、すぐに反映します。動画を関連付けや引数で開いたときは、設定の「プロキシを自動生成しない」がオフ（＝自動生成オン）でもプロキシは作りません。プレイヤーは前面 UI を出さずに起動し、A／T の表示は F8 と共通で覚えます（既定はどちらもオフ。プレイリストからの本再生は開始時オン／再生中はオフ可／次の再生で再びオン）。

表示項目

  • スピーカー定義 …… 有効にする定義のチェック。既定は Stereo だけ。今使っている定義は外しても、切り替えるまで残ります。全部外すことはできません。ステータスバーの SPEAKER も同じ一覧です。
  • プレイリストに載せる書類・動画 …… PDF / MOV / MP4 / AVI / MKV / WebM / MPG を別々にオンオフできます。PDF は既定オン、動画は既定オフ。AVI / MKV / WebM / MPG は ffmpeg が無いとリストに載りません（チェックは灰色でもできます）。オフにした種類はフォルダ追加やドロップで載せません。プレイヤー専用で、エディタには持っていけません。
  • プレイリストの列 …… Wave 用と MP3 用を別々に選べます（その形式で意味のある列だけ。ファイル名はいつも出ます。リストが空のときは列を全部隠します）。WAVE / AIFF だけなら Wave 側、MP3 / M4A だけなら MP3 側です。混ざっているときは、最初は両方の列を合わせます。混ざっているあいだに見出しをドラッグして並べ替えたり、右クリックで出したり隠したりすると、その並びだけ覚え、Wave／MP3 の設定は変えません。Wave／MP3 の設定を変えると、また両方を合わせた並びに戻ります。それぞれ「既定に戻す」があります。Wave の最初の並びはファイル／レート／ビット／Ch／時間／日付／親フォルダ／波形。MP3 はファイル／タイトル／アルバム／アーティスト／作曲／時間／トラック／ディスク／年／ジャンル／日付／コメント／親フォルダ（波形はオフ）。値が無い列は自動で隠し、値が付いたら出します。ジャケットは Wave / AIFF だけなら隠し、MP3 / M4A があれば出します。見出しはドラッグで並べ替え、右クリックでもオンオフできます。
  • 波形表示の幅 …… Wave 用と MP3 用を、それぞれの列チェックの一番下で別々に選べます。S（短）／M（中）／L（長）。Wave / MP3 とも最初は L。M は S の 2 倍、L は 3 倍です。WAVE / AIFF だけのリストは Wave 側、MP3 / M4A だけは MP3 側、混ざっているときは広い方です。「既定に戻す」でもその側の幅を戻します。リストを出したあと、波形の棒は少し遅れて描きます。

オーディオ

  • 既定 Wave フォーマット …… 最初は 48kHz / 24bit / Stereo。新しいファイルに使います。チャンネルは、有効にしたスピーカーと、いつも選べるモノラルです。
  • 自動スピーカー選択 …… 最初はオフ。くわしく
  • スピーカー配置 …… モノラル〜Atmos。ゲーム向けの変則配置も含みます。自分では追加できません。ファイルの中身はチャンネル番号のままです。各スピーカーにチャンネルを割り当てると、そのレーンだけ L / C / LFE などの名前が出ます。最初は 1 から順。変更したあと OK せずに別の配置へ切り替えると、保存するか聞きます。
  • API とデバイス …… WaveOut／WASAPI／ASIO と、使うオーディオ機器。
  • 録音／再生ポートと Ch …… スピーカー名は配置から、ポート名は機器から来ます。チャンネル番号は録音と再生で共通。「なし」はそのスピーカーを使いません。録音はレベルメーターで確認します。
  • 確認音 …… 再生ポートごとに、Sine −20 dB（ふつう 1 kHz、LFE は 80 Hz）と英語の Voice（LFE には無し）。
  • 左右 2 本だけで再生していて、ポートを決めていないときは、スピーカーの音を左右にまとめます。

プレイヤー

先頭がギャップレス再生（既定オン。何をするかは ギャップレス再生）。続けて左ツリーのルートです。既定はマイミュージック。登録・削除・上から順の並び替えができます。

編集

  • ラウドネスターゲット …… LKFS。
  • 無音しきい値（Silent Skip / 無音削除）…… 最初は -60 dB。-120 から 0。再生の飛ばしと、オン時の録音のゲートと、右クリックの無音部分削除に使います。
  • 横に、割り当てた録音をモノラルにしたレベルメーターがあります。バーはピーク。赤線と数値は谷の平均で、ピークではありません。編集タブでも入力を監視します。
  • スキップ時の無音挿入時間 …… 最初は 500 ms。それ以上の無音は縮めます。0 なら無音は全部捨てます。0 から 10000。再生には使いません。
  • プチノイズ防止フェード …… 最初は 20 ms。1 から 100。リージョン毎のノーマライズ、無音削除、Silent Skip 録音の継ぎ目に使います。
  • フェードカーブ既定。
  • リージョンを付けるかどうかは、録音を始めるときに指定します。

書き出し・パス

  • オーディオ …… LAME パス／LAME オプション／Windows ビットレート（LAME を使わないとき）／同時書き出し本数（既定 Auto＝CPU コア数の 1/4。上限はコア数の 1/2）。
  • ムービー …… FFmpeg パス（利用推奨。プロキシ生成に使う）／プロキシを自動生成しない（既定オフ。関連付け・引数起動の動画では、ここがオフでもプロキシは作りません）／動画プロキシの保存期間／現在の容量／すべて削除（期限を無視して今すぐ全部消す。確認あり）。

Wwise

EXPORT のときの Music Track です。ストリーム再生はいつもオン。Prefetch Length と Look-ahead Time の最初はどちらも 500 ms（0 から 10000）。先頭の区間の Look-ahead は 50 ms 固定です。Prefetch は先頭、Look-ahead は 2 本目以降です。

全体波形

上段

明るい部分が表示中の範囲です。ドラッグで移動し（中央をスクラブ）、ホイールで拡縮します（再生ヘッド基準）。

波形エリア

本編集面

時間ルーラー、マーカー／リージョンフラッグ、再生ヘッド、マウスガイドがあります。トリプルクリックで全選択します。

チャンネル

  • 左端のチャンネル名をクリックでソロ。同じ名前をもう一度で解除。Ctrl＋クリックで追加。Shift＋クリックでミュート／解除。
  • Tab でチャンネルをソロ。繰り返すと次へ。Shift+Tab で逆順。最後の次で解除します。
  • 波形の時間選択は変えません。フェード／音量／ノーマライズ／リバース／ピッチ／タイムストレッチ／コピー／削除などはそのチャンネルだけです。ミュートしたレーンはグレー。再生中でもできます。

フルスクリーン

  • F11 …… 波形エリアをフルスクリーン。タブ・トランスポート・メーター・Tips・WAAPI は隠します。チャンネル名と dB 目盛りも出さず、全体波形とステータスバーは残します。ウィンドウの枠とタスクバーは隠します。ブラウザの F11 と同じです。タイル表示でも同じ。もう一度 F11 で戻します。プレイヤーから移るとき、動画／PDF はファイルごと持ち込まず（音声だけ残すこともない）、選択中の音声ファイルだけ残します。
  • F12 …… タイトルバーだけ隠すフルスクリーン。タブ・トランスポート・メーター・Tips・WAAPI・チャンネル名・dB 目盛りは残します。スペクトラム／ラウドネス／レベルメーター／ベクタースコープは 1.5 倍（Windows の画面の大きさと表示倍率のうえ）。タイル表示でも同じ。もう一度 F12 で戻します。プレイヤーから移るとき、動画／PDF はファイルごと持ち込まず（音声だけ残すこともない）、選択中の音声ファイルだけ残します。

プレイヤーモード

波形エリアで F10。全画面にはしません。もう一度 F10 で戻します。

画面

  • タブは出ません。上段は左にフォルダツリー、中央がファイルリスト。下段は高さが固定の低い波形です。全体波形は出ません。
  • 既定は親フォルダでグループし、グループごとにジャケットを出します。動画／PDF はサムネイルがあれば各行に出します（画像が無いときのプレースホルダは出しません）。再生や曲送りではリストを作り直しません。
  • プレイリストが空のときは列をすべて隠し（表示中から空にしたときは1秒でフェードアウト）、レベルメーター・スペアナ・ラウドネス・ゴニオ／サラウンドメーターを出さず、入ったときは最初から消します。空のときはライブラリ（フォルダツリー）にフォーカスします。
  • F8 で動画専用ミニプレイヤーにします（プレイリスト等の前面 UI は無し。ウィンドウは映像の原寸枠。動画の本再生中かつプレイリストに再生対象があるときだけ。拡張子連動／引数で動画を開いたときは自動で入ります）。
    • Space／Enter で止めると止めた位置で静止します（暗い 1/4 速＋格子のバックグラウンド再生へは落としません。通常のプレイリストでは暗いプレビューへ戻します）。
    • A（波形・アナライザ・ファイル名）／T（タイムコード）の表示は引数起動と共通に覚えます（既定はどちらもオフ。プレイリストからの本再生は開始時オン／再生中はオフ可／次の再生で再びオン）。
    • F 全画面中でも F8 で入れます（全画面を解除してから映像の原寸枠へ）。
    • もう一度 F8 で通常のプレイヤー表示に戻し、再生は続けます。
    • F9／F10 でプレイリストが見えるプレイヤーへ戻します（本再生は止め、暗いプレビューへ）。
    • F11／F12 へ移るとき、動画／PDF はファイルごと持ち込まず（音声だけ残すこともない）、選択中の音声ファイルだけ残します。
  • F9 でプレイリストと波形だけを出します（デスクトップの占有面積を節約したいとき。どのモードからでも）。
    • ライブラリ／お気に入り／トランスポート／ステータスバーは出ません。ピークメーター・ゴニオ／サラウンド・スペアナ・ラウドネスは出します。Alt+S（Silent Skip）と Alt+A（Always on Top）は効きます。
    • もう一度 F9 で通常のエディタへ戻します（再生を止めてから、選択したファイルだけ残し、タブの複数選択は解除）。
    • F10 で通常のプレイヤー表示に戻し、再生は続けます。
  • ウィンドウの位置とサイズは通常モードと別々に覚え、切り替えで戻します。

再生

  • 入ると 1 曲めを選んで再生します（ファイルを指定して起動したときも同じ）。
  • Enter またはトランスポートの再生で先頭から再生し直し、終わったら次へ。Space はその曲だけ再生し、終わったら停止します。
  • 停止中の選択は波形だけ出し、再生はしません。PDF／動画を選ぶと背面に暗いプレビューも出します（動画は暗転＋格子＋無音 1/4 速ループ。PDF は暗転だけ。すりガラスは無し）。曲を追加したときは 1 秒でフェードインし、再生が始まったらすぐ出します。リストが空になったら 1 秒でフェードアウトします。
  • R でランダム再生。一巡まで同じ曲を繰り返しません。空でも切替可。既定オフ。プレイヤーを抜けるとオフ。設定には残しません。
  • 再生は音が出せるようになった時点で始めます。波形が全部描き終わるのは待ちません。
  • 続けて聴くときは次の曲を先に用意し、終わったら隙間なくつなぎます。MP3／M4A の頭と尻のごく短い無音は ギャップレス再生（設定のプレイヤー。最初はオン）で減らします。オンでもわずかな隙間は残ることがあります。
  • 設定の「プレイリストに載せる書類・動画」でオンにした種類（PDF / MOV / MP4 / AVI / MKV / WebM / MPG。PDF は既定オン、動画は既定オフ。AVI / MKV / WebM / MPG は ffmpeg があるときだけ）がリストに載ります。動画は音楽と同じく連続再生と単独再生ができます。音声はアナライザー（レベル／スペクトラム／ラウドネス）へ通します。波形も出します。MOV / MP4 / AVI はコーデックを調べ、MJPEG / Photo JPEG ならそのまま、それ以外（ProRes など）と MKV / WebM / MPG は ffmpeg で再生用プロキシを作ってから再生します（生成中はすりガラスで進捗。Esc で中断。ffmpeg は同梱せず、設定の「書き出し・パス」の ffmpeg.exe を使います。空欄や無効ならプロキシは作らず原ファイルの再生を試みます（エラーは出しません）。関連付けや引数で動画を開いたときも、自動生成がオンでもプロキシは作らず、プレイヤーの前面 UI を出さない状態で起動します。プロキシは元と同じフレームレートの MJPEG（AVI。スクラブ向け）。最後に使ってから設定の日数で消します。既定 7 日）。アプリウィンドウ全体の背面（ジャケットの動的背景より前、リストや波形より後ろ）で再生します。本再生が始まると明るくし、暗転と格子を外します。前面 UI を 0.2 秒で消すのは動画の本再生中と PDF の明るい表示モードのときだけで、暗い選択プレビューでは消しません。動画の本再生中は波形とレベルメーター／スペアナ／ゴニオ／サラウンド／ラウドネスは表示したままです。上中央に再生位置と長さの時刻を大きく出します（範囲選択中は次の行に始点と終点。2 行分の高さを常に確保します）。下中央に再生中のファイル名を出します。プレイリストからの動画本再生では A／T は開始時オンで、再生中はオフにできます（次の再生や別動画へ移ると再びオン。F8／引数起動の記憶とは別）。F8／引数起動の動画ミニでは A で波形・アナライザ・ファイル名をフェードで出す／消します（タイムコードは含まない）。T でタイムコード（選択範囲）の表示をトグルし、オンオフを覚えます（既定オフ）。PDF 表示中は A／T の表示は出さず、状態も変えません（次の音声／動画で覚えている状態を使います）。F はブラウザの F11 と同じ全画面です（動画／PDF の表示中。暗いプレビューでも可。もう一度 F で戻します。再生停止などでは勝手に解除しません）。PDF の明るい表示モードでも前面 UI を隠します（Enter／Space で暗いプレビューへ戻る）。B で今のページを暗くして静止背景へ固定し、すぐ表示を抜けます（暗いプレビュー中でも可。音楽や動画の背面に残す。ドリフトなし。もう一度 B で元の動的背景へ。エディタへ移ると破棄）。Silent Skip がオンでも動画再生中は無視します（チェックボックスは変えません）。止めると先頭へ戻さず、真っ黒にもせず、止めた位置のまま暗転へ短くフェードして格子を出し、無音の 1/4 速プレビューへ移します。前面 UI は 0.2 秒で戻します。ほかの曲を再生するとこのレイヤーを隠して動的背景を出します。シークや 5 秒送りは波形と同じです。PDF も連続再生の対象で、当たったら明るい表示にして停止します（タイムラインが無いため）。明るい表示モード中は ←／→ と PageUp／PageDown でページめくり、Home／End で先頭／最終ページ。+／-（テンキー可）で拡縮（100% は画面に全体が収まる倍率から 300% まで。幅いっぱいまたは高さいっぱいで一旦止まり、離して押し直すとさらに拡大。ほかのファイルへ移ると拡大率は忘れます）。このあいだ ↑／↓ で前後のファイルへ移れます（本再生のつなぎではプレイリストを出しません）。ほかのプレイリスト操作は表示を抜けるまで使えません。動画も PDF もプレイヤー専用で、エディタへは持っていけません。
  • 左右キーの早送り／巻き戻しはしません。テンキーはどのペインからでも（NumLock オン）使えます。
    • 0 …… 再生／一時停止
    • 1 …… 早戻し、3 …… 早送り（推移中は -4 dB）
    • 4 …… 前の曲、5 …… 再生し直し、6 …… 次の曲
    • 7／9 …… 5 秒戻し／送り（0.75 秒クロスフェード。押しっぱなしは少し待ってから繰り返す）
  • キーボード上段の 0–9 は割合ジャンプのままです。

リストとフォーカス

  • ↑↓ でファイル選択。Home／End でリストの先頭／末尾。PageUp／PageDown でページ送り（複数選択可。再生中はキーを離すとその曲へ。停止中は選択だけ）。
  • F1 または Ctrl+←／Ctrl+↑ でツリー、F2 または Ctrl+↓ でお気に入り、F3 または Ctrl+→ でプレイリストにフォーカス。
  • F5 でフォルダツリーを更新し、フォーカスもツリーへ移します（ディスク上の追加・削除を取り込み直す。展開と選択はできるだけ残す。プレイリスト／お気に入り／波形フォーカスでも効く）。
  • Tab でツリー→お気に入り→プレイリスト（Shift+Tab は逆）。フォーカス中は上端に明るいグラデーションが出ます。
  • Ctrl+F で今選んでいるライブラリ／プレイリストを検索します。空白区切りは全部含む、| はどれか含む。Enter で決定して元の場所へ戻り、Esc は入力を取り消します。

ライブラリ

  • 開いたファイルはリストへ載せるだけで、全部の波形を一度に読みません。曲名や時間などの情報は載せるときに読み、列へ出します。出す列は設定の表示項目で Wave／MP3 別に選び、見出しの並びも覚えます。空のときは列を全部隠し、値が無い列は自動で隠します。波形の幅も同じ表示項目です。
  • 左のツリーは既定でマイミュージック。選んだ場所・展開状況と、お気に入りとの仕切り位置を覚えます。
  • 区切りとスクロールバーは近づけると出し、マウスが約 3 秒止まると消します。フォルダを選んでもリストへは自動で載せません。
  • ツリーの * は選択フォルダ以下を全展開、/ で閉じます。
  • ツリーにフォーカスがあるとき、フォルダ名の先頭を打つとそのフォルダへジャンプします。続けて打つと絞り込み、約 1 秒空くと打ち直しです。プレイリストには載せません。
  • ツリーの Enter はプレイリストを空にして、そのフォルダの中の対応ファイルを載せます。検索中は見えているフォルダだけです。ファイル名がヒットしたときはそのファイルだけ、フォルダ名がヒットしたときはそのフォルダの中すべて。中のフォルダから順に載せ、最初に載った曲から再生します。
  • Shift+Enter とダブルクリック、リストへのフォルダドロップは配下ごと追加します。

波形

シークと選択だけです。右クリックもメニューキー／Shift+F10 も出さず、マーカー／リージョン／ループも出しません。範囲は反転して半透明です。拡大しません。画面用の波形だけ作り、短いファイルは粗くしません。スペクトラムやラウドネスの曲線表示には切り替えません。編集は使えず、メニューは灰色になります。

ジャケットと背景

  • ジャケット／サムネイルは実画像があるときだけ出します（動画・PDF のサムネ含む）。無い行は空白で、プレースホルダ画像は出しません。プレイリストに1枚も無ければ枠ごと隠します。
  • ジャケット枠へ画像ドロップで差し替えできるのは MP3 のみ（ファイルへ書き込み）。WAVE / AIFF / M4A は差し替えできません。
  • ジャケットがあるときはウィンドウ全体の背景に、縦横比を崩してエリアいっぱいに置いてから大きくぼかして使います（トランスポート・メーター・ステータスバーも含む）。

入り方と抜け方

  • 起動時に指定したファイルに mp3／m4a が 1 つでも混ざるとプレイヤーで起動し、それらのファイルをリストへ載せます。このモードでは、たくさん開くときの半透明の画面は出ません。
  • WAAPI は無効です。入る前にオンなら、抜けたときに戻します。他モードのファイルはリストへ引き継ぎます。
  • 抜けるときは再生を止めてから、選択したファイルだけ残し、タブの複数選択を解除します。プレイヤーのまま終了したときは、読み込んだファイルは覚えません。

読み込み中の表示

  • 1 件の読み込みに時間がかかるときは、中央に Now Loading ... を出します。
  • 2 件以上は半透明の画面を乗せ、全体と各ファイルの進捗を出します。Esc で中断でき、読み込み済みは残します。

時間スクロールバー

波形の下

表示範囲を左右に動かします。

タブ

1 ファイルでも表示します。

  • 閉じるは Ctrl+W。アプリ終了は Ctrl+Q。
  • 誤って閉じたタブは Ctrl+Shift+T で開き直せます（今の起動で閉じたもの。複数可）。
  • Ctrl+Shift+W でもすべてのタブを閉じられます。複数タブを閉じるとき、未保存が 2 件以上なら「すべて保存して閉じる」「すべて保存せずに閉じる」も選べます。

右クリック

  • 「このタブを閉じる(S)」「このタブ以外を閉じる(O)」「このタブを含め右側を全部閉じる(R)」「このタブを含め左側を全部閉じる(L)」「すべてのタブを閉じる(W)」
  • 「ファイル名を変更(N)」（F2、またはタブ／タイルの帯のファイル名ダブルクリックでも）
  • 「ファイルを複製(U)」（Ctrl+Shift+D）、「ファイルを削除(D)」
  • 「全部のタブを選択する(A)」「閉じたタブを再開(T)」
  • 「すべてのファイルの時間を表示(I)」（表ウィンドウ。コピー／セル範囲コピー／CSV・PDF。複数タブ選択中は「選択ファイルの時間を表示(I)」になり、選択したファイルだけ）
  • 「タブのまま(B)」「左右に並べる(1)」「上下に並べる(2)」「上下左右に並べる(3)」（タイル表示。2 タブ以上。波形エリアに収まらない配置は選べません。チェックが今の配置）
  • 「Wave で書き出す(E)」「MP3 で書き出す(M)」「マーカーでセパレートして書き出す(K)」「リージョンでセパレートして書き出す(G)」「チャンネルごとに書き出す(C)」

波形の右クリックには「タブ」カテゴリがあり、閉じる系／バウンス／全選択／再開／時間／タイル配置はタブメニューと同じ文言・同じアクセスキーです（対象はアクティブなタブ）。これに加えて「すべてのタブを Wave / MP3 で保存」（常に全タブ向け。タブ右クリックで全選択したときの「選択ファイルを〜で保存」とは別）と「次のタブ(N)／前のタブ(V)」があります。リネーム・複製・削除は波形 → ファイル、書き出し・セパレートは波形 → 書き出しにあります。

バウンス

2 つ以上のタブを選択すると「選択ファイルをバウンス(J)」で、波形を重ねて合成した新しい Wave を作り、選択の右隣のタブで開きます。Ctrl+Shift+B でも同じです。

  • 長さはいちばん長いタブ。フォーマットは左端の選択タブ。
  • マーカーとリージョンは位置そのままで引き継ぎ、同じ位置で同じコメントのマーカーは 1 つにまとめます。
  • 先に保存ダイアログで保存先と名前を指定します。既定名は Bounce.wav。初期フォルダはファイルを持つ最初の選択タブ、無ければ前回の書き出し先です。

書き出し

  • 今の編集内容を別ファイルへ出します（未保存のままで可）。1 件は保存ダイアログ、複数はフォルダを選びます。
  • 既存ファイルは上書き確認です。はい＝上書き、いいえ＝それらをスキップ、キャンセル＝中止。多いときは件数と先頭だけ出します。
  • セパレートはフォルダを選びます。マーカーは区間が 2 つ以上、リージョンは 1 本以上あるタブだけ出します（足りないタブは飛ばす）。名前は元名に _1（10 個以上なら _01 のように桁を合わせる）。
  • チャンネルごとは、今のスピーカー配置と Ch 割り当てで Wave を出します（ファイルのチャンネル順や名前は見ない。割り当てが無いスピーカーは出さない）。名前は元名に _L / _C / _LFE など配置のラベルを付け、フォルダを選びます。
  • 複数書き出しの名前は元ファイル名（未保存はタブ名）で、同じ名前が重なれば 2 から番号を付けます。前回の書き出しフォルダを覚えます（開くとは別）。
  • 実行中は半透明の画面で操作を止め、全体と並列中の曲すべてのプログレスバーを出します（多いときは列を増やす）。
  • Ctrl+Shift+Alt+M で全タブを MP3 で保存します（波形右クリック → タブ。今のタブは開いたまま。Wave の一括保存にキーはありません）。

複数選択

  • Ctrl+クリックで個別追加、Shift+クリックで範囲選択。タブバーまたはタイルのファイル名の帯の上の Ctrl+A で全選択できます。選択中のタブとタイルの帯はハイライトされ、Esc で解除します。
  • Ctrl+Shift+A は、ポインタの位置やタイル表示かどうかに関係なく全タブを選択します。タイル表示の検索フィルター中は、検索でヒットしたタブだけを選択します。タイル表示でも帯で同じ複数選択ができます。
  • 選択中の右クリックは、以外／右／左を残したまま次の名前になります。「選択した（すべての）タブを閉じる」「選択ファイルをバウンス」「選択ファイルを複製」「選択ファイルを削除」「選択した（すべての）タブにペーストする」「選択したタブを Wave / MP3 で書き出す」「選択したタブをマーカー／リージョンでセパレートして書き出す」「選択したタブをチャンネルごとに書き出す」。全タブ選択時はいずれも「選択ファイルを〜」表記で、Wave / MP3 は「選択ファイルを〜で保存」です。
  • Ctrl+V で、コピーした編集履歴を選択タブへ一括適用できます。適用中は半透明の画面で操作を止め、全体と各タブの進捗を出します。

幅が足りないとき

タブが増えてバーに収まらないときは、先にアクティブ以外を縮めます。タイトルが 6 文字を切るまで縮めても足りなければ、左右の ＜＞ で送ります。

タイル表示

複数のタブを 1 画面に並べて聴き比べられます。

並べ方

  • Ctrl+T で左右→上下→上下左右→解除の順に巡回します。ファイル数によって見た目が同じになる配置、波形エリアに収まらない配置は飛ばします。左右・上下が収まらなければ格子を試し、格子も無理なら動きません。
  • 波形の右クリック → タブ、またはタブの右クリックの「タブのまま(B)／左右に並べる(1)／上下に並べる(2)／上下左右に並べる(3)」で直接指定もできます。2 タブ以上。収まらない配置は選べません。チェックが今の配置です。
  • 並べるときは、いま表示しているタブの解析モード（波形／スペクトログラム／重ね／ラウドネス）に全タブを揃えます。
  • 再生中に配置を切り替えても音は止まりません。タイル中に閉じたタブは並びから外れ、1 つになると通常表示へ戻ります。
  • ウィンドウを狭くして今の左右・上下が収まらなくなると格子を試し、格子も無理ならタブ表示へ戻します。
  • 設定の一般タブ「複数ファイル」で、2 つ以上のファイルを開いたあとに自動で並べる既定配置を選べます（既定はタブのまま。左右・上下が収まらなければ格子を試し、格子も無理なら並べません）。
  • 終了時の配置は覚え、複数タブが復元されたときに次回起動でも戻します（収まらなければ格子、格子も無理なら戻しません）。

選択

  • タイルをクリックまたは再生するとアクティブが替わり、ファイル名の帯が青くなり、シアンの再生ヘッドもアクティブだけ出ます（非アクティブの帯は塗りなし）。
  • 帯の Ctrl＋クリック／Shift＋クリックはタブと同じ複数選択。Ctrl+A を帯の上で押すと全タブ選択。選んだ帯もアクティブと同じハイライトです。
  • ファイル名の帯を右クリックすると、タブと同じメニューが出ます。

検索

Ctrl+F でタブ名の検索（絞り込み）ができます。波形エリア中央に検索ボックスが出て（「全部含む／どれか含む」の書き方もボックス内に表示）、1 文字入れるたびにすぐ絞り込みます。ヒットしないタイルは暗くなり、半透明の画面で覆われます。

  • 空白区切りは AND、| 区切りは OR です（例: bgm loop|se ＝ bgm と loop の両方を含む、または se を含む。大文字小文字は区別しません）。
  • Enter で条件を確定して検索ボックスを閉じます。フィルターは残ります。もう一度 Ctrl+F を押すと、同じ条件から編集できます。
  • Esc は、開いた時点の文字列に戻して閉じるキャンセルです。解除するには検索文字を空欄にします。
  • Alt+Enter でヒット以外を閉じます。未保存の編集があるタブは残し、確認は出さず、フィルターは解除します。
  • Ctrl+Shift+F は、検索ワードが入っているときだけ、ボックスを出さずに検索ワードを空にして確定します（フィルターの即解除）。
  • 覆われたタイルは操作できません。クリックしてもアクティブにならず、Ctrl+Tab／Ctrl+PageUp・PageDown の切り替えでも飛ばされます。
  • 文字を変えて絞り込むと、ヒットした先頭（タブの並び順。タイルの左上から）の波形をアクティブにします。すでにそのファイルならそのままです。ヒットが無いときはアクティブを変えません。検索文字を空にして解除したときも、アクティブは移しません。
  • 検索の確定でタブが選択されることはありません。検索文字を変えたり確定したりすると、残っていたタブの複数選択は解除されます。選択はフィルター中の Ctrl+Shift+A で明示的に行い、検索でヒットしたタブだけを全選択します。
  • 絞り込み中にバウンスや複製で増えた新しいタブがヒットしない名前の場合は、手前に出さず、暗いまま加わります。タイル表示をやめると検索もリセットされます。

Silent Skip

ステータスバーの SPEAKER の左、Alt+S。既定オフ。

  • 再生中に無音区間を飛ばし、録音中はしきい値を超えたときだけ書き込みます。
  • 書き込んだ可聴の前後には、プチノイズだけを消す短いフェードをかけます（設定の編集タブ。既定 20 ms）。
  • 再生中の ←／→ 早送り／巻き戻し中は飛ばしません。
  • しきい値を下回った時点から無音を書き、設定の長さで止めます。音が戻ったときにまとめて挟みません。録音専用です。既定 500 ms。再生には使いません。
  • 録音開始時は毎回、Silent Skip をオンにするか確認します。チェックの初期値はステータスバー。OK するとステータスバーにも反映し、キャンセルは変えません。確認文にしきい値と無音の尺が出ます。設定から変更できます。
  • オンのときだけ「録音部分にリージョンを付加」を選べます（オフでは選べない）。付けると、無音を pad まで挟んだときの前後の録音へ付けます。無音には付けません。波形の短い谷では分けず、続きの録音は新しい区間だけです。既定オフ。状態は覚えます。リージョン付加は録音開始時に指定します。
  • しきい値とスキップ時の無音挿入時間は設定の編集タブです（しきい値の既定 -60 dB）。同じしきい値で、波形の右クリック → 編集 → 無音部分を削除もできます。

ギャップレス再生

設定 → プレイヤーの先頭。最初はオン。

もともと途切れない曲を、ファイルをまたいでつながったまま聴きたいときの設定です。ライブやクラシックを曲ごとに MP3／M4A にすると、頭と尻にごく短い無音が付いて、途切れ途切れに聞こえることがあります。オンのときは、その無音を外して次の曲へつなぎます。静かなところを全部飛ばす機能ではありません（それは Silent Skip です）。

  • 無音の長さが分からないファイル（古い作り方や、Windows で作った MP3 など）はそのまま再生します。
  • 情報と実際が違うと、曲の頭や尻が数十ミリ秒だけ欠けることがあります。すでに無音が外れているときは、もう一度切りません。
  • 取り込みのときに曲のあいだへ入れた長い無音（2 秒など）は、この設定では消えません。
  • オンでも、ほんの少し隙間が残ることがあります。CD とまったく同じつながりになるとは限りません。
  • オフにすると、頭と尻の無音も含めてそのまま再生します。波形の長さの表示はどちらでも変わりません。

Always on Top

Silent Skip の右、SPEAKER の左

ウィンドウを最前面に固定します。Alt+A で切り替えます。

スペクトラム／ラウドネス／レベルメーター／ベクタースコープ

再生出力の表示です。

ラウドネス

スペクトラムの左に出ます。Short Term / Integrated / Momentary Max、Loudness Range、True Peak。ターゲット LKFS は設定です。青＝余裕、橙＝接近、赤＝超過。

  • 再生中は出力のリアルタイム計測で、数値が色づきます。
  • 停止中は波形全体のオフライン解析です。Short Term はファイル内の最大。色が数値の塗りになり、文字は通常色です。音量などの編集後は測り直します。
  • ラウドネスの左に編集履歴の一覧があります。収まる分だけ出し、古いものは切れます。クリックで U の編集履歴。ここからは選べません。

スペクトラムとチャンネル色

  • スペクトラムは、すべてのチャンネルをまとめた帯域の表示です。
  • 波形のチャンネル名は、スピーカーに割り当てた Ch のレーンだけ配置の名前（L / C / LFE など）です。割り当てのないレーンは 1 からの番号。初期値は 1 から順です。
  • 3ch 以上では、名前は白文字で、角丸バッジの塗りがよくある登場順（Atmos 9.1.6 の 16 色）です。波形も同じ色で薄く染めます。レベルメーターのバーも同じ色です。

2ch 以下

シアングラデです。内側 2 本が Peak（上の赤ランプがクリップ）、外側 2 本が RMS（どちらもホールド線）。下の数値は Peak 行／RMS 行です。メーターにチャンネル名は出しません。

3ch 以上

  • ベクタースコープの代わりにサラウンドの絵になり、同じ割り当てで配置の位置を使います（ファイルから名前は当てません）。
  • エネルギーは波形と同じチャンネル色です。大きさはチャンネルのレベル、輪郭の凹凸はそのチャンネルの直近の波形です（先端が今、裾が少し前）。
  • 全体の広がりをひとつのダークグレーの細線で囲みます。枠はピークを少し持ってからゆっくり戻ります。
  • レベルメーターはチャンネルごとの Peak バーに、Peak ホールドと緩やかな RMS ホールドを載せます。

幅と表示の切り替え

  • 列の左端をドラッグすると幅を広げられます。既定が最小で、バーが最大の太さになるところで止まります。広げた幅は次の起動でも覚えます。
  • 停止後、表示はゆっくり消えます。レベルメーター上の WAAPI でバーの表示を切り替えます。

Tips

WAAPI バーの上。高さ固定。

  • コントロールにマウスを置くと説明が出ます。はみ出したらスクロールします。すぐ出ます。別の項目へ移ると、少し待ってから差し替えます。
  • 見出しまたは本文をクリックでロックします（枠がシアン、Tips (Locked)）。もう一度クリックで解除。ロック中とパネル上では内容が変わりません。
  • トランスポートのボタンだけ、短いツールチップ（ショートカット付き。折り返し、切り詰めなし）も出ます。他のコントロールにホバー用ツールチップはありません。

WAAPI バー

接続状態、作成先、Play -E、Auto Active、EXPORT があります。

プロジェクト名をクリック、または Alt+Ctrl+Shift+W で Wwise を開く／前面に出します。WAAPI がオフでもバーを出してから起動します。覚えたプロジェクトが無ければバーの表示までとし、起動できない旨を出します。

ステータスバー

  • ファイル位置 …… 2 ファイル以上開いているときは、冒頭に 1 / 10 Files のように何番目／全数を表示します。
  • ファイル情報 …… サンプリングレートなど（名前はタブ側）。レート／ビット深度／チャンネルを変換すると、該当項目が保存まで赤になります。MP3／M4A はビットレートも表示します。容量は MB（MiB / B）。変換や範囲削除で変わると推測サイズが赤になります。
  • Silent Skip と Always on Top …… NOW POS の左。Silent Skip は Alt+S。Always on Top は Alt+A。無音を飛ばして再生し、録音ではしきい値超だけ書きます。しきい値は設定です。
  • SPEAKER …… その右でスピーカー配置を切り替えます。一覧は表示項目タブと同じです。今使っている定義は外しても、切り替えるまで残ります。自動スピーカー選択がオンなら、ファイルの本数に合う定義へ切り替えます。既定オフ。
  • 時間 …… 現在時間／選択開始／選択範囲／選択終了／トータル。トータル以外は入力・ホイール／↑↓で調整します。時間は 1 秒／Shift 10 秒／Ctrl 1 分／Ctrl+Shift 10 分、サンプルは 1／Shift 10／Ctrl 100／Ctrl+Shift 1000。右クリックで時間とサンプル数を切り替えます。

選んだタブの音を重ねて、新しい Wave を作ります。プラグインやエフェクトは通りません。速い代わりに、大きい音を重ねると割れやすいので、重ねる前に音量を下げるか、できたあとにピークを確認してください。長さが違うファイルは揃えてから重ねます。

4. 再生

  • Space …… 再生／停止。停止すると、音楽は開始位置へ戻します。動画は先頭へ戻さず、止めた位置から暗い 1/4 速＋格子のバックグラウンド再生へ戻します。プレイヤーモードでは選択曲だけ再生し、終わったら停止します（連続再生しません）。PDF の明るい表示モード中は暗いプレビューへ戻ります。
  • Enter …… その場停止。プレイヤーのリストでは先頭から再生し直し、終わったら次の曲へ進みます（再生中は止めます。動画は暗いプレビューへ。トランスポートの再生も同じ）。
  • ←／→ …… 停止中はシーク（表示の約 1 px。点が見えるときは 1 サンプル）。再生中は押しっぱなしで、ピッチ据え置きの 3 倍早送り／巻き戻し（推移中は -4 dB）。離すと元の速さと音量。その間 Silent Skip は動きません。プレイヤーモードでは左右キーの早送り／巻き戻しはしません（テンキー 1／3）。
  • Ctrl+Space …… 3 秒前から。
  • Alt+Enter …… 再生開始位置からやり直し（タイル検索ボックスにフォーカスがあるときはヒット以外を閉じる）。
  • Alt+S …… Silent Skip。無音区間を飛ばして再生し、録音中はしきい値を超えたときだけ書く（既定オフ。しきい値は設定、既定 -60 dB）。再生中の ←／→ 早送り／巻き戻し中は飛ばしません。録音開始時は毎回、Silent Skip をオンにするか確認します（チェックの初期値はステータスバー。OK すると反映。確認文にしきい値と無音の尺。設定から変更可）。オンのときだけリージョン付加を指定します（既定オフ。前回の指定を初期値にする）。
  • プレイヤーの連続再生は次の曲を先に用意します。MP3／M4A の頭と尻のごく短い無音は ギャップレス再生（設定のプレイヤー。最初はオン）で減らします。オンでもわずかな隙間は残ることがあります。
  • Ctrl+ドラッグ …… つまんで聴く（スクラブ）。すべてのチャンネルを左右にまとめます（レベルメーターも左右だけ動きます）。
  • G …… ステータスバーの NOW POS を入力。Enter で移動。コピー／貼り付け可。右クリックで時間／サンプル数。
  • Z または .（テンキーの . も同じ）…… 中央寄せ。再生中はセンターロックの切替、停止で解除。
  • L …… 選択（無ければサンプルループ／-L）の末尾 3 秒前からループ再生。
  • K …… 範囲メトロノーム。等分マーカー／リージョン位置でメトロノームを鳴らす。ボタンまたは K でオン／オフ（既定オフ。自動ではオンにならない）。波形の右クリック → 再生でも切り替え可。
  • Tab …… チャンネルをソロ。他のレーンはグレーでミュート。繰り返すと次のチャンネルへ。Shift+Tab で逆順。最後の次で解除。左端のチャンネル名をクリックでもソロ（同じ名前をもう一度で解除。Ctrl＋クリックで追加。Shift＋クリックでミュート／解除）。波形の時間選択は変えない。波形操作はそのチャンネルだけ。再生中でも停止中でも可。
  • Ctrl+N …… 新規。空のタブを作る。フォーマットは都度選ぶ（前回を覚える）。チャンネルは表示項目で有効にしたスピーカーと Mono（常に選べる）。
  • Ctrl+R …… 録音。
    • 開始前に毎回、Silent Skip をオンにするか確認します。チェックの初期値はステータスバー。OK すると反映。確認文にしきい値と無音の尺。設定から変更可。オンのときだけリージョン付加を選べます。既定オフ。状態は覚えます。
    • 今開いているファイルのフォーマットで、シークバーの位置から録ります。それ以降の波形は上書きします（Undo で戻せる。take より後ろは残す。take が長ければ伸ばす）。
    • ファイルが無いときは始まりません（先に Ctrl+N または開く）。録音は Wave のままです。MP3 になるのは保存／書き出しのときです。
    • 未保存のまま終了しても作業コピーが残り、開いたままだったタブは再起動で戻ります。閉じてしまったタブは、今の起動のうちなら Ctrl+Shift+T で再開できます。
    • もう一度、または Space / Enter / Esc で停止します。録音中は波形の背景が赤系になり、新しい区間はすぐ粗い波形で出し、少し遅れて通常の描画に整えます。
    • Silent Skip をオンにすると、しきい値を超えたときだけ書き込み、下回った時点から無音を挟んで設定の長さ（既定 500 ms）で止めます。可聴の前後には設定の短いフェード（既定 20 ms）をかけます。リージョンを付けると、停止時に今回書いた可聴／無音それぞれへ付けます。
    • 録音ポート・再生ポート・Ch は、その配置の中で割り当てます（Ch は録音と再生で共通。なしはそのスピーカーを使いません）。
  • 左右 2 本の機器で再生ポートを決めていないときは、スピーカーの音を左右にまとめます。モノラルはポートが 2 つ以上あれば、左右へ同じ音を出します。

5. 選択と編集

ドラッグで選択。ダブルクリックは区間（マーカー間）、トリプルクリックは必ず全選択。Esc または Shift なし移動で解除。未選択のフェード／音量／ピッチ／ノーマライズ／リバース／タイムストレッチは時間方向は全体です。チャンネルソロ中は聞こえているレーンだけが対象です。ステータスバーの選択開始／範囲／終了に値を入れることでも選択できます。

  • FADE IN I／FADE OUT O …… カーブを選び Space で試聴、Enter で実行。1–9 でカーブ。
  • X …… シークバー前後をフェード。シークを境に、今見えている前だけアウト／後ろだけイン（リニア）。
  • V …… ラウドネス曲線を表示して音量。dB を直接入力、または ↑↓／ホイールで 0.1 dB（Shift 1／Ctrl 3／Ctrl+Shift 6）。Space で試聴、Enter で実行。メニューに波形全体の Integrated LKFS／RMS／Peak の変化を先に出します。Short Term 曲線と停止中メーターも同じ dB で追従します。Esc または Shift+V で曲線を閉じます。
  • P …… ピッチ。↑↓／ホイールで半音（Shift または Ctrl で 1 オクターブ）。Space で試聴、Enter で実行。±2 オクターブ。長さを保つのは既定オン（Tab でチェックへ）。オフは再生速度と同じく長さも変わります。実行中は半透明の画面で進捗を出します。
  • T …… タイムストレッチ（ピッチ据え置き）。選択があればその時間、無ければ全体。伸ばした時間と割合（％）が連動。↑↓／ホイール（時間は 1 秒／Shift 10 秒／Ctrl 1 分／Ctrl+Shift 10 分。割合は 0.1／Shift 1／Ctrl 10／Ctrl+Shift 25％）。Tab で時間と割合。Space で試聴、Enter で実行。10–1000％。実行中は半透明の画面。
  • NORMALIZE N …… ピークを -0.1 dB に合わせる。
  • R …… リバース。選択があればその範囲、無ければ全体の波形だけを時間方向に反転。マーカー／リージョン／ループは動かさない。
  • 波形の右クリック → オーディオ → リージョン毎に波形をノーマライズ …… 各リージョンのピークを -0.1 dB に合わせる。先頭と終端に、プチノイズだけを消す短いフェード（設定の編集タブ。既定 20 ms。0 交差）をかける。
  • DELETE …… 選択を詰めて削除。選択中のマーカー／リージョンもまとめて削除。
  • 波形の右クリック → 編集 → 無音部分を削除 …… 選択があればその中、なければ全体の、しきい値より小さいところを詰めて削除します。しきい値は Silent Skip と同じ（設定の編集タブ。最初は -60 dB）。継ぎ目には、プチノイズだけを消す短いフェード（既定 20 ms）をかけます。ファイル全体が無音だけのときは削除しません。
  • Ctrl+X／C／V …… カット・コピー・ペースト（範囲内マーカー含む。選択がリージョンと一致すればリージョンも）。
  • U …… 編集履歴。↑↓ で移動、Enter 確定、Esc キャンセル。背景はサンプルレート変換の候補リストと同じ塗り。ラウドネス左の一覧をクリックしても開きます。
  • 履歴のコピー＆ペースト
    • 履歴内で Ctrl+クリック（Shift+クリックや Shift+↑↓ で範囲、Ctrl+A で全選択）して Ctrl+C。別ファイルで Ctrl+V すると同じ処理を再適用します（履歴を開いていなくても可）。
    • コピーは次に何かをコピーするまで残るので、タブを切り替えて Ctrl+V を繰り返せば複数ファイルへ反映できます。
    • タブを複数選んで一括適用するときや、ピッチなど重い処理のときは、半透明の画面で全体と各タブの進捗を出します。
    • 選択なしの Ctrl+C は現在位置までの全操作です。範囲は再生時間が同じ位置に合わせ、音量をそろえる操作は貼り付け先でやり直します。
    • コピーできないのは「初期状態」だけです（操作ではない。Ctrl+A でも色が付きません）。
  • 履歴を貼っても効かない／意図と違う例
    • 貼り付けは 1 件ずつ試し、適用先に合わないものはスキップします（「3 / 5 件適用しました」）。
    • スキップされる例: 同じ時刻にすでにマーカーがある追加、先方が短くて範囲がはみ出す削除／フェード、無音が無い先への無音削除、すでに同じレート／ビット／ch への変換、先方に無いマーカーへのコメント、MP3 へのリージョン／ループ。
    • ドラッグや ←→ でのマーカー／リージョン／ループ移動と、押しっぱなしの等分は、その時点の配置を丸ごと写します。移動だけをコピーして別テイクへ貼ると、先方のマーカーが置き換わります。追加から移動まで含めてコピーすると意図どおりになりやすいです。
    • 適用先が短いと時間は末尾に寄ります。チャンネルソロ中の編集は同じチャンネル番号だけに効きます。
    • 録音／波形ペーストの履歴は、そのとき入った音そのものを持ちます。波形を Ctrl+C したあとの Ctrl+V は履歴ではなく音声の貼り付けです。
  • 選択ファイルへの一括適用。タブを複数選択（Ctrl＋クリック／Shift＋クリック／Ctrl+Shift+A）していると、次は選択したファイル全部に実行します（それぞれのファイル全体。各ファイルのチャンネルソロを尊重）。
    • 対象: フェードイン／フェードアウト、ノーマライズ、リージョン毎のノーマライズ、音量、ピッチ、タイムストレッチ、リバース、無音部分を削除、サンプルレート／ビット深度／チャンネルの変換、保存（Ctrl+S）、名前を付けて保存（Ctrl+Shift+S）。
    • 右クリックメニューの名前も「選択ファイルをノーマライズ(N)」「選択ファイルを保存(S)／名前を付けて保存(A)」のように変わります。
    • 保存はパスがあるものを上書きし、未保存や AIFF は保存先フォルダへ Wave。名前を付けて保存は保存先フォルダを選び、Wave で書いてタブのパスを付け替えます（書き出しとは違い、保存後のファイルが今のタブになります）。
    • カーブや dB などの試聴はアクティブなファイルで行い、Enter で選択したファイル全部へ適用します。タイムストレッチは割合（％）に換算して各ファイルへかけます。
    • 適用できないファイル（リージョンが無い、無音が無い、すでに同じフォーマットなど）はスキップし、全部スキップならその旨を出します。
    • 実行中は半透明の画面で全体と各ファイルの進捗を出して操作を抑制します。タイル検索フィルターの半透明の画面は解除せず、その上に重なります。
    • 書き出しと履歴ペーストも同様です。波形右クリック → 書き出しの「Wave／MP3 で書き出す」「マーカー／リージョンでセパレート」「チャンネルごとに書き出す」は、タブ選択中「選択したタブを〜」となり、選択タブを一括で書き出します。

  • Ctrl+Z／Ctrl+Y（Ctrl+Shift+Z でもやり直し）…… 元に戻す／やり直す。

6. マーカー／リージョン／ループ

  • M／Ins …… 選択が無ければ再生位置にマーカー。同じフレームには打てない。選択中は開始と終了を置き、両端にマーカーがあればすぐ中央→3 等分→4…と打ち直す（押しっぱなしはマーカー移動と同じ間隔。離すまで 1 つの履歴）。
  • Shift+L …… 選択をサンプルループに（同じ範囲でもう一度で解除）。
  • Shift+R …… 選択をリージョンに。両端にリージョンがあればすぐ 2 等分。同じ範囲で続けて打つと 3…と打ち直す（解除は右クリック／Delete。押しっぱなしは同じ間隔で、離すまで 1 つの履歴）。
  • フラッグをクリックで端を選択。Shift+クリックで範囲、Ctrl+クリックで追加。ドラッグまたは ←→ で移動（Shift で 3 倍）。
  • ダブルクリックでコメント／リージョン名。-A ライム、-L ブルー、-E 赤（書いたときだけ。ループやサンプルループの後ろは自動では赤くしません）。-R はグレー。EXPORT での意味は 9-3。
  • Ctrl+Shift+R …… リネーム。
  • 右クリック、または Ctrl+Del でマーカー削除。すべてのマーカーを削除と、すべてのリージョンを削除はタイムラインにあります。

Wave に保存すると、マーカー・リージョン・ループもファイルへ入ります。MP3 にはリージョンとループを付けられません。マーカーは置けますが、MP3 へ保存しても書きません。

7. スペクトログラム／ラウドネス解析

切り替え

  • A でスペクトログラム／重ね表示を切り替えます。
  • V でラウドネス解析（Short Term 曲線）を出して音量入力を開きます。
  • 抜けるのは Esc、Shift+A、または Shift+V です。今の表示にかかわらず通常の波形へ戻ります。Esc は入力や選択を先に解除します。
  • VIEW のラウドネスボタンは表示だけ切り替えます。
  • L は選択（無ければサンプルループ／-L）の末尾 3 秒前からループ再生です。

ラウドネス曲線

  • Short Term LKFS の曲線です。白い幅は曲線の上下 ±1 LU（1 LU ＝ 1 LKFS の差。メーターの「接近」と同じ）で、半透明です。
  • 波形は Mid 合成のピーク dBFS を線でつなぎ、LKFS と同じ縦軸に載せます（0 dBFS ＝ 目盛の 0）。拡大してサンプルが見えるときは、通常の波形と同じく各サンプルを線でつなぎます。
  • dBFS と LKFS は別物ですが、ピークとラウドネスを同じ高さで比べられます。
  • 背景の帯はメーターと同じ青／橙／赤です（0〜ターゲットが赤、その下 6 LU が橙、さらに下が青）。曲線は原色のシアン／橙／赤で、赤だけ少し太くします。
  • 左目盛は LKFS です（通常の波形では dB）。白い線は設定のターゲットです。

重ね表示

  • スペクトログラムの上に波形の形だけを載せます（半透明のベールはかけません）。
  • -A／-L／-E とループ／リージョンの下塗りは重ねません。フラッグとラインはそのままです。スペクトログラム単体とラウドネス解析でも下塗りは出しません。
  • 重ね波形も Mid 合成の 1 本です。拡大してサンプルが見えるときは、通常の波形と同じく点と線でつなぎます。振幅ズームが 1 のときは中央半分、拡大すると縦いっぱいに伸びます。
  • 色は、いちばん大きいところを基準に見やすく塗ります（音そのものは変えません）。

描き方

  • 暗いところは、明るい部分を潰さない範囲で少し持ち上げて見やすくします。スペクトログラム／重ねでは、左端のバーか Alt+↑／↓ で持ち上げ量を変えられます（押しっぱなしで連続）。
  • 低い音ほど縦に詰めます（100 Hz 以下はほぼ見えません）。上限は 24 kHz です。
  • ファイル全体が画面に収まっているときは、くっきり描きます。
  • 拡大しているときはなめらかに描き、スクロールやズームが重くならないようにします。

8. フォーマット変換

  • S …… サンプリングレート
  • B …… ビット深度
  • C …… ファイルのチャンネル数（Mono／Stereo。スピーカー配置の切替ではない）

プリセットと操作

  • プリセットは 8 / 11.025 / 16 / 22.05 / 32 / 44.1 / 48 / 96 kHz、ビットは 4 / 8 / 16 / 24、チャンネルは Mono / Stereo です。
  • 任意 Hz は 1000–384000 で、↑↓／ホイールで 1Hz（Shift 10／Ctrl 100／Ctrl+Shift 1000）。
  • メニューはカーソルの直下を避けます。項目を選んだ時点で、ステータスの容量が推測サイズに更新されます。
  • 変換中は半透明の画面で操作を止めます。確定した項目は保存まで赤のままです。

元の音から作り直す

  • サンプリングレートとビット深度は、最初に読んだ音（またはフェードなどの編集後の音）から毎回作り直します。48 kHz → 24 kHz のあと 11 kHz にしても、24 kHz 経由ではなく 48 kHz から作り直します。
  • Space で試聴できるのはレートとビットです（チャンネルは Enter のみ。1–2）。
  • 4 bit は聴き比べ用です。Wave に書くビットは 8 / 16 / 24、および元が 32 bit のときはそのままで書けます。4 bit のままでは出さず 16 bit で書きます。変換メニューに 32 はありません。

9. WAAPI EXPORT（Wave 単体）

1 本の Wave の上で、ワンショットとループの区切りを決めて Wwise へ渡します。 あらかじめファイルを分けなくても構いません。EXPORT は元の波形を 1 ファイルのまま Originals へ書き、区間はクリップのトリムで合わせます。Interactive Music のプレイリストを 1 つ作ります。-A / -L / -E は区間と入り口／出口の目印に使い、マーカーは Custom Cue にしません。小節やテンポの管理、複数波形の切り替え、XML のマーカートラックはありません。

フェードや削除などの編集は、渡す前に波形へ確定します。マーカーとサンプルループは、保存するときに Wave へ埋め込みます。

9-1. 手順

  1. Wwise Authoring を起動します。
  2. レベルメーター上の WAAPI をオンにします（W）。
  3. Wwise で作成先オブジェクトを選びます。Keep Target でパスを固定できます。
  4. 書き出し先は接続中プロジェクトの Originals 配下である必要があります。
  5. EXPORT または Ctrl+Shift+E。WAAPI 接続中だけ有効です。
  • Play -E（Alt+E。WAAPI オン時）…… 出口のあとも鳴らします。アプリ内ではループの折り返しでその部分を二重に再生し、再生位置が 2 本になります。EXPORT すると、つなぎのときも出口のあとを鳴らします。
  • Auto Active …… EXPORT 後に Wwise を前面へ出します。
  • プロジェクト名 …… クリック、または Alt+Ctrl+Shift+W で Wwise を開く／前面に出します。WAAPI がオフでもバーを出してから起動します。覚えたプロジェクトが無ければ起動せず、その旨を出します。

9-2. リージョンの組み立て

上にあるものほど優先します。

  1. サンプルループ（Wave に付いているループ、または Shift+L）…… ループ前が Intro、ループが -L。後ろに余りがあれば EXPORT では -E（波形は赤くしない）。マーカーより優先します。
  2. 末尾が -A／-L／-E のマーカー…… その位置から次の同じ種類のマーカー（無ければ終端）までが区間になります。名前のないマーカーや、末尾が付いていない名前付きマーカーは区間を切りません。EXPORT では -L の直後で末尾が無いマーカーを -E として扱います（波形上の文字は変えず、赤にもしません。-A／-L／-E／-R は上書きしません）。
  3. 末尾の無いマーカーがちょうど 2 点…… その間をループとして扱います。
  4. リージョン（Shift+R）…… 特殊マーカーもサンプルループも無いとき、名前付き区間をそのまま通します。
  5. どれも無ければ、ファイル全体を 1 区間として渡します。

9-3. 名前の末尾

末尾意味
-Lループ。プレビューでループし、Wwise では無限ループの Music Segment になります。
-EExit Cue 以降（余韻）。直前の -L と同じ Music Segment に束ね、遷移時に次と重なって鳴らせます。
-AEntry Cue 前（アウフタクト）。次の区間と同じ Music Segment に束ねます。
-R別の取り込みツール向けの印です。このアプリでは使いません。

マーカーは Wwise の Custom Cue にはしません。-A / -L / -E は区間と入り口／出口にだけ使います。

9-4. Wwise に作られるもの

  • 音楽プレイリストを 1 つ（名前はファイル名）。中は順番再生で、各区間が 1 項目です。
  • 音楽セグメント。1 区間ならファイル名のまま、複数なら _a／_b…。ループ区間は無限ループです。-A と -E は隣の区間と同じセグメントに入り、入り口／出口だけがずれます。マーカーは Custom Cue にしません。
  • 元の波形は分割せず 1 本の WAV。各クリップは同じファイルを指し、始まりと終わりのトリムで区間を合わせます。
  • 先頭の区間は遅延を小さくし、先読みは設定の Wwise タブ（最初は 500 ms）。2 本目以降も同じタブの値です。ストリーム再生はいつもオンです。
  • テンポ 120、4/4 を上書きします（小節管理はしません）。
  • Play -E オンのとき、プレイリストの既定ルールで出口のあとも鳴らします。

同名の Container があれば中身を置き換えます。Originals に同名 WAV があれば確認なしで上書きします。最終確認は必ず Wwise 上で行ってください。

11. 設定と言語

設定は左上の歯車、または Ctrl+Shift+O です。タブは一般／表示項目／オーディオ／プレイヤー／編集／書き出し・パス／Wwise。各項目の内容は 画面の見方 → 設定 にあります。Esc で閉じます。

  • 表示言語は一般タブです。最初は Auto（パソコンが日本語なら Japanese、それ以外は English）。日本語の画面でも、ボタン名などに英語が残ることがあります。
  • マニュアルは画面の ?、またはブラウザで開きます。表示言語に合わせて日本語／英語になります。
  • 設定や、開いていたタブは、このパソコンのユーザー用フォルダ（%LocalAppData%\MGA\MGA Sonic Anvil\）に残ります。アプリの横には書きません。
  • MP3 は、設定で LAME の場所が正しければそれを使い、空欄や無効なら Windows で書き出します（128〜320 kbps。最初は 192）。今聴いている左右 2 本にまとめた音になります（くわしく）。書き出した MP3 は今のタブへは開きません。LAME はこのアプリには入っていません。
  • アプリを閉じると、開いていたタブとウィンドウの位置を覚えます。プレイヤーとふつうの画面は別々です。保存していない編集も残し、次に起動したときに戻します。プレイヤーのまま終了したときは、リストの曲は覚えません。
  • 同時に起動できるのは 1 つです。2 回目は今のウィンドウを前面にし、渡したファイルを開きます（mp3／m4a が混ざるとプレイヤー）。
  • 起動時に、新しい版があれば知らせます。はい＝案内ページを開く（自動ではダウンロードしません）。いいえ＝その版では再通知しません。ネットが無いときはそのまま続けます。

11-1. 自動スピーカー選択

設定のオーディオタブ、既定 Wave フォーマットの下です。最初はオフです。オンにすると、今のファイルのチャンネル数に合わせて、有効にした配置へ切り替えます。ファイルを開く、タブを前面にする、新規、チャンネル数の変換のときに動きます。ファイルの種類名から 5.1 などを当てるのではなく、本数だけを見ます。

  • 便利なとき …… 1〜2 本は Stereo。6 本なら有効な配置のうち 5.1 を選びます。同じ本数が 1 つだけ有効ならそれを使います。Stereo だけ有効なら、6 本のファイルでも何も変わりません。
  • 注意 …… 今の配置がすでに同じ本数なら維持します。切替は再生と録音を止め、その配置の機器に載せ替えます。Stereo をヘッドホン、5.1 を別の機器にしていると、タブを変えるたびに出力先が飛びます。6 本を Stereo のまままとめて聴きたいときはオフにしてください。

11-2. MP3 のダウンミックス

MP3 に保存／書き出すとき、今聴いている配置の音を左右 2 本にまとめます。ファイルのチャンネル番号の順ではありません。Wave 書き出しはチャンネル数を変えません。確認は出しません。

スピーカー順行き先混ぜ方
1 本目Lそのまま
2 本目Rそのまま
3 本目L と R少し小さめ（センター扱い）
4 本目L と R少し小さめ（LFE も足す）
5〜8 本目奇数は L、偶数は R少し小さめ
9 本目以降奇数は L、偶数は Rさらに小さめ

5.1（L / R / C / LFE / Ls / Rs）と同じ並びです。Atmos の上のスピーカーや、特殊な並びのファイルは、意図しないバランスになることがあります。

12. 対応範囲と位置づけ

  • Wwise の Interactive Music でできることをすべてカバーするものではありません。EXPORT は 1 本の Wave（マーカー／サンプルループ）に限っています。
  • アプリ内のプレビューは目安です。最終確認は EXPORT のあと、Wwise 上で行ってください。
  • AIFF では書き出せません。Wave または MP3 を選んでください。Wave に書くビットは 8 / 16 / 24、および元が 32 bit のときはそのままです（4 bit は試聴用で、保存時は 16 bit）。
  • チャンネルが多い MP3 は、今聴いている左右 2 本にまとめた音です。
  • EXPORT は Wwise のプロジェクトを変更します。実行前にバックアップをおすすめします。
