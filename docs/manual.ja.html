MGA Sonic Anvil マニュアル

ゲーム向け波形を、聴いて切って、マーカーとループを置いて、Wwise へ Wave 単体で渡す。

このマニュアルは AI で書いています。説明が多すぎたり、わかりにくいところがあるかもしれません。先にお詫びします。機能の更新が落ち着いたら、読みやすく整える予定です。

1. このアプリでできること

波形エディタと、Wwise Interactive Music への Wave 単体 EXPORT をひとつにしたものです。

フェード・ノーマライズ・部分削除・コピー／ペースト、マーカー／リージョン／サンプルループ、スペクトログラムまで、聴きながら決めて焼き込めます。

Wwise へは Wave 単体モードで渡せます。 元波形を Originals へ書き、Music Playlist Container（-A / -L / -E とサンプルループ。Custom Cue にはしない）として取り込みます。

開いた波形は Wave / MP3 に保存できます。タブの右クリックで、今の編集内容を Wave / MP3 として書き出せます。

Ctrl+N で新規ファイルを作るか、ファイルを開いてから Ctrl+R で録音できます。開始前に毎回 Silent Skip をオンにするか確認します。録音は今開いているファイルのフォーマットで、シークバーの位置から上書きします（Undo で戻せます）。ファイルが無いときは始まりません。

録音は常に PCM で持ち、MP3 は保存／書き出しのときだけです。未保存のまま終了しても、開いたままだったタブは再起動で戻ります。閉じたタブは、今の起動のうちなら Ctrl+Shift+T で開き直せます。

スピーカー配置（モノラル〜Atmos）と Ch の割り当ては、設定とステータスバーの SPEAKER で切り替えます。

2. クイックスタート

  1. Wave / AIFF / MP3 をドロップするか、Ctrl+O で開きます。

    • M4A はプレイヤー専用。複数可。タブで並びます。
    • フォルダをドロップすると、中の対応ファイルを再帰的に追加し、非対応の拡張子は無視します。
    • 複数のときはステータスバーに進捗が出ます。Esc で中断でき、読み込み済みは残します。
    • 開くダイアログは前回の開くフォルダを覚えます。保存／書き出し先とは別です。

    Ctrl+N で空のタブを作れます。フォーマットは都度指定し、前回を覚えます。チャンネルは、有効にしたスピーカーと Mono です。

  2. 波形上で聴きながら切る・フェードする・マーカーやループを置きます。多チャンネルなら、先に設定の表示項目で配置を有効にし、ステータスバーの SPEAKER で選びます。Ctrl+R で録音できます（開始前に Silent Skip をオンにするか確認）。

  3. 必要なら Ctrl+S で Wave または MP3 に保存します（AIFF 書き出しは非対応）。

    • タブを複数選択しているときは、保存も名前を付けて保存（Ctrl+Shift+S）も選択したファイル全部に行います。
    • 保存はパスがあるものを上書きし、未保存や AIFF は保存先フォルダを選んで Wave で書きます。
    • 名前を付けて保存は保存先フォルダを選び、各ファイルを Wave で書いてタブのパスを付け替えます。書き出しとは違い、保存後のファイルが今のタブになります。
    • Ctrl+Shift+M は MP3 専用です。MP3 への書き出しは別名保存のようにファイルを出すだけで、今のタブは開いたままです（書き出した MP3 は読み込みません）。
    • MP3 は 16bit PCM から再エンコードします。3ch 以上、またはスピーカーの Ch を入れ替えているときは、今の配置で聴いている 2ch 畳みと同じ音を書きます（係数。確認は出しません）。
    • 設定で LAME のパスが有効ならそれを使い、空欄または無効なら Windows（既定 192 kbps）です。マーカー等は書きません。
  4. Wwise へ渡すときは、レベルメーター上の WAAPI をオンにし、作成先を選んで EXPORT します。

設定は %LocalAppData%\MGA\MGA Sonic Anvil\ に保存されます。exe 横には書きません。アプリ終了時は開いていたタブと未保存の編集、未保存の録音、編集履歴（戻せる操作）もここに残します。プレイヤーモードのまま終了したときは、読み込んだファイルは残しません。閉じたタブの再開（Ctrl+Shift+T）は今の起動で閉じたものだけです。終了すると忘れます。

アプリの配色を調整します（ダーク固定。ライト切替はありません）。初回はアプリの中央に開き、位置とサイズを覚えます。

設定

左上の歯車、Ctrl+Shift+O

  • 設定・新規・保存確認などのダイアログでは Tab でボタンへも移動できます。
  • Ctrl+Tab で次のタブ、Ctrl+Shift+Tab で前のタブ。Esc で閉じます。
  • 幅はオーディオタブの内容に合わせます。タブは一般／表示項目／オーディオ／プレイヤー／編集／書き出し／Wwise です。

一般

  • 表示言語 …… Auto／Japanese／English。Auto は OS が日本語なら Japanese、それ以外は English。
  • 表示倍率 …… 100〜200%。OS の DPI に加えて拡大します。縮小はありません。作用するのはメインウィンドウのみで、右クリックメニューや設定などの別ウィンドウ、編集履歴は等倍のままです。コンボを変えた瞬間に反映し、キャンセルで戻します。
  • 複数ファイル …… 2 つ以上のファイルを開いたあとの並べ方。タブのまま／左右／上下／上下左右。既定はタブのまま。
  • 関連付け …… Wave / AIFF / MP3 / M4A。M4A はプレイヤー専用。チェックでこのアプリを既定にし、外すと解除します。すでに既定ならチェック済みです。OK を待たず、今の exe へ書きます。

表示項目

  • スピーカー定義 …… 有効にする定義のチェック。既定は Stereo だけ。今使っている定義は外しても、切り替えるまで残ります。全部外すことはできません。ステータスバーの SPEAKER も同じ一覧です。
  • プレイリストの列 …… Wave 用と MP3 用を別々に選びます（それぞれその形式で意味のある列だけ。ファイル名の列は常に表示。プレイリストが空のときは列をすべて隠します）。WAVE / AIFF だけのリストは Wave 側、MP3 / M4A だけなら MP3 側、混在は（未調整時）両方の和集合。混在中に見出しで並べ替え／オンオフすると、混在用の表示と並びだけを内部で覚え、Wave／MP3 の設定は変えません。Wave／MP3 の設定（または単一形式での見出し変更）を変えると混在の記憶は捨てて、再び和集合になります。それぞれ「既定に戻す」があります。Wave 既定はファイル／レート／ビット／Ch／時間／日付／親フォルダ／波形。MP3 既定はファイル／タイトル／アルバム／アーティスト／作曲／時間／トラック／ディスク／年／ジャンル／日付／コメント／親フォルダ（波形表示はオフ）。プレイリストに値が無い列は自動で隠し、値が付いたら出します（ジャケットは Wave / AIFF だけでは隠し、MP3 / M4A があれば出す）。列の見出しを右クリックしてもオンオフでき、いまの形式向けの設定に覚えます。
  • 波形表示の幅 …… S（短）／M（中）／L（長）。L が既定。M は S の 2 倍、L は 3 倍。棒の間引きは同じで長さだけ変えます。リスト表示後に粗い棒で後追い描画します。
  • Wave オンリーのときは波形表示を自動で L サイズにする …… 既定オン。プレイリストが WAVE だけのとき、上の幅指定を無視して L（長）にします。MP3 などが混ざると選んだ S / M / L に戻ります。

オーディオ

  • デフォルトオーディオフォーマット …… 既定 48kHz / 24bit / Stereo。新規ファイルに使います。チャンネルは有効にしたスピーカーと、常に選べる Mono です。
  • 自動スピーカー選択 …… 既定オフ。詳細
  • スピーカー配置 …… モノラル〜Atmos。Quad / LCRS / 2.1 / 5.1 Side などゲーム向けの変則も含みます。自分では追加しません。ファイルの正体は番号のままです。各スピーカーに Ch を割り当て、そのレーンだけ L / C / LFE などを出します。初期値は 1 から順。変更したあと OK せずに別の配置へ切り替えると、保存するか聞きます。
  • API とデバイス …… WaveOut／WASAPI／ASIO とオーディオデバイス。
  • 録音／再生ポートと Ch …… スピーカー名は配置から、ポート名はデバイスから来ます。Ch は録音と再生で共通。なしはそのスピーカーを使いません。録音はレベルメーターで確認します。
  • 確認音 …… 再生ポート行ごとの Sine −20 dB（通常 1 kHz、LFE は 80 Hz）と英語の Voice（LFE には無し）。
  • 2ch 再生でポート未設定なら、スピーカー分を L/R にダウンミックスします。

プレイヤー

先頭がギャップレス再生（既定オン。何をするかは ギャップレス再生）。続けて左ツリーのルートです。既定はマイミュージック。登録・削除・上から順の並び替えができます。

編集

  • ラウドネスターゲット …… LKFS。
  • 無音しきい値（Silent Skip / 無音削除）…… 既定 -60 dB。-120 から 0。再生の飛ばしと、オン時の録音ゲートと、右クリックの無音部分削除に使います。
  • 横に、割り当て録音をモノラル化したレベルメーターがあります。バーはピーク。赤線と数値は谷の平均で、ピークではありません。編集タブでも入力を監視します。
  • スキップ時の無音挿入時間 …… 既定 500 ms。それ以上の無音は縮めます。0 なら無音は全部捨てます。0 から 10000。再生には使いません。
  • プチノイズ防止フェード …… 既定 20 ms。1 から 100。リージョン毎ノーマライズ、無音削除、Silent Skip 録音の継ぎ目に使います。
  • フェードカーブ既定。
  • リージョン付加は録音開始時に指定します。

書き出し

  • MP3 …… Windows ビットレート（LAME を使わないとき）／LAME パス／LAME オプション。
  • 同時書き出し本数 …… 既定 Auto＝CPU コア数の 1/4。上限はコア数の 1/2。

Wwise

EXPORT 時の Music Track です。Stream は常にオン。Prefetch Length と Look-ahead Time の既定はどちらも 500 ms（0 から 10000）。先頭 Segment は Zero Latency で Look-ahead 50 ms 固定。Prefetch は先頭、Look-ahead は 2 本目以降です。

上段

明るい部分が表示中の範囲です。ドラッグで移動し（中央をスクラブ）、ホイールで拡縮します（再生ヘッド基準）。

波形エリア

本編集面

時間ルーラー、マーカー／リージョンフラッグ、再生ヘッド、マウスガイドがあります。トリプルクリックで全選択します。

チャンネル

  • 左端のチャンネル名をクリックでソロ。同じ名前をもう一度で解除。Ctrl＋クリックで追加。Shift＋クリックでミュート／解除。
  • Tab でチャンネルをソロ。繰り返すと次へ。Shift+Tab で逆順。最後の次で解除します。
  • 波形の時間選択は変えません。フェード／音量／ノーマライズ／リバース／ピッチ／タイムストレッチ／コピー／削除などはそのチャンネルだけです。ミュートしたレーンはグレー。再生中でもできます。

フルスクリーン

  • F11 …… 波形エリアをフルスクリーン。タブ・トランスポート・メーター・Tips・WAAPI は隠します。チャンネル名と dB 目盛りも出さず、全体波形とステータスバーは残します。ウィンドウの枠とタスクバーは隠します。ブラウザの F11 と同じです。タイル表示でも同じ。もう一度 F11 で戻します。
  • F12 …… タイトルバーだけ隠すフルスクリーン。タブ・トランスポート・メーター・Tips・WAAPI・チャンネル名・dB 目盛りは残します。スペクトラム／ラウドネス／レベルメーター／ベクタースコープは 1.5 倍（OS の DPI と表示倍率のうえ）。タイル表示でも同じ。もう一度 F12 で戻します。

プレイヤーモード

波形エリアで F10。全画面にはしません。もう一度 F10 で戻します。

画面

  • タブは出ません。上段は左にフォルダツリー、中央がファイルリスト。下段は高さが固定の低い波形です。全体波形は出ません。
  • 既定は親フォルダでグループし、グループごとにジャケットを出します。再生や曲送りではリストを作り直しません。
  • プレイリストが空のときは列をすべて隠し（表示中から空にしたときは1秒でフェードアウト）、レベルメーター・スペアナ・ラウドネス・ゴニオ／サラウンドメーターを出さず、入ったときは最初から消します。空のときはライブラリ（フォルダツリー）にフォーカスします。
  • F9 でプレイリストと波形だけを出します（デスクトップの占有面積を節約したいとき。どのモードからでも）。
    • ライブラリ／お気に入り／メーター／アナライザ／トランスポート／ステータスバーは出ません。Alt+S（Silent Skip）と Alt+A（Always on Top）は効きます。
    • もう一度 F9 で通常のエディタへ戻します（再生を止めてから、選択したファイルだけ残し、タブの複数選択は解除）。
    • F10 で通常のプレイヤー表示に戻し、再生は続けます。
  • ウィンドウの位置とサイズは通常モードと別々に覚え、切り替えで戻します。

再生

  • 入ると 1 曲めを選んで再生します（引数起動も同じ）。
  • Enter またはトランスポートの再生で先頭から再生し直し、終わったら次へ。Space はその曲だけ再生し、終わったら停止します。
  • 停止中の選択は波形だけ出し、再生はしません。曲を追加したときは 1 秒でフェードインし、音声信号で動き始めたら即表示します。リストが空になったら 1 秒でフェードアウトします。
  • R でランダム再生。一巡まで同じ曲を繰り返しません。空でも切替可。既定オフ。プレイヤーを抜けるとオフ。設定には残しません。
  • 再生はストリームが乗った時点で始めます（フル PCM は展開しない）。波形の描画完了は待ちません。
  • 連続再生では次の曲を先読みし、終わったら隙間なくつなぎます。MP3 の頭尻の無音は ギャップレス再生（設定のプレイヤータブ。既定オン）で減らします。オンでもわずかな隙間は残ることがあります。
  • 左右キーの早送り／巻き戻しはしません。テンキーはどのペインからでも（NumLock オン）使えます。
    • 0 …… 再生／一時停止
    • 1 …… 早戻し、3 …… 早送り（推移中は -4 dB）
    • 4 …… 前の曲、5 …… 再生し直し、6 …… 次の曲
    • 7／9 …… 5 秒戻し／送り（0.75 秒クロスフェード。押しっぱなしは少し待ってから繰り返す）
  • キーボード上段の 0–9 は割合ジャンプのままです。

リストとフォーカス

  • ↑↓ でファイル選択。Home／End でリストの先頭／末尾。PageUp／PageDown でページ送り（複数選択可。再生中はキーを離すとその曲へ。停止中は選択だけ）。
  • F1 または Ctrl+←／Ctrl+↑ でツリー、F2 または Ctrl+↓ でお気に入り、F3 または Ctrl+→ でプレイリストにフォーカス。
  • F5 でフォルダツリーを更新し、フォーカスもツリーへ移します（ディスク上の追加・削除を取り込み直す。展開と選択はできるだけ残す。プレイリスト／お気に入り／波形フォーカスでも効く）。
  • Tab でツリー→お気に入り→プレイリスト（Shift+Tab は逆）。フォーカス中は上端に明るいグラデーションが出ます。
  • Ctrl+F でフォーカス中のライブラリ／プレイリストを検索します。空白区切りが AND、| が OR。Enter で決定して元のペインへ戻り、Esc は入力を破棄します。

ライブラリ

  • 開いたファイルはリストへ登録するだけで、波形（PCM）は全件走査しません。タグと時間などのメタは登録時にすべて読み、列へ出します。出す列は設定の表示項目で Wave／MP3 別に選び、見出しをドラッグした並びも覚えます（混在時の並びは別記憶。Wave／MP3 を変えると和集合へ戻る）。空のときは列をすべて隠し、値が無い列は自動で隠し、波形表示の幅も同じ表示項目です。
  • 左のツリーは既定でマイミュージック。選んだ場所・展開状況と、お気に入りとの仕切り位置を覚えます。
  • 区切りとスクロールバーは近づけると出し、マウスが約 3 秒止まると消します。フォルダを選んでもリストへは自動で載せません。
  • ツリーの * は選択フォルダ以下を全展開、/ で閉じます。
  • ツリーにフォーカスがあるとき、フォルダ名の先頭を打つとそのフォルダへジャンプします。続けて打つと絞り込み、約 1 秒空くと打ち直しです。プレイリストには載せません。
  • ツリーの Enter はプレイリストをクリアして、そのフォルダ配下を載せます。検索中は見えているフォルダだけです。ファイル名ヒットはそのファイルだけ、フォルダ名ヒットはそのフォルダ内すべて。深さ優先で、最初に登録した曲から再生します。
  • Shift+Enter とダブルクリック、リストへのフォルダドロップは配下ごと追加します。

波形

シークと選択だけです。右クリックもメニューキー／Shift+F10 も出さず、マーカー／リージョン／ループも出しません。範囲選択は反転＋半透明。拡大しません。表示用のピークだけ作り、短いファイルは粗くしません。スペクトラム／ラウドネス曲線ビューには切り替えません。編集コマンドは拒否してグレーアウトします。

ジャケットと背景

  • ジャケットはリストで選択したときに読みます。埋め込みが無ければ No Image。Wave / AIFF だけのプレイリストではジャケット枠自体を出さない（MP3 / M4A が混ざれば出す）。
  • ジャケット枠へ画像ドロップで差し替えできるのは MP3 のみ（ファイルへ書き込み）。WAVE / AIFF / M4A は差し替えできません。
  • ジャケットがあるときはウィンドウ全体の背景に、縦横比を崩してエリアいっぱいに置いてから大きくぼかして使います（トランスポート・メーター・ステータスバーも含む）。

入り方と抜け方

  • 引数に mp3／m4a が 1 つでも混ざるとプレイヤーで起動し、それらのファイルをリストへ載せます。このモードでは複数ファイルのすりガラス読み込みは出ません。
  • WAAPI は無効です。入る前にオンなら、抜けたときに戻します。他モードのファイルはリストへ引き継ぎます。
  • 抜けるときは再生を止めてから、選択したファイルだけ残し、タブの複数選択を解除します。プレイヤーのまま終了したときは、読み込んだファイルは覚えません。

読み込み中の表示

  • 1 件の読み込みに時間がかかるときは、中央に Now Loading ... を出します。
  • 2 件以上はすりガラスを乗せ、全体と各ファイルの進捗を出します。Esc で中断でき、読み込み済みは残します。

時間スクロールバー

波形の下

表示範囲を左右に動かします。

タブ

1 ファイルでも表示します。

  • 閉じるは Ctrl+W。アプリ終了は Ctrl+Q。
  • 誤って閉じたタブは Ctrl+Shift+T で開き直せます（今の起動で閉じたもの。複数可）。
  • Ctrl+Shift+W でもすべてのタブを閉じられます。複数タブを閉じるとき、未保存が 2 件以上なら「すべて保存して閉じる」「すべて保存せずに閉じる」も選べます。

右クリック

  • 「このタブを閉じる(S)」「このタブ以外を閉じる(O)」「このタブを含め右側を全部閉じる(R)」「このタブを含め左側を全部閉じる(L)」「すべてのタブを閉じる(W)」
  • 「ファイル名を変更(N)」（F2、またはタブ／タイルの帯のファイル名ダブルクリックでも）
  • 「ファイルを複製(U)」（Ctrl+Shift+D）、「ファイルを削除(D)」
  • 「全部のタブを選択する(A)」「閉じたタブを再開(T)」

波形の右クリックには「タブ」カテゴリがあり、閉じる系／バウンス／全選択／再開／時間／タイル配置はタブメニューと同じ文言・同じアクセスキーです（対象はアクティブなタブ）。これに加えて「すべてのタブを Wave / MP3 で保存」（常に全タブ向け。タブ右クリックで全選択したときの「選択ファイルを〜で保存」とは別）と「次のタブ(N)／前のタブ(V)」があります。リネーム・複製・削除は波形 → ファイル、書き出し・セパレートは波形 → 書き出しにあります。

バウンス

2 つ以上のタブを選択すると「選択ファイルをバウンス(J)」で、波形を重ねて合成した新しい Wave を作り、選択の右隣のタブで開きます。Ctrl+Shift+B でも同じです。

  • 長さはいちばん長いタブ。フォーマットは左端の選択タブ。
  • マーカーとリージョンは位置そのままで引き継ぎ、同じ位置で同じコメントのマーカーは 1 つにまとめます。
  • 先に保存ダイアログで保存先と名前を指定します。既定名は Bounce.wav。初期フォルダはファイルを持つ最初の選択タブ、無ければ前回の書き出し先です。

書き出し

  • 今の編集内容を別ファイルへ出します（未保存のままで可）。1 件は保存ダイアログ、複数はフォルダを選びます。
  • 既存ファイルは上書き確認です。はい＝上書き、いいえ＝それらをスキップ、キャンセル＝中止。多いときは件数と先頭だけ出します。
  • セパレートはフォルダを選びます。マーカーは区間が 2 つ以上、リージョンは 1 本以上あるタブだけ出します（足りないタブは飛ばす）。名前は元名に _1（10 個以上なら _01 のように桁を合わせる）。
  • チャンネルごとは、今のスピーカー配置と Ch 割り当てで Wave を出します（ファイルのチャンネル順や名前は見ない。割り当てが無いスピーカーは出さない）。名前は元名に _L / _C / _LFE など配置のラベルを付け、フォルダを選びます。
  • 複数書き出しの名前は元ファイル名（未保存はタブ名）で、同じ名前が重なれば 2 から番号を付けます。前回の書き出しフォルダを覚えます（開くとは別）。
  • 実行中はすりガラスで操作を止め、全体と並列中の曲すべてのプログレスバーを出します（多いときは列を増やす）。
  • Ctrl+Shift+Alt+M で全タブを MP3 で保存します（波形右クリック → タブ。今のタブは開いたまま。Wave の一括保存にキーはありません）。

複数選択

  • Ctrl+クリックで個別追加、Shift+クリックで範囲選択。タブバーまたはタイルのファイル名の帯の上の Ctrl+A で全選択できます。選択中のタブとタイルの帯はハイライトされ、Esc で解除します。
  • Ctrl+Shift+A は、ポインタの位置やタイル表示かどうかに関係なく全タブを選択します。タイル表示の検索フィルター中は、検索でヒットしたタブだけを選択します。タイル表示でも帯で同じ複数選択ができます。
  • 選択中の右クリックは、以外／右／左を残したまま次の名前になります。「選択した（すべての）タブを閉じる」「選択ファイルをバウンス」「選択ファイルを複製」「選択ファイルを削除」「選択した（すべての）タブにペーストする」「選択したタブを Wave / MP3 で書き出す」「選択したタブをマーカー／リージョンでセパレートして書き出す」「選択したタブをチャンネルごとに書き出す」。全タブ選択時はいずれも「選択ファイルを〜」表記で、Wave / MP3 は「選択ファイルを〜で保存」です。
  • Ctrl+V で、コピーした編集履歴を選択タブへ一括適用できます。適用中はすりガラスで操作を止め、全体と各タブの進捗を出します。

幅が足りないとき

タブが増えてバーに収まらないときは、先にアクティブ以外を縮めます。タイトルが 6 文字を切るまで縮めても足りなければ、左右の ＜＞ で送ります。

タイル表示

複数のタブを 1 画面に並べて聴き比べられます。

並べ方

  • Ctrl+T で左右→上下→上下左右→解除の順に巡回します。ファイル数によって見た目が同じになる配置、波形エリアに収まらない配置は飛ばします。左右・上下が収まらなければ格子を試し、格子も無理なら動きません。
  • 波形の右クリック → タブ、またはタブの右クリックの「タブのまま(B)／左右に並べる(1)／上下に並べる(2)／上下左右に並べる(3)」で直接指定もできます。2 タブ以上。収まらない配置は選べません。チェックが今の配置です。
  • 並べるときは、いま表示しているタブの解析モード（波形／スペクトログラム／重ね／ラウドネス）に全タブを揃えます。
  • 再生中に配置を切り替えても音は止まりません。タイル中に閉じたタブは並びから外れ、1 つになると通常表示へ戻ります。
  • ウィンドウを狭くして今の左右・上下が収まらなくなると格子を試し、格子も無理ならタブ表示へ戻します。
  • 設定の一般タブ「複数ファイル」で、2 つ以上のファイルを開いたあとに自動で並べる既定配置を選べます（既定はタブのまま。左右・上下が収まらなければ格子を試し、格子も無理なら並べません）。
  • 終了時の配置は覚え、複数タブが復元されたときに次回起動でも戻します（収まらなければ格子、格子も無理なら戻しません）。

選択

  • タイルをクリックまたは再生するとアクティブが替わり、ファイル名の帯が青くなり、シアンの再生ヘッドもアクティブだけ出ます（非アクティブの帯は塗りなし）。
  • 帯の Ctrl＋クリック／Shift＋クリックはタブと同じ複数選択。Ctrl+A を帯の上で押すと全タブ選択。選んだ帯もアクティブと同じハイライトです。
  • ファイル名の帯を右クリックすると、タブと同じメニューが出ます。

検索

Ctrl+F でタブ名の検索（絞り込み）ができます。波形エリア中央に検索ボックスが出て（AND / OR の書き方もボックス内に表示）、1 文字入れるたびに判定します。ヒットしないタイルは暗くなり、すりガラスで覆われます。

  • 空白区切りは AND、| 区切りは OR です（例: bgm loop|se ＝ bgm と loop の両方を含む、または se を含む。大文字小文字は区別しません）。
  • Enter で条件を確定して検索ボックスを閉じます。フィルターは残ります。もう一度 Ctrl+F を押すと、同じ条件から編集できます。
  • Esc は、開いた時点の文字列に戻して閉じるキャンセルです。解除するには検索文字を空欄にします。
  • Alt+Enter でヒット以外を閉じます。未保存の編集があるタブは残し、確認は出さず、フィルターは解除します。
  • Ctrl+Shift+F は、検索ワードが入っているときだけ、ボックスを出さずに検索ワードを空にして確定します（フィルターの即解除）。
  • 覆われたタイルは操作できません。クリックしてもアクティブにならず、Ctrl+Tab／Ctrl+PageUp・PageDown の切り替えでも飛ばされます。
  • 文字を変えて絞り込むと、ヒットした先頭（タブの並び順。タイルの左上から）の波形をアクティブにします。すでにそのファイルならそのままです。ヒットが無いときはアクティブを変えません。検索文字を空にして解除したときも、アクティブは移しません。
  • 検索の確定でタブが選択されることはありません。検索文字を変えたり確定したりすると、残っていたタブの複数選択は解除されます。選択はフィルター中の Ctrl+Shift+A で明示的に行い、検索でヒットしたタブだけを全選択します。
  • フィルター中にバウンスや複製で増えた新しいタブがヒットしない名前の場合は、前面化・選択されず、すりガラス側に加わります。タイル表示を解除すると検索もリセットされます。

Silent Skip

ステータスバーの SPEAKER の左、Alt+S。既定オフ。

  • 再生中に無音区間を飛ばし、録音中はしきい値を超えたときだけ書き込みます。
  • 書き込んだ可聴の前後には、プチノイズだけを消す短いフェードをかけます（設定の編集タブ。既定 20 ms）。
  • 再生中の ←／→ 早送り／巻き戻し中は飛ばしません。
  • しきい値を下回った時点から無音を書き、設定の長さで止めます。音が戻ったときにまとめて挟みません。録音専用です。既定 500 ms。再生には使いません。
  • 録音開始時は毎回、Silent Skip をオンにするか確認します。チェックの初期値はステータスバー。OK するとステータスバーにも反映し、キャンセルは変えません。確認文にしきい値と無音の尺が出ます。設定から変更できます。
  • オンのときだけ「録音部分にリージョンを付加」を選べます（オフでは選べない）。付けると、無音を pad まで挟んだときの前後の録音へ付けます。無音には付けません。波形の短い谷では分けず、続きの録音は新しい区間だけです。既定オフ。状態は覚えます。リージョン付加は録音開始時に指定します。
  • しきい値とスキップ時の無音挿入時間は設定の編集タブです（しきい値の既定 -60 dB）。同じしきい値で、波形の右クリック → 編集 → 無音部分を削除もできます。

ギャップレス再生

設定 → プレイヤーの先頭。既定オン。

トラックとトラックのあいだに、元の音源では全く無音が無かったものを、つながったまま聞きたいための機能です。CD で一続きだったライブやクラシックを曲ごとに MP3 へ取り込んだとき、各ファイルの頭と尻にエンコーダが足したごく短い無音が乗り、曲が途切れ途切れに聞こえます。オンのときは、LAME タグに書いてある encoder delay／padding を再生から外し、次の曲を先読みしてつなぎます。無音検出で「静かなら全部飛ばす」のではありません（それは Silent Skip です）。

  • タグが無い・古いエンコード・Windows 経由の MP3 は切る量が分からないので、そのまま再生します。
  • タグの数値が嘘だと、曲頭のアタックや曲末の残響が数十ミリ秒欠けることがあります。デコーダが既に同じ無音を削っているときに二重に切ることもあり得ます。
  • リップで曲間 2 秒などをファイルへ入れてしまった無音は、この設定では消えません。
  • オンでも、エンコードの切れ目やデバイスのバッファで、わずかな隙間が残ることがあります。完全に CD と同じつながりになるとは限りません。
  • オフにすると、エンコーダが足した無音も含めてデコード結果をそのまま再生します。波形の表示尺はどちらでも変えません。

Always on Top

Silent Skip の右、SPEAKER の左

ウィンドウを最前面に固定します。Alt+A で切り替えます。

スペクトラム／ラウドネス／レベルメーター／ベクタースコープ

再生出力の表示です。

ラウドネス

スペクトラムの左に出ます。Short Term / Integrated / Momentary Max、Loudness Range、True Peak。ターゲット LKFS は設定です。青＝余裕、橙＝接近、赤＝超過。

  • 再生中は出力のリアルタイム計測で、数値が色づきます。
  • 停止中は波形全体のオフライン解析です。Short Term はファイル内の最大。色が数値の塗りになり、文字は通常色です。音量などの編集後は測り直します。
  • ラウドネスの左に編集履歴の一覧があります。収まる分だけ出し、古いものは切れます。クリックで U の編集履歴。ここからは選べません。

スペクトラムとチャンネル色

  • スペクトラムは全チャンネルを畳んだ、Layer Music Checker と同じ LED 帯域表示です。
  • 波形のチャンネル名は、スピーカーに割り当てた Ch のレーンだけ配置の名前（L / C / LFE など）です。割り当てのないレーンは 1 からの番号。初期値は 1 から順です。
  • 3ch 以上では、名前は白文字で、角丸バッジの塗りがよくある登場順（Atmos 9.1.6 の 16 色）です。波形も同じ色で薄く染めます。レベルメーターのバーも同じ色です。

2ch 以下

シアングラデです。内側 2 本が Peak（上の赤ランプがクリップ）、外側 2 本が RMS（どちらもホールド線）。下の数値は Peak 行／RMS 行です。メーターにチャンネル名は出しません。

3ch 以上

  • ベクタースコープの代わりにサラウンドビューになり、同じ割り当てで配置の位置を使います（ファイルヘッダから名前は当てません）。
  • エネルギーは波形と同じチャンネル色です。大きさはチャンネルのレベル、輪郭の凹凸はそのチャンネルの直近の波形です（先端が今、裾が少し前）。
  • 全体の広がりをひとつのダークグレーの細線で囲みます。枠はピークを少し持ってからゆっくり戻ります。
  • レベルメーターはチャンネルごとの Peak バーに、Peak ホールドと緩やかな RMS ホールドを載せます。

幅と表示の切り替え

  • 列の左端をドラッグすると幅を広げられます。既定が最小で、バーが最大の太さになるところで止まります。広げた幅は次の起動でも覚えます。
  • 停止後、表示はゆっくり消えます。レベルメーター上の WAAPI でバーの表示を切り替えます。

Tips

WAAPI バーの上。高さ固定。

  • コントロールにマウスを置くと説明を表示し、はみ出したらスクロールします。初回はすぐ出ます。別の項目へ移る／外すときは 300ms 待ってから差し替え／消去します。
  • 見出しまたは本文をクリックでロックします（枠がシアン、Tips (Locked)）。もう一度クリックで解除。ロック中とパネル上では内容が変わりません。
  • トランスポートのボタンだけ、短いツールチップ（ショートカット付き。折り返し、切り詰めなし）も出ます。他のコントロールにホバー用ツールチップはありません。

WAAPI バー

接続状態、作成先、Play -E、Auto Active、EXPORT があります。

プロジェクト名をクリック、または Alt+Ctrl+Shift+W で Wwise Authoring を開く／前面化します。WAAPI がオフでもバーを出してから起動します。覚えた .wproj が無ければバーの表示までとし、起動できない旨を出します。

ステータスバー

  • ファイル位置 …… 2 ファイル以上開いているときは、冒頭に 1 / 10 Files のように何番目／全数を表示します。
  • ファイル情報 …… サンプリングレートなど（名前はタブ側）。レート／ビット深度／チャンネルを変換すると、該当項目が保存まで赤になります。MP3／M4A はビットレートも表示します。容量は MB（MiB / B）。変換や範囲削除で変わると推測サイズが赤になります。
  • Silent Skip と Always on Top …… NOW POS の左。Silent Skip は Alt+S。Always on Top は Alt+A。無音を飛ばして再生し、録音ではしきい値超だけ書きます。しきい値は設定です。
  • SPEAKER …… その右でスピーカー配置を切り替えます。一覧は表示項目タブと同じです。今使っている定義は外しても、切り替えるまで残ります。自動スピーカー選択がオンなら、ファイルの本数に合う定義へ切り替えます。既定オフ。
  • 時間 …… 現在時間／選択開始／選択範囲／選択終了／トータル。トータル以外は入力・ホイール／↑↓で調整します。時間は 1 秒／Shift 10 秒／Ctrl 1 分／Ctrl+Shift 10 分、サンプルは 1／Shift 10／Ctrl 100／Ctrl+Shift 1000。右クリックで時間とサンプル数を切り替えます。

バウンスの補足。合成は 32bit float の単純加算です。DAW のバウンスと違い、プラグイン・オートメーション・センドなどの処理を一切通さないため高速です（サンプルレートが違うタブだけ sinc 補間でリサンプルします）。

加算そのものに音質の劣化はなく、DAW 内部のサミングと本質的に同じです。ただしゲイン調整を挟まない素の加算なので、大きい波形を重ねると合計が 0 dBFS を超え、Wave に書く時点でクリップします。

音量に余裕があれば DAW のミックスダウン代わりにも使えますが、リミッターやディザなどの仕上げ処理は無いため、あえて推奨はしません。重ねる素材の音量を事前に下げるか、バウンス後に波形とレベルメーターでピークを確認してください。

4. 再生

  • Space …… 再生／停止。停止すると開始位置へ戻ります。プレイヤーモードでは選択曲だけ再生し、終わったら停止します（連続再生しません）。
  • Enter …… その場停止。プレイヤーのリストでは先頭から再生し直し、終わったら次の曲へ進みます（トランスポートの再生も同じ連続再生）。
  • ←／→ …… 停止中はシーク（表示の約 1 px。点が見えるときは 1 サンプル）。再生中は押しっぱなしで、ピッチ据え置きの 3 倍早送り／巻き戻し（推移中は -4 dB）。離すと元の速さと音量。その間 Silent Skip は動きません。プレイヤーモードでは左右キーの早送り／巻き戻しはしません（テンキー 1／3）。
  • Ctrl+Space …… 3 秒前から。
  • Alt+Enter …… 再生開始位置からやり直し（タイル検索ボックスにフォーカスがあるときはヒット以外を閉じる）。
  • Alt+S …… Silent Skip。無音区間を飛ばして再生し、録音中はしきい値を超えたときだけ書く（既定オフ。しきい値は設定、既定 -60 dB）。再生中の ←／→ 早送り／巻き戻し中は飛ばしません。録音開始時は毎回、Silent Skip をオンにするか確認します（チェックの初期値はステータスバー。OK すると反映。確認文にしきい値と無音の尺。設定から変更可）。オンのときだけリージョン付加を指定します（既定オフ。前回の指定を初期値にする）。
  • プレイヤーの連続再生は次曲を先読みします。MP3 の頭尻の無音は ギャップレス再生（設定のプレイヤータブ。既定オン）で減らします。オンでもわずかな隙間は残ることがあります。
  • Ctrl+ドラッグ …… スクラブ。全チャンネルを L/R に畳む（レベルメーターも L/R だけ動く）。
  • G …… ステータスバーの NOW POS を入力。Enter で移動。コピー／貼り付け可。右クリックで時間／サンプル数。
  • Z または .（テンキーの . も同じ）…… 中央寄せ。再生中はセンターロックの切替、停止で解除。
  • L …… 選択（無ければサンプルループ／-L）の末尾 3 秒前からループ再生。
  • K …… 範囲メトロノーム。等分マーカー／リージョン位置でメトロノームを鳴らす。ボタンまたは K でオン／オフ（既定オフ。自動ではオンにならない）。波形の右クリック → 再生でも切り替え可。
  • Tab …… チャンネルをソロ。他のレーンはグレーでミュート。繰り返すと次のチャンネルへ。Shift+Tab で逆順。最後の次で解除。左端のチャンネル名をクリックでもソロ（同じ名前をもう一度で解除。Ctrl＋クリックで追加。Shift＋クリックでミュート／解除）。波形の時間選択は変えない。波形操作はそのチャンネルだけ。再生中でも停止中でも可。
  • Ctrl+N …… 新規。空のタブを作る。フォーマットは都度選ぶ（前回を覚える）。チャンネルは表示項目で有効にしたスピーカーと Mono（常に選べる）。
  • Ctrl+R …… 録音。
    • 開始前に毎回、Silent Skip をオンにするか確認します。チェックの初期値はステータスバー。OK すると反映。確認文にしきい値と無音の尺。設定から変更可。オンのときだけリージョン付加を選べます。既定オフ。状態は覚えます。
    • 今開いているファイルのフォーマットで、シークバーの位置から録ります。それ以降の波形は上書きします（Undo で戻せる。take より後ろは残す。take が長ければ伸ばす）。
    • ファイルが無いときは始まりません（先に Ctrl+N または開く）。録音は常に PCM。MP3 は保存／書き出しです。
    • 未保存のまま終了しても作業コピーが残り、開いたままだったタブは再起動で戻ります。閉じてしまったタブは、今の起動のうちなら Ctrl+Shift+T で再開できます。
    • もう一度、または Space / Enter / Esc で停止します。録音中は波形の背景が赤系になり、新しい区間はすぐ粗い波形で出し、少し遅れて通常の描画に整えます。
    • Silent Skip をオンにすると、しきい値を超えたときだけ書き込み、下回った時点から無音を挟んで設定の長さ（既定 500 ms）で止めます。可聴の前後には設定の短いフェード（既定 20 ms）をかけます。リージョンを付けると、停止時に今回書いた可聴／無音それぞれへ付けます。
    • 録音ポート・再生ポート・Ch は、その配置の中で割り当てます（Ch は録音と再生で共通。なしはそのスピーカーを使いません）。
  • 再生ポートが未設定の 2ch デバイスでは、スピーカー分を L/R にダウンミックスします。モノラルはポートが 2 つ以上あれば L/R へ同じ音を出します。

5. 選択と編集

ドラッグで選択。ダブルクリックは区間（マーカー間）、トリプルクリックは必ず全選択。Esc または Shift なし移動で解除。未選択のフェード／音量／ピッチ／ノーマライズ／リバース／タイムストレッチは時間方向は全体です。チャンネルソロ中は聞こえているレーンだけが対象です。ステータスバーの選択開始／範囲／終了に値を入れることでも選択できます。

  • FADE IN I／FADE OUT O …… カーブを選び Space で試聴、Enter で実行。1–9 でカーブ。
  • X …… シークバー前後をフェード。シークを境に、今見えている前だけアウト／後ろだけイン（リニア）。
  • V …… ラウドネス曲線を表示して音量。dB を直接入力、または ↑↓／ホイールで 0.1 dB（Shift 1／Ctrl 3／Ctrl+Shift 6）。Space で試聴、Enter で実行。メニューに波形全体の Integrated LKFS／RMS／Peak の変化を先に出します。Short Term 曲線と停止中メーターも同じ dB で追従します。Esc または Shift+V で曲線を閉じます。
  • P …… ピッチ。↑↓／ホイールで半音（Shift または Ctrl で 1 オクターブ）。Space で試聴、Enter で実行。±2 オクターブ。長さを保つのは既定オン（Tab でチェックへ）。オフは再生速度と同じく長さも変わります。実行中はすりガラスで進捗を出します。
  • T …… タイムストレッチ（ピッチ据え置き）。選択があればその時間、無ければ全体。伸ばした時間と割合（％）が連動。↑↓／ホイール（時間は 1 秒／Shift 10 秒／Ctrl 1 分／Ctrl+Shift 10 分。割合は 0.1／Shift 1／Ctrl 10／Ctrl+Shift 25％）。Tab で時間と割合。Space で試聴、Enter で実行。10–1000％。実行中はすりガラス。
  • NORMALIZE N …… ピークを -0.1 dB に合わせる。
  • R …… リバース。選択があればその範囲、無ければ全体の波形だけを時間方向に反転。マーカー／リージョン／ループは動かさない。
  • 波形の右クリック → オーディオ → リージョン毎に波形をノーマライズ …… 各リージョンのピークを -0.1 dB に合わせる。先頭と終端に、プチノイズだけを消す短いフェード（設定の編集タブ。既定 20 ms。0 交差）をかける。
  • DELETE …… 選択を詰めて削除。選択中のマーカー／リージョンもまとめて削除。
  • 波形の右クリック → 編集 → 無音部分を削除 …… 選択があればその中、なければ全体の、しきい値未満のフレームを詰めて削除。しきい値は Silent Skip と同じ（設定の編集タブ。既定 -60 dB）。判定は約 50ms の窓内ピークです。しきい値付近の周期音の谷だけが抜けて、ピッチが微妙に変わってしまう不具合を直しています。詰めた継ぎ目には、プチノイズだけを消す短いフェード（設定の編集タブ。既定 20 ms）をかけます。ファイル全体が無音だけのときは削除しません。
  • Ctrl+X／C／V …… カット・コピー・ペースト（範囲内マーカー含む。選択がリージョンと一致すればリージョンも）。
  • U …… 編集履歴。↑↓ で移動、Enter 確定、Esc キャンセル。背景はサンプルレート変換の候補リストと同じ塗り。ラウドネス左の一覧をクリックしても開きます。
  • 履歴のコピー＆ペースト
    • 履歴内で Ctrl+クリック（Shift+クリックや Shift+↑↓ で範囲、Ctrl+A で全選択）して Ctrl+C。別ファイルで Ctrl+V すると同じ処理を再適用します（履歴を開いていなくても可）。
    • コピーは次に何かをコピーするまで残るので、タブを切り替えて Ctrl+V を繰り返せば複数ファイルへ反映できます。
    • タブを複数選んで一括適用するときや、ピッチなど重い処理のときは、すりガラスで全体と各タブの進捗を出します。
    • 選択なしの Ctrl+C は現在位置までの全操作です。範囲はサンプルレートが違っても時間基準で写像され、ノーマライズ等は適用先で再計算されます。
    • コピーできないのは「初期状態」だけです（操作ではない。Ctrl+A でも色が付きません）。
  • 履歴を貼っても効かない／意図と違う例
    • 貼り付けは 1 件ずつ試し、適用先に合わないものはスキップします（「3 / 5 件適用しました」）。
    • スキップされる例: 同じ時刻にすでにマーカーがある追加、先方が短くて範囲がはみ出す削除／フェード、無音が無い先への無音削除、すでに同じレート／ビット／ch への変換、先方に無いマーカーへのコメント、MP3 へのリージョン／ループ。
    • ドラッグや ←→ でのマーカー／リージョン／ループ移動と、押しっぱなしの等分は、その時点の配置を丸ごと写します。移動だけをコピーして別テイクへ貼ると、先方のマーカーが置き換わります。追加から移動まで含めてコピーすると意図どおりになりやすいです。
    • 適用先が短いと時間は末尾に寄ります。チャンネルソロ中の編集は同じチャンネル番号だけに効きます。
    • 録音／波形ペーストの履歴は、そのとき入った音そのものを持ちます。波形を Ctrl+C したあとの Ctrl+V は履歴ではなく音声の貼り付けです。
  • 選択ファイルへの一括適用。タブを複数選択（Ctrl＋クリック／Shift＋クリック／Ctrl+Shift+A）していると、次は選択したファイル全部に実行します（それぞれのファイル全体。各ファイルのチャンネルソロを尊重）。
    • 対象: フェードイン／フェードアウト、ノーマライズ、リージョン毎のノーマライズ、音量、ピッチ、タイムストレッチ、リバース、無音部分を削除、サンプルレート／ビット深度／チャンネルの変換、保存（Ctrl+S）、名前を付けて保存（Ctrl+Shift+S）。
    • 右クリックメニューの名前も「選択ファイルをノーマライズ(N)」「選択ファイルを保存(S)／名前を付けて保存(A)」のように変わります。
    • 保存はパスがあるものを上書きし、未保存や AIFF は保存先フォルダへ Wave。名前を付けて保存は保存先フォルダを選び、Wave で書いてタブのパスを付け替えます（書き出しとは違い、保存後のファイルが今のタブになります）。
    • カーブや dB などの試聴はアクティブなファイルで行い、Enter で選択したファイル全部へ適用します。タイムストレッチは割合（％）に換算して各ファイルへかけます。
    • 適用できないファイル（リージョンが無い、無音が無い、すでに同じフォーマットなど）はスキップし、全部スキップならその旨を出します。
    • 実行中はすりガラスで全体と各ファイルの進捗を出して操作を抑制します。タイル検索フィルターのすりガラスは解除せず、その上に重なります。
    • 書き出しと履歴ペーストも同様です。波形右クリック → 書き出しの「Wave／MP3 で書き出す」「マーカー／リージョンでセパレート」「チャンネルごとに書き出す」は、タブ選択中「選択したタブを〜」となり、選択タブを一括で書き出します。
    • 編集 → 「編集データをペーストする」は「選択したタブにペーストする」（全選択なら「編集データを全てにペーストする」）として選択タブへ貼ります（Ctrl+V と同じ）。
    • 複製とファイルの削除も、選択中は「選択ファイルを複製(U)」（Ctrl+Shift+D も同じ）「選択ファイルを削除(D)」になり、選択したファイル全部に行います。確認は 1 回にまとめます。複製はそれぞれ元のタブの隣で開き、削除で消せなかったファイルは最後にまとめて表示します。
    • 波形右クリック → タブには「全部のタブを選択する(A)」もあります（Ctrl+Shift+A と同じ）。
    • シークバー前後をフェード（X）とカット／コピー／ペースト／削除は、アクティブなファイルだけです。
  • Ctrl+Z／Ctrl+Y（Ctrl+Shift+Z でもやり直し）…… 元に戻す／やり直す。

6. マーカー／リージョン／ループ

  • M／Ins …… 選択が無ければ再生位置にマーカー。同じフレームには打てない。選択中は開始と終了を置き、両端にマーカーがあればすぐ中央→3 等分→4…と打ち直す（押しっぱなしはマーカー移動と同じ間隔。離すまで 1 つの履歴）。
  • Shift+L …… 選択をサンプルループに（同じ範囲でもう一度で解除）。
  • Shift+R …… 選択をリージョンに。両端にリージョンがあればすぐ 2 等分。同じ範囲で続けて打つと 3…と打ち直す（解除は右クリック／Delete。押しっぱなしは同じ間隔で、離すまで 1 つの履歴）。
  • フラッグをクリックで端を選択。Shift+クリックで範囲、Ctrl+クリックで追加。ドラッグまたは ←→ で移動（Shift で 3 倍）。
  • ダブルクリックでコメント／リージョン名。-A ライム、-L ブルー、-E 赤（書いたときだけ。ループやサンプルループの後ろは自動では赤くしません）。-R はグレー。EXPORT での意味は 9-3。
  • Ctrl+Shift+R …… リネーム。
  • 右クリック、または Ctrl+Del でマーカー削除。すべてのマーカーを削除と、すべてのリージョンを削除はタイムラインにあります。

WAV の cue / adtl（マーカー・リージョン）と smpl（サンプルループ）を読み書きします。保存時に埋め込みます。MP3 にはリージョンとサンプルループを付けられません。マーカーは置けますが、MP3 へ保存しても書き出しません（再エンコード時にメタは付きません）。

7. スペクトログラム／ラウドネス解析

切り替え

  • A でスペクトログラム／重ね表示を切り替えます。
  • V でラウドネス解析（Short Term 曲線）を出して音量入力を開きます。
  • 抜けるのは Esc、Shift+A、または Shift+V です。今の表示にかかわらず通常の波形へ戻ります。Esc は入力や選択を先に解除します。
  • VIEW のラウドネスボタンは表示だけ切り替えます。
  • L は選択（無ければサンプルループ／-L）の末尾 3 秒前からループ再生です。

ラウドネス曲線

  • Short Term LKFS の曲線です。白い幅は曲線の上下 ±1 LU（1 LU ＝ 1 LKFS の差。メーターの「接近」と同じ）で、半透明です。
  • 波形は Mid 合成のピーク dBFS を線でつなぎ、LKFS と同じ縦軸に載せます（0 dBFS ＝ 目盛の 0）。拡大してサンプルが見えるときは、通常の波形と同じく各サンプルを線でつなぎます。
  • dBFS と LKFS は別物ですが、ピークとラウドネスを同じ高さで比べられます。
  • 背景の帯はメーターと同じ青／橙／赤です（0〜ターゲットが赤、その下 6 LU が橙、さらに下が青）。曲線は原色のシアン／橙／赤で、赤だけ少し太くします。
  • 左目盛は LKFS です（通常の波形では dB）。白い線は設定のターゲットです。

重ね表示

  • スペクトログラムの上に波形の形だけを載せます（半透明のベールはかけません）。
  • -A／-L／-E とループ／リージョンの下塗りは重ねません。フラッグとラインはそのままです。スペクトログラム単体とラウドネス解析でも下塗りは出しません。
  • 重ね波形も Mid 合成の 1 本です。拡大してサンプルが見えるときは、通常の波形と同じく点と線でつなぎます。振幅ズームが 1 のときは中央半分、拡大すると縦いっぱいに伸びます。
  • 色はファイル内のピークを 0 dBFS とみなす表示用ノーマライズで着色します（音声データは変更しません）。ゲインは読み込み・編集の解析時に一度だけ計算し、リアルタイムには追従しません。

描き方

  • 暗いビンは、ハイライトを潰さない範囲で持ち上げて見えやすくします。スペクトログラム／重ねでは、左端のバーか Alt+↑／↓ で持ち上げ量を変えられます（押しっぱなしで連続）。
  • 周波数軸は対数で、低域ほど縦を詰めます（100 Hz 以下はほぼ見えません）。上限は 24 kHz です。
  • ファイル全体が画面に収まっているとき（短い SE のフィット表示など）は、画面列ごとに FFT し、補間せずシャープに描きます。
  • ズームしているときは全体キャッシュから補間して滑らかに描き、ズーム操作や追従スクロールを軽く保ちます。スクロールは列をずらして足りない分だけ計算します。

8. フォーマット変換

  • S …… サンプリングレート
  • B …… ビット深度
  • C …… ファイルのチャンネル数（Mono／Stereo。スピーカー配置の切替ではない）

プリセットと操作

  • プリセットは 8 / 11.025 / 16 / 22.05 / 32 / 44.1 / 48 / 96 kHz、ビットは 4 / 8 / 16 / 24、チャンネルは Mono / Stereo です。
  • 任意 Hz は 1000–384000 で、↑↓／ホイールで 1Hz（Shift 10／Ctrl 100／Ctrl+Shift 1000）。
  • メニューはカーソルの直下を避けます。項目を選んだ時点で、ステータスの容量が推測サイズに更新されます。
  • 変換中はすりガラスで操作を止めます。確定した項目は保存まで赤のままです。

元の PCM から作り直す

  • サンプリングレートとビット深度は、読み込み時（またはフェード等の中身の編集後）の元 PCM から毎回変換します。48 kHz→24 kHz のあと 11 kHz にしても、24 kHz 経由ではなく 48 kHz から作り直します。
  • Space で試聴できるのはレートとビットです（チャンネルは Enter のみ。1–2）。
  • 4 bit は量子化の試聴用です。Wave に書くビットは 8 / 16 / 24、および元が 32bit のときの IEEE float です。4 bit のままでは出さず 16 bit で書きます。変換メニューに 32 はありません。

9. WAAPI EXPORT（Wave 単体）

Wwise IM Importer の Wave 単体モードと同じ組み立てです。ワンショットとループをあらかじめ別ファイルに分けず、1 本のマスター波形上で構造を決めます。EXPORT は元波形を 1 ファイルのまま Originals へ書き、区間は MusicClip のトリムで合わせます。Music Playlist Container 1 つを作ります。-A / -L / -E は区間と Entry／Exit Cue に使い、マーカーは Custom Cue にしません。小節・テンポ管理、複数波形の Switch、XML マーカートラックはありません。

このアプリは波形エディタでもあるので、フェードや削除などの編集はソースへ焼き込んだうえで渡します。マーカーとサンプルループは保存時に WAV へ埋め込みます。

9-1. 手順

  1. Wwise Authoring を起動します。
  2. レベルメーター上の WAAPI をオンにします（W）。
  3. Wwise で作成先オブジェクトを選びます。Keep Target でパスを固定できます。
  4. 書き出し先は接続中プロジェクトの Originals 配下である必要があります。
  5. EXPORT または Ctrl+Shift+E。WAAPI 接続中だけ有効です。
  • Play -E（Alt+E。WAAPI オン時）…… Exit Cue 以降を再生。アプリ内ではループ折り返し時に -E を二重再生し、シークバーが 2 本になります。EXPORT 時は Music Playlist Container の既定トランジションルール（Any to Any）の Play post-exit へ反映します。
  • Auto Active …… EXPORT 後に Wwise を前面へ出します。
  • プロジェクト名 …… クリック、または Alt+Ctrl+Shift+W で Wwise Authoring を開く／前面化します。WAAPI がオフでもバーを出してから起動します。覚えた .wproj が無ければ起動せず、その旨を出します。関連付けが Launcher でも、版に合う Wwise.exe を直接起動します。

9-2. リージョンの組み立て

上にあるものほど優先します。

  1. サンプルループ（WAV の smpl、または Shift+L）…… ループ前が Intro、ループが -L。後ろに余りがあれば EXPORT では -E（波形は赤くしない）。マーカーより優先します。
  2. 接尾辞付きマーカー（-A／-L／-E）…… その位置から次の接尾辞付きマーカー（無ければ終端）までがリージョンになります。無名や名前付きマーカーは区間を切りません。EXPORT では -L の直後の接尾辞なしマーカーを -E として扱います（波形上のコメントは書き換えず、赤にもしません。-A／-L／-E／-R は上書きしません）。
  3. 接尾辞の無いマーカーがちょうど 2 点…… その間を暗黙のループにします。
  4. リージョン（Shift+R）…… 特殊マーカーもサンプルループも無いとき、名前付き区間をそのまま通します。
  5. どれも無ければ、ファイル全体を 1 区間として渡します。

9-3. 接尾辞

接尾辞意味
-Lループ。プレビューでループし、Wwise では無限ループの Music Segment になります。
-EExit Cue 以降（余韻）。直前の -L と同じ Music Segment に束ね、遷移時に次と重なって鳴らせます。
-AEntry Cue 前（アウフタクト）。次の区間と同じ Music Segment に束ねます。
-RWwise IM Importer の除外指定。本アプリでは対応しません。

マーカーは Wwise の Custom Cue にはしません（Wwise IM Importer の Wave 単体と同じ）。-A / -L / -E は区間と Entry／Exit Cue にだけ使います。

9-4. Wwise に作られるもの

  • Music Playlist Container 1 つ（名前はファイル名）。中は Sequential、各区間が Playlist Item。
  • Music Segment。1 区間ならファイル名のまま、複数なら _a／_b…。ループ区間は Loop Count 0（無限）。-A と -E は隣の区間と同一 Segment に入り、Entry／Exit Cue だけがずれます。マーカーは Custom Cue にしません。
  • 元波形は分割せず 1 本の WAV。各クリップは同じファイルを参照し、Begin／End Trim で区間を合わせます。
  • 先頭 Segment は Zero Latency、Look-ahead 50 ms、Prefetch は設定の Wwise タブ（既定 500 ms）。以降は Look-ahead を同じタブの値（既定 500 ms）。Stream は常にオン。
  • Tempo 120／4/4 を Override します（小節管理はしません）。
  • Play -E オン時、Playlist 既定ルール（Any to Any）の Play post-exit を立てます。

同名の Container があれば中身を置き換えます。Originals に同名 WAV があれば確認なしで上書きします。最終確認は必ず Wwise 上で行ってください。

11. 設定と言語

  • 設定は左上の歯車、または Ctrl+Shift+O。設定・新規・保存確認などのダイアログでは Tab でボタンへも移動できます。Ctrl+Tab で次のタブ、Ctrl+Shift+Tab で前のタブ。ウィンドウの位置と高さは閉じたときに覚え、幅はオーディオタブの内容から自動です。

    内容は一般／表示項目／オーディオ／プレイヤー／編集／書き出し／Wwise です。

    • 一般 …… 表示言語のほかに表示倍率 100〜200%（OS の DPI に加えて拡大。縮小なし。メインウィンドウのみ。右クリックメニューや設定などの別ウィンドウ、編集履歴は等倍。コンボを変えた瞬間に反映。キャンセルで戻す）と複数ファイル（2 つ以上を開いたあとの並べ方。タブのまま／左右／上下／上下左右。既定はタブのまま）。
    • 関連付け …… 拡張子ごと（.wav / .wave / .aif / .aiff / .mp3 / .m4a。m4a はプレイヤー専用）。チェックするとこのアプリが既定になり、外すと外します。すでにこのアプリが既定ならチェック済みです。OK を待たず、今動いている exe へユーザー単位で書き込みます。
    • 表示項目 …… 有効にするスピーカー定義（既定は Stereo だけ。今使っている定義は外しても切り替えるまで残る。全部外すことはできない。ステータスバーの SPEAKER も同じ一覧）とプレイリストの列（Wave 用と MP3 用を別々に選ぶ。ファイル名の列は常に表示。空のときは列をすべて隠す。WAVE / AIFF だけなら Wave 側、MP3 / M4A だけなら MP3 側、混在は未調整時は和集合。混在中の見出し操作は混在用だけ覚え、Wave／MP3 設定を変えると和集合へ戻る。それぞれ既定に戻せる。値が無い列は自動で隠し、値が付いたら出す。列見出しの右クリックでもオンオフ可）。波形表示の幅は S／M／L（既定 L。M は S の 2 倍、L は 3 倍）。Wave オンリー自動 L は既定オン。
    • オーディオ
      • デフォルトオーディオフォーマットは既定 48kHz / 24bit / Stereo。新規ファイルに使います。チャンネルは有効にしたスピーカーと、常に選べる Mono です。
      • 自動スピーカー選択は既定オフ。詳細
      • スピーカー配置はモノラル〜Atmos。自分では追加しません。その中に API（WaveOut／WASAPI／ASIO）とデバイス、録音／再生ポートと Ch があります。Ch は録音と再生で共通。なしはそのスピーカーを使いません。初期値は 1 から順。変更したあと OK せずに別の配置へ切り替えると、保存するか聞きます。
      • 再生ポート行ごとに Sine −20 dB（通常 1 kHz、LFE は 80 Hz）と英語の Voice（LFE には無し）。2ch 再生でポート未設定なら、スピーカー分を L/R にダウンミックスします。録音のレベルメーターで信号を確認できます。
    • プレイヤー …… 左ツリーのルート。既定はマイミュージック。登録・削除・上から順の並び替え。
    • 編集
      • ラウドネスターゲットは既定 -24 LKFS（-70 から 0）。色分けの基準で、音声は変えません。
      • 無音しきい値（Silent Skip / 無音削除）は既定 -60 dB（-120 から 0）。ピークがこれ未満なら再生は次の音まで飛ばし、録音中は書き込みません。判定は約 50ms の窓内ピークです。しきい値付近の周期音の谷だけが抜けて、ピッチが微妙に変わる不具合を直しています。右クリックの無音部分削除も同じしきい値です。
      • 横に、割り当て録音をモノラル化したレベルメーターがあります。バーはピーク。赤線と数値は谷の平均で、ピークではありません。編集タブでも入力を監視します。
      • スキップ時の無音挿入時間は既定 500 ms。それ以上の無音は縮めます。0 なら無音は全部捨てます。0 から 10000。再生には使いません。
      • プチノイズ防止フェードは既定 20 ms（1 から 100）。リージョン毎ノーマライズ、無音削除、Silent Skip 録音の継ぎ目に使います。フェードカーブ既定もこのタブです。リージョン付加は録音開始時に指定します。
    • 書き出し／Wwise …… MP3 と同時書き出し本数は書き出しタブ。Prefetch Length と Look-ahead Time は Wwise タブ（既定はどちらも 500 ms。0 から 10000。Stream は常にオン。先頭 Segment の Look-ahead は 50 ms 固定）。

  • MP3 は、設定の LAME パスが有効ならユーザー用意の lame.exe を呼び、オプション欄の内容を渡します。入出力ファイルは自動で付けます。既定は -V2 --noreplaygain で、空欄もこの既定です。

    • パスが空欄または無効なら Windows Media Foundation で出力します。ビットレートは 128 / 160 / 192 / 224 / 256 / 320 kbps（既定 192。CBR）。
    • 今のスピーカー配置で聴いている 2ch 畳みを書きます（係数。確認は出しません）。
    • 書き出し後に LAME / Windows のどちらで変換したかを知らせ、失敗はダイアログです。
    • 書き出した MP3 は今のタブへ読み込みません。開いているのがその MP3 のときの上書き保存だけ、今のファイルのままです。
    • 全タブ書き出しの同時数は同時書き出し本数です（既定 Auto＝CPU コア数の 1/4。上限はコア数の 1/2。Windows の MP3 は常に 1 本）。
    • 前回選んだ保存／書き出しフォルダは settings.json に残し、名前を付けて保存・保存先フォルダ・MP3 として保存とタブ書き出しで同じ場所を開きます（開くフォルダとは別）。LAME は同梱しません。
  • 表示言語も歯車の設定。既定は Auto（OS が日本語なら Japanese、それ以外は English）。日本語版は現状の文言（英語ラベル含む）のままです。同じ一般タブに表示倍率（100〜200%。メインウィンドウのみ）と複数ファイルの並べ方があります。
  • マニュアルは ?、またはブラウザの GitHub Pages。表示言語に合わせて日本語／英語を開きます。
  • 設定ファイル: %LocalAppData%\MGA\MGA Sonic Anvil\settings.json

  • アプリを閉じる（Ctrl+Q、またはウィンドウを閉じる）と、開いていたタブ（どれが前面だったか含む）とウィンドウ位置・サイズ（最大化含む）を覚えます。プレイヤーと通常は別々で、F10 の切り替えで戻します。

    • 未保存の編集と未保存の録音も作業コピーとして残し、終了時に開いていたタブだけを次回起動時に戻します。複数タブなら、開くときと同じくすりガラスと進捗が出ます。
    • プレイヤーモードのまま終了したときは、読み込んだファイルは覚えず、次回は通常モードの空の状態で起動します。閉じてから終了したタブは戻しません。Ctrl+Shift+T も今の起動で閉じたタブだけです。

11-1. 自動スピーカー選択

設定のオーディオタブ、デフォルトオーディオフォーマットの下にあるチェックです。既定はオフです。オンにすると、アクティブなファイルのチャンネル数に合わせて、有効にしたスピーカー定義へ切り替えます。ファイルを開く、タブを前面にする、新規、チャンネル数の変換（Undo / Redo 含む）のときに動きます。ファイルのヘッダから 5.1 などを当てるのではなく、本数だけを見ます。

  • 利便性 …… 1〜2ch は Stereo。6ch なら有効な定義のうち 5.1 を選びます。同じ本数が 1 つだけ有効ならそれを使います（6ch で 5.1 Side だけなら 5.1 Side）。8ch なら 7.1、というように全チャンネル数で同じ規則です。Stereo だけ有効なら 6ch ファイルでも何も変わりません。
  • 注意 …… 今の配置がすでに同じ本数なら維持します（5.1 Side を 5.1 へ戻しません）。同じ本数が複数あって、いちばん普通の配置が無効なら切り替えません。切替は再生と録音を止め、定義ごとのデバイスとポート割り当てに載せ替えます。Stereo をヘッドホン、5.1 を別インターフェースにしていると、タブを変えるたびに出力先が飛びます。6ch を Stereo のまま畳んで聴きたいときはオフにしてください。

11-2. MP3 のダウンミックス

MP3 に保存／書き出すとき、今のスピーカー配置と Ch 割り当てで再生している音を 2ch に畳みます（2ch 再生・ポート未設定と同じ経路）。ファイルのチャンネル番号順ではありません。先に各スピーカーへファイルの Ch を寄せ、割り当てが無いスピーカーは無音、どのスピーカーにも付いていないファイル Ch は使いません。そのあと、配置が 3 本以上なら下の係数で L/R へ畳みます。配置が Stereo なら、割り当てた 2 本だけをステレオとして出します。モノラルファイルはそのままです。ソロ／ミュートは書きません。Wave 書き出しはチャンネル数を変えません。確認や警告は出しません。

スピーカー順行き先係数
1 本目L1
2 本目R1
3 本目L と R1/√2（約 0.707、−3 dB）。センター扱い
4 本目L と R1/√2。LFE も足します
5 本目L1/√2
6 本目R1/√2
7 本目L1/√2
8 本目R1/√2
9 本目以降奇数番は L、偶数番は R0.5

係数は配置の名前ではなく、割り当て後の並びです。5.1（L / R / C / LFE / Ls / Rs）と一致します。Quad や 3.0 など並びが違う配置も、再生と同じ近似です。

Atmos（9.1.6 など）のハイトやオブジェクト、Ambisonics、ステムを並べたファイルは、この並び前提では意図しないミックスになります。専用のフォールドダウンやバイノーラルは現状サポートしません。需要があれば検討します。

12. 対応範囲と位置づけ

  • Wwise の Interactive Music でできることをすべてカバーするものではありません。EXPORT は Wave 単体（マーカー／サンプルループ）に限っています。
  • アプリ内プレビューは近似です。Play -E の二重再生も Wwise 実機と完全一致するとは限りません。最終確認は EXPORT 後に Wwise 上で行ってください。
  • AIFF の書き出しには対応していません。Wave または MP3 を選んでください。Wave に書くビットは 8 / 16 / 24、および元が 32bit のときの IEEE float です（4 bit は量子化の試聴用で、保存時は 16 bit。変換メニューに 32 は出しません）。
  • MP3 の多チャンネルは、今のスピーカー配置で聴いている 2ch 畳みです。Atmos のハイト／オブジェクトや Ambisonics、ステムパック向けの専用ミックスは現状サポートしません。需要があれば検討します。
  • EXPORT は Wwise プロジェクトを変更します。実行前のバックアップやバージョン管理をおすすめします。
