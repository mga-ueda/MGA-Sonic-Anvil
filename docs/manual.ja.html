MGA Sonic Anvil マニュアル

音を聴きながら切って整え、目印とループを付けて、Wwise へ Wave で渡すアプリです。

1. このアプリでできること

波形の編集と、Wwise への書き出しが、ひとつの画面でできます。

フェード、音量のそろえ、いらない部分の削除、コピー／貼り付け、マーカー、リージョン、ループ、スペクトログラム。聴きながら決めて、そのまま確定できます。

Wwise へは、1 本の Wave として渡せます。 元の波形をプロジェクトの Originals に書き、Interactive Music のプレイリストとして取り込みます。名前の末尾が -A / -L / -E の目印と、サンプルループを使います（Wwise の Custom Cue にはしません）。くわしくは WAAPI EXPORT です。

開いている音は Wave または MP3 で保存できます。タブを右クリックすると、今の編集内容を別ファイルへ書き出せます。

新しいファイルは Ctrl+N。開いたあと Ctrl+R で録音できます。録音の前に、無音を飛ばす Silent Skip を使うか毎回聞きます。録音は今のファイルの形式で、再生位置から上書きします（元に戻すで戻せます）。ファイルが無いときは始まりません。

録音そのものは Wave のままです。MP3 になるのは保存や書き出しのときだけです。保存せずに終了しても、開いたままだったタブは次に起動したときに戻ります。閉じたタブは、アプリを閉じる前なら Ctrl+Shift+T で開き直せます。

スピーカーの配置（モノラル〜Atmos）と、どのチャンネルを出すかは、設定と画面下の SPEAKER で切り替えます。

2. クイックスタート

  1. Wave / AIFF / MP3 をドラッグするか、Ctrl+O で開きます。

    • M4A はプレイヤー専用です。複数開くとタブで並びます。
    • プレイヤーでは、設定がオンなら PDF / MOV / MP4 / AVI / MKV / WebM / MPG もプレイリストに載せます（PDF は既定オン。動画は既定オフ。AVI / MKV / WebM / MPG は ffmpeg があるときだけ。エディタでは開きません）。
    • フォルダをドロップすると、中の対応ファイルをすべて追加します（開けない種類は無視します）。
    • たくさん開くときは、画面下に進み具合が出ます。Esc で止められ、すでに開いた分は残ります。
    • 開く場所は前回を覚えます。保存先とは別です。

    Ctrl+N で空のタブを作れます。形式は毎回選べ、前回の選択を覚えます。チャンネルは、設定で有効にしたスピーカーと、いつも選べるモノラルです。

  2. 波形の上で聴きながら切る・フェードする・マーカーやループを置きます。チャンネルが多いファイルは、先に設定の表示項目で配置を有効にし、画面下の SPEAKER で選びます。Ctrl+R で録音できます（開始前に Silent Skip を使うか確認します）。

  3. 必要なら Ctrl+S で Wave または MP3 に保存します（AIFF では書き出せません）。

    • タブを複数選んでいるときは、保存も名前を付けて保存（Ctrl+Shift+S）も、選んだファイル全部に行います。
    • すでに場所があるファイルは上書きします。まだ保存していないものや AIFF は、フォルダを選んで Wave で保存します。
    • 名前を付けて保存はフォルダを選び、各ファイルを Wave で書いて、タブがその新しいファイルを指すようになります。書き出しと違い、保存後のファイルが今のタブになります。
    • Ctrl+Shift+M は MP3 専用です。ファイルを出すだけで、今のタブはそのままです（書き出した MP3 は開きません）。
    • MP3 はいったん 16 bit の音から作り直します。3 チャンネル以上、またはスピーカーの割り当てを変えているときは、今聴いている左右 2 本にまとめた音を書きます（くわしくは MP3 のダウンミックス。確認は出しません）。
    • 設定で LAME の場所が正しければそれを使い、空欄や無効なら Windows で書き出します（既定 192 kbps）。マーカーなどは MP3 には書きません。
  4. Wwise へ渡すときは、レベルメーター上の WAAPI をオンにし、作成先を選んで EXPORT します。

設定や、開いていたタブ、保存していない編集は、このパソコンのユーザー用フォルダ（%LocalAppData%\MGA\MGA Sonic Anvil\）に残ります。アプリの横には書きません。プレイヤーのまま終了したときは、リストの曲は覚えません。閉じたタブの再開（Ctrl+Shift+T）は、アプリを閉じる前に閉じたものだけです。

設定

左上の歯車、Ctrl+Shift+O

  • 設定・新規・保存確認などのダイアログでは Tab でボタンへも移動できます。
  • Ctrl+Tab／Ctrl+PageDown で次のタブ、Ctrl+Shift+Tab／Ctrl+PageUp で前のタブ（端から反対側へ回る。長押しの連続送りは端で一旦止まる）。Esc で閉じます。
  • 幅はオーディオタブの内容に合わせます。タブは一般／表示項目／オーディオ／プレイヤー／編集／書き出し・パス／Wwise です。

一般

  • 表示言語 …… Auto／Japanese／English。Auto は、パソコンが日本語なら Japanese、それ以外は English です。
  • 表示倍率 …… 100〜200%。Windows の拡大に加えて、さらに大きくします。小さくはできません。効くのはメイン画面だけです。右クリックメニューや設定などの別ウィンドウ、編集履歴は 100% のままです。選んだ瞬間に変わり、キャンセルで戻します。
  • 複数ファイル …… 2 つ以上開いたあとの並べ方。タブのまま／左右／上下／上下左右。最初はタブのままです。
  • 起動モード …… エディタ（通常）／エディタ（フルスクリーン：アナライザー有り）／エディタ（フルスクリーン：アナライザー無し）／プレイヤー（通常）／プレイヤー（コンパクト）。既定はエディタ（通常）。コンパクトはプレイリストと波形だけです。ファイルを渡さずに起動したときだけ入ります。引数や関連付けでファイルを開いたときは、今までどおり種類で決まります。次回起動から効きます。
  • 壁紙 …… 動的背景の上に重ねる画像です。最初は無し。参照で画像（JPEG / PNG / BMP / GIF / TIFF）を選び、クリアまたは空欄で外します。読めないパスは出しません。パスを指定した瞬間、および不透明度を変えた瞬間に画面へ反映し、キャンセルで開く前へ戻します。不透明度は 0〜100%（最初は 10%）。欄の ↑↓ とマウスホイールで 1% ずつ変わります。比率は変えず、中央を基準に画面全体を覆います（はみ出しは切れ、タイルには並べません）。動画や PDF を背面に出しているときは、その手前に隠れます。

  • 関連付け …… 種類ごとに、このアプリで開くかどうかを決めます。OK を待たずすぐ反映します。「すべてオン」「すべてオフ」は、今操作できる種類だけをまとめて付けたり外したりします（FFmpeg が無効で灰色の動画は対象にしません）。

    • 音声: Wave / AIFF / MP3 / M4A（M4A はプレイヤー専用）
    • 動画: MP4 / MOV / AVI / MKV / WebM / MPG / MPEG（プレイヤー専用。FFmpeg パスが空または無効のときは灰色で操作不可。パスを設定すると有効になる）
    • すでにこのアプリになっている種類はチェック済みです。外すと解除します。
    • 関連付け／引数で動画を開いたとき、および F8 の動画ミニでは、自動生成オンでもプロキシは作りません。
    • そのときのプレイヤーは前面 UI なしで起動します。A／T の表示は F8 と共通で覚えます（既定オン。変えた状態は本再生とミニで共通に覚え、以後ずっと使う）。

表示項目

  • スピーカー定義 …… 有効にする定義のチェック。既定は Stereo だけ。今使っている定義は外しても、切り替えるまで残ります。全部外すことはできません。ステータスバーの SPEAKER も同じ一覧です。

  • プレイリストに載せる書類・動画 …… PDF / MOV / MP4 / AVI / MKV / WebM / MPG を別々にオンオフできます。

    • PDF は既定オン、動画は既定オフ。
    • AVI / MKV / WebM / MPG は ffmpeg が無いとリストに載らず、設定でもチェックできません（灰色）。
    • オフにした種類はフォルダ追加やドロップで載せません。
    • プレイヤー専用で、エディタには持っていけません。

  • プレイリストの列 …… Wave／MP3／動画用を別々に選べます（その形式で意味のある列だけ。ファイル名はいつも出ます。空のときは列を全部隠します）。

    • WAVE / AIFF だけ → Wave 側、MP3 / M4A だけ → MP3 側、動画だけ → 動画側。混在は（未調整時）三つの和集合。
    • 混在中の見出しドラッグ／右クリックのオンオフは、混在用の並びだけ覚え、Wave／MP3／動画の設定は変えません。
    • Wave／MP3／動画の設定を変えると、混在の記憶は捨てて再び和集合になります。それぞれ「既定に戻す」があります。
    • Wave 既定: ファイル／レート／ビット／Ch／時間／日付／親フォルダ／ラウドネス／波形（ラウドネスは WAVE／AIFF の Integrated LKFS だけ。Short Term などは出しません。MP3／M4A／動画では出さない。計測前や未キャッシュは空欄。値の色はメーターと同じで、ターゲットまで青、そこから +3 LU まで橙、それより上は赤。設定の Wave 列チェックでオフにもできる）
    • MP3 既定: ファイル／タイトル／アルバム／アーティスト／作曲／時間／トラック／ディスク／年／ジャンル／日付／コメント／親フォルダ（波形オフ）
    • 動画既定: ファイル／解像度／フレームレート／ビットレート／映像コーデック／レート／ビット／Ch／音声コーデック／時間／日付／親フォルダ／波形
    • 列の空欄（仕様）: MP3／M4A のビット深度は出さない（デコード仮定の 16bit を出さない）。WAVE／AIFF のビットレートは出さない（PCM から機械的に出る値だけのため）。動画のビット深度は非圧縮 PCM 音声のときだけ。
    • 値が無い列は自動で隠し、値が付いたら出します。ジャケットは実画像があるときだけ。見出しはドラッグ並べ替え／右クリックでオンオフ。
    • 見出しをクリックした並び（どの列か、昇順か降順か）は設定ファイルに残ります。未設定のときはアルバム名の昇順です。ソート中の列が隠れるとソートは外れ、その状態も残ります。
  • 波形表示の幅 …… Wave 用と MP3 用を、それぞれの列チェックの一番下で別々に選べます。S（短）／M（中）／L（長）。Wave / MP3 とも最初は L。M は S の 2 倍、L は 3 倍です。WAVE / AIFF だけのリストは Wave 側、MP3 / M4A だけは MP3 側、混ざっているときは広い方です。「既定に戻す」でもその側の幅を戻します。リストを出したあと、波形の棒は少し遅れて描きます。

オーディオ

  • 既定 Wave フォーマット …… 最初は 48kHz / 24bit / Stereo。新しいファイルに使います。チャンネルは、有効にしたスピーカーと、いつも選べるモノラルです。
  • 自動スピーカー選択 …… 最初はオフ。くわしく
  • スピーカー配置 …… モノラル〜Atmos。ゲーム向けの変則配置も含みます。自分では追加できません。ファイルの中身はチャンネル番号のままです。各スピーカーにチャンネルを割り当てると、そのレーンだけ L / C / LFE などの名前が出ます。最初は 1 から順。変更したあと OK せずに別の配置へ切り替えると、保存するか聞きます。
  • API とデバイス …… WaveOut／WASAPI／ASIO と、使うオーディオ機器。
  • 録音／再生ポートと Ch …… スピーカー名は配置から、ポート名は機器から来ます。チャンネル番号は録音と再生で共通。「なし」はそのスピーカーを使いません。録音はレベルメーターで確認します。
  • 確認音 …… 再生ポートごとに、Sine -20 dB（ふつう 1 kHz、LFE は 80 Hz）と英語の Voice（LFE には無し）。
  • 左右 2 本だけで再生していて、ポートを決めていないときは、スピーカーの音を左右にまとめます。

プレイヤー

先頭がギャップレス再生（既定オン。何をするかは ギャップレス再生）。続けて左ツリーのルートです。既定はマイミュージック。登録・削除・上から順の並び替えができます。見つからない登録は赤字で表示します。ルートは設定のほか、ツリーの右クリック／メニューキー「ツリーのルートに登録」、またはエクスプローラーからフォルダをツリーへドロップしても追加できます（既にルートなら「ツリーのルートから外す」）。並び替えは設定の上へ／下へ、ルート選択時の Alt+↑／↓、またはルートをツリー内でドラッグしてもできます。

編集

  • ラウドネスターゲット …… LKFS。
  • 無音しきい値（Silent Skip）…… 最初は -60 dB。-120 から 0。再生の飛ばしと、オン時の録音のゲートに使います。無音・ヒット検出（Ctrl+D）のしきい値とは共有しません。
  • 横に、割り当てた録音をモノラルにしたレベルメーターがあります。バーはピーク。赤線と数値は谷の平均で、ピークではありません。編集タブでも入力を監視します。
  • スキップ時の無音挿入時間 …… 最初は 500 ms。それ以上の無音は縮めます。0 なら無音は全部捨てます。0 から 10000。再生には使いません。
  • プチノイズ防止フェード …… 最初は 20 ms。1 から 100。リージョン毎のノーマライズと Silent Skip 録音の継ぎ目に使います。無音・ヒット検出のカット時フェードとは独立です。
  • フェードカーブ既定。
  • リージョンを付けるかどうかは、録音を始めるときに指定します。

書き出し・パス

  • オーディオ …… LAME パス／LAME オプション／Windows ビットレート（LAME を使わないとき）／同時書き出し本数（既定 Auto＝CPU コア数の 1/4。上限はコア数の 1/2）。

  • ムービー …… 再生用プロキシと ffmpeg の設定です。

    • FFmpeg パス（利用推奨。プロキシ生成に使う）
    • プロキシを自動生成しない（既定オフ。F8／関連付け・引数起動ではオフでも自動生成しません。自動生成は F9／F10 の本再生時だけ）
    • プレイリスト／本再生／ミニでは Ctrl+Shift+P で強制生成できます（設定や F8 抑止を無視）
    • 未使用プロキシの保存日数（動画ごと。起動だけでは未使用はリセットされない。再生・波形・サムネ参照も「使用」）
    • 現在の容量／すべて削除（期限を無視して今すぐ全部消す。確認あり）

Wwise

EXPORT のときの Music Track です。ストリーム再生はいつもオン。Prefetch Length と Look-ahead Time の最初はどちらも 500 ms（0 から 10000）。先頭の区間の Look-ahead は 50 ms 固定です。Prefetch は先頭、Look-ahead は 2 本目以降です。

ファイル名の色 …… ファイル名に文字列が含まれると、先頭に縦の色マーカーを付けます。上から見て最初に一致した色を使います。大文字と小文字は区別しません。空の文字列と、範囲外の色は設定を確定したときに捨てます。同じ色は何度でも使えます。色は Wwise と同じ 28 色です。行の ▲／▼ で順番を変え、追加はリストのすぐ下に付きます。手動で付けた色があるファイルでは、このルールより手動が優先されます。出し方と記録の残り方は ファイル名の色 です。

波形エリア

本編集面

時間ルーラー、マーカー／リージョンフラッグ、再生ヘッド、マウスガイドがあります。トリプルクリックで全選択します。

チャンネル

  • 左端のチャンネル名をクリックでソロ。同じ名前をもう一度で解除。Ctrl＋クリックで追加。Shift＋クリックでミュート／解除。
  • Tab でチャンネルをソロ。繰り返すと次へ。Shift+Tab で逆順。最後の次で解除します。
  • 波形の時間選択は変えません。フェード／音量／ノーマライズ／リバース／ピッチ／タイムストレッチ／コピー／削除などはそのチャンネルだけです。ミュートしたレーンはグレー。再生中でもできます。

フルスクリーン

  • F11 …… 波形エリアをフルスクリーン。タブ・トランスポート・メーター・WAAPI は隠します。チャンネル名と dB 目盛りも出さず、全体波形とステータスバーは残します。ウィンドウの枠とタスクバーは隠します。ブラウザの F11 と同じです。タイル表示でも同じ。もう一度 F11 で戻します。プレイヤーから移るとき、動画／PDF はファイルごと持ち込まず（音声だけ残すこともない）、選択中の音声ファイルだけ残します。
  • F12 …… タイトルバーだけ隠すフルスクリーン。タブ・トランスポート・メーター・WAAPI・チャンネル名・dB 目盛りは残します。スペクトラム／ラウドネス／レベルメーター／ベクタースコープは 1.5 倍（Windows の画面の大きさと表示倍率のうえ）。タイル表示でも同じ。もう一度 F12 で戻します。プレイヤーから移るとき、動画／PDF はファイルごと持ち込まず（音声だけ残すこともない）、選択中の音声ファイルだけ残します。

プレイヤーモード

波形エリアで F10。全画面にはしません。もう一度 F10 で戻します。

画面

  • タブは出ません。上段は左にフォルダツリー、中央がファイルリスト。下段は高さが固定の低い波形です。全体波形は出ません。
  • 既定は親フォルダでグループし、グループごとにジャケットを出します。動画／PDF はサムネイルがあれば各行に出します（画像が無いときのプレースホルダは出しません）。再生や曲送りではリストを作り直しません。
  • プレイリストが空のときは列をすべて隠し（表示中から空にしたときは1秒でフェードアウト）、レベルメーター・スペアナ・ラウドネス・ゴニオ／サラウンドメーターを出さず、入ったときは最初から消します。空のときはライブラリ（フォルダツリー）にフォーカスします。

  • F8 …… 動画／PDF ミニプレイヤー（プレイリスト等の前面 UI は無し）。

    • ウィンドウは映像／PDF ページの原寸枠。+／-（キーボード・テンキー）は常に 25% 刻み（枠ドラッグ後の次キーは近い 25% へ。原寸で一旦停止。25〜300%。縦横比維持。倍率は F8 を抜けるまで記憶）。
    • 窓枠ドラッグは連続拡縮（25% 刻みではない。縦横比固定。ホイール不可）。
    • 背面に動画または PDF があるとき（本再生または暗いプレビュー）かつプレイリストに再生対象があるときだけ入れます。関連付け／引数で動画を開いたときは自動で入ります。
    • Space は開始位置へ戻して静止（即再開しない）、Enter はその場一時停止（プレイリストは出さない。暗い 1/3 速＋格子へは落とさない）。Escape／Q でプレイリストへ戻る（動画ミニで In／Out があるとき Escape は解除して留まる）。
    • A（波形・アナライザ。オフにした瞬間に波形のない簡易シークバーを出し、その後はマウスを動かすかキーボードで時間を動かすと出す）／T（タイムコード・ファイル名）は引数起動と共通に記憶（既定オン。変えた状態は本再生とミニで共通に覚え、以後ずっと使う）。
    • F 全画面中でも F8 可（全画面解除のあと原寸枠へ）。もう一度 F8 で通常プレイヤーへ戻り、再生は継続。
    • F9／F10 でプレイリストが見えるプレイヤーへ（本再生は止め、暗いプレビューへ）。
    • F11／F12 へ移るとき、動画／PDF は持ち込まず、選択中の音声だけ残します。
  • F9 でプレイリストと波形だけを出します（デスクトップの占有面積を節約したいとき。どのモードからでも）。
    • ライブラリ／お気に入り／レベルメーター／アナライザ／トランスポート／ステータスバーは出しません。Alt+S（Silent Skip）と Alt+A（Always on Top）は効きます。
    • もう一度 F9 で通常のエディタへ戻します（再生を止めてから、選択したファイルだけ残し、タブの複数選択は解除）。
    • F10 で通常のプレイヤー表示に戻し、再生は続けます。
  • ウィンドウの位置とサイズは通常モードと別々に覚え、切り替えで戻します。

再生

  • 入ると 1 曲めを選んで再生します（ファイルを指定して起動したときも同じ）。

  • Space またはトランスポートの再生は、その曲だけ再生して終わったら停止します。

    • シークバー位置から開始／再開。同じ動画の暗いプレビューから戻すときも今の位置から。
    • 再生中の Space は止めて開始位置へ戻す。動画本再生中はプレイリストを出さず開始位置で静止（即再開しない）。
    • Enter はその場停止（プレイリストへは戻さない）。停止中の動画／PDF では Space と同じく本再生／明るい表示へ。
    • バックグラウンドへ戻すのは Escape／Q（PDF の明るい表示の抜けも同じ）。
    • 曲末で次へ進むかは「次の曲を自動再生」（Alt+N。既定オフ）。ダブルクリックは再生開始で、自動再生オンなら次へ進みます。
  • 停止中の選択は波形だけ出し、再生はしません。PDF／動画を選ぶと背面に暗いプレビューも出します（動画は暗転＋格子＋無音 1/3 速ループ。PDF は暗転だけ。すりガラスは無し）。曲を追加したときは 1 秒でフェードインし、再生が始まったらすぐ出します。リストが空になったら 1 秒でフェードアウトします。
  • Alt+R でランダム再生（プレイリスト上段の Random）。一巡まで同じ曲を繰り返しません。空でも切替可。既定オフ。エディタとプレイヤーを行き来しても、次回起動でも最後の状態を設定に覚えます。R は今の曲を先頭から再生し直しです。
  • Alt+P で Auto Play。オンのとき、プレイリストをクリアして追加（Enter／ドロップ）すると先頭から再生します。オフのときは追加だけ（再生も停止もしない）。Shift 付きの追加では再生しません。既定オン。最後の状態を設定に覚えます。
  • Alt+N で次の曲を自動再生（プレイリスト上段の Auto Next）。オンのとき曲末で次へ進み、ギャップレス先読みもします。オフのときはその曲で止まります。空でも切替可。既定オフ。エディタとプレイヤーを行き来しても、次回起動でも最後の状態を設定に覚えます。N は次の曲への手動送りのままです。
  • 再生は音が出せるようになった時点で始めます。波形が全部描き終わるのは待ちません。
  • 次の曲を自動再生がオンのとき、次の曲を先に用意し、終わったら隙間なくつなぎます。MP3／M4A の頭と尻のごく短い無音は ギャップレス再生（設定のプレイヤー。最初はオン）で減らします。オンでもわずかな隙間は残ることがあります。

  • 設定のプレイリストに載せる書類・動画でオンにした種類がリストに載ります（PDF / MOV / MP4 / AVI / MKV / WebM / MPG。PDF 既定オン、動画既定オフ。AVI / MKV / WebM / MPG は ffmpeg があるときだけ）。

    • 動画は音楽と同じく連続再生と単独再生ができます。音声はメーター／スペクトラム／ラウドネスへ通し、波形も出します。
    • プロキシ …… MOV / MP4 / AVI はコーデックを調べ、MJPEG / Photo JPEG ならそのまま。それ以外（ProRes など）と MKV / WebM / MPG は ffmpeg で再生用プロキシ（元と同じ fps の MJPEG AVI）を作ってから再生します。生成中はすりガラス（Esc で中断）。ffmpeg は同梱せず、設定の「書き出し・パス」を使います。空欄や無効ならプロキシなしで原ファイルを試します（エラーは出しません）。
    • いつプロキシを作るか …… 自動生成は F9／F10 の本再生時だけ。関連付け／引数起動と F8 ミニでは自動では作りません。Ctrl+Shift+P ならプレイリスト／本再生／ミニで強制生成できます。関連付け／引数では前面 UI なしで起動します。
    • 保存 …… 未使用のまま設定の日数を超えると消します（既定 7 日。起動だけでは未使用はリセットされない。再生・波形・サムネも「使用」）。

    • 表示

      • 背面（ジャケットより前、リスト／波形より後ろ）で再生。本再生で明るくし暗転と格子を外します。
      • 前面 UI を 0.2 秒で消すのは本再生中と PDF 明るい表示のときだけ。本再生中も波形と各メーターは出したまま。
      • 上中央に NOW／END（MM:SS.ff。小数は常に 30fps 換算フレーム。選択中は始点／終点の行も確保）、下中央にファイル名（プロキシ利用時は (Proxy)。A オフのあいだは中央固定）。どちらも T。A でアナライザを隠した瞬間に、ファイル名の上の波形のない半透明の簡易シークバーをすぐ出す。その後は、マウスがどこにあっても動いたときと、キーボードで時間を動かしたときに出し、止まって 3 秒後から 1 秒かけてフェードアウトする（T は無関係）。
      • 2 曲以上で前面 UI 隠れ時は、左下に現在／総数を一瞬出してフェードアウトします。
    • 曲末 …… 前面 UI 隠れ時は次へ進まず頭へ戻して停止（次へは N／P またはテンキー 4／6）。プレイリストが見えていて「次の曲を自動再生」オンなら連続再生します。

    • A／T／F／W

      • 動画本再生と F8／引数ミニの A／T は既定オン。変えた状態は共通に覚え、以後ずっと使う。
      • F8／引数ミニでは A が波形・アナライザ（オフにした瞬間に簡易シークバー。その後はマウス移動かキーボードの時間移動）、T がタイムコード・ファイル名。
      • PDF 表示中は A／T を出さず状態も変えません。
      • F はブラウザの F11 と同じ全画面。W で今の PDF ページを静止背景へ固定して表示を抜けます（もう一度 W で動的背景へ。エディタへ移ると破棄）。
    • 停止 …… Silent Skip オンでも動画再生中は無視します。止めると先頭へ戻さず、暗転＋格子へ移し、約 1 秒で 1 倍→1/3 速に落とします。前面 UI は 0.2 秒で戻します。ほかの曲を再生するとこのレイヤーを隠します。シークや 5 秒送りは波形と同じです。

    • PDF

      • 連続再生の対象。当たったら明るい表示にして停止します。
      • ページ切替時だけ下中央にページ番号をトースト。上段数字でページへ（二桁可。0 単体は 1。テンキーは再生操作のまま）。
      • ←／→・PageUp／PageDown でめくり、Home／End で先頭／最終。+／- で拡縮（100%＝全体収まり〜300%。幅／高さいっぱいで一旦停止）。
      • このあいだ ↑／↓ で前後ファイルへ。ほかのプレイリスト操作は表示を抜けるまで使えません。
    • 動画も PDF もプレイヤー専用で、エディタへは持っていけません。
  • 左右キーの早送り／巻き戻しはしません。動画の本再生中またはフレーム一時停止中の ←／→ は、一時停止して 1 フレーム戻し／送ります（押しっぱなしは最初だけ待ってから繰り返します）。再生操作はどのペインからでも使えます。
    • Space …… 再生／停止（停止で開始位置へ。動画本再生中は開始位置へ戻して静止する（即再開しない）。プレイリストは出さない。暗いプレビューへは Escape／Q）、Enter …… その場停止（停止中の動画／PDF は本再生／明るい表示へ。本再生中の動画はプレイリストを出さない）
    • , …… 早戻し、. …… 早送り（±3 倍・ピッチ据え置き。推移中は -4 dB。停止中でも可。離すとその位置で停止のまま。動画は映像を音声ヘッドに追従）
    • P …… 前の曲（先頭の前は末尾）、R …… 再生し直し、N …… 次の曲（末尾の次は先頭）
    • J …… 5 秒戻し、K …… 5 秒送り（0.75 秒クロスフェード。押しっぱなしは少し待ってから繰り返す）
    • テンキー …… 0 一時停止・再開、1／3 ±3 倍早戻し／早送り、4／6 前／次、5 最初から、7／9 ±5 秒（2／8は未使用）
  • テンキーは再生操作（0＝一時停止・再開、1／3＝±3 倍早戻し／早送り、4／6＝前／次、5＝最初から、7／9＝±5 秒。2／8は未使用。エディタでも同じで、エディタの 4／6 は前後のタブ。J／K／,／. もエディタで同じ）。上段の 0–9 と Alt＋テンキー数字は表示範囲の割合ジャンプ（0＝先頭、9＝90%）。Shift＋上段数字と Shift＋テンキー数字は、一時マーカーがあるときマーカー番号へ（音声波形／動画本再生／F8／フレーム一時停止。二桁可。暗いプレビューは一時マーカーを出さないので飛ばない。NumLock オンでもテンキーの Shift は Home／End にせずマーカー番号）。Ctrl＋上段数字と Ctrl＋テンキー数字は、ファイルにリージョンがあるときその番号の先頭へ（1 から。二桁可。エディタでも同じ）。無修飾のテンキーは再生のまま。ツリーの Shift+8（上段）は配下展開のまま。

リストとフォーカス

  • ↑↓ でファイル選択（先頭の前は末尾、末尾の次は先頭。長押し連続は端で一旦止まり、離して押し直すと再び回る）。Home／End でリストの先頭／末尾。PageUp／PageDown でページ送り（複数選択可。再生中はキーを離すとその曲へ。停止中は選択だけ。長押し連続は端で一旦止まる）。Shift+↑／↓ は範囲選択。Ctrl+Shift+↑↓ は選択を保ったままキャレットだけ上下。プレイリストの複数選択は Shift+Space でチェックモードをトグル（初期オフ。オン時だけ行頭にチェックボックス。ツリーには出さない）。モード中の Space はカーソル行のチェックを入れる／外す。Shift+↑↓ で範囲を付けた状態で Space を押すとその範囲すべてにチェック（すでにすべてオンならまとめてオフ）。右クリック等の操作は、チェックモード中はチェック行が対象、オフ時は従来どおり選択行。モードをオフにするとチェック列を隠し、チェック済みだった行の選択は残す（チェック自体は忘れる。再度オンは空のチェックから）。通常の ↑↓ は単一移動。ツリーにフォーカスがあるときの Space／Shift+Space は展開／折りたたみのまま（プレイリストのチェックモード切替はプレイリスト側）。Ctrl+Space は波形フォーカス時のプリロールだけ（プレイリストでは使わない）。
  • Ctrl+←／Ctrl+↑ でツリー、Ctrl+↓ でお気に入り、Ctrl+→ でプレイリストにフォーカス。F1 と F3 はこの移動には使いません。
  • F2 は名前の変更です。ツリーでは選択中のフォルダ、お気に入りでは選択中のフォルダ（ディスク上の実体）、プレイリストでは選択中のファイル。ライブラリ索引はフルパスで覚えているので、変えたパスへその場で書き換えます。Ctrl+F5 のやり直しは要りません。
  • F7 はツリーだけで有効です。選択中のフォルダの直下に、指定した名前で新しいフォルダを作ります。お気に入りとプレイリストでは何もしません。
  • 複製は Ctrl+Shift+D だけです。Ctrl+D は使いません。ツリーではルート以外のフォルダを同じ階層へ複製します（ルート自体は不可）。名前は元の名前のうしろに半角スペースと番号です（例: 名前 2）。プレイリストでは選択したファイルを1つでも複数でも全部複製し、同じ印を付けます。お気に入りでは複製しません。
  • ディスクからの削除は Ctrl+Delete です。実行前に必ず確認します。OK しない限り消しません。ツリーではルートより下のファイルとフォルダを消します（ルートは不可）。プレイリストでは選択ファイルをディスクから消し、リストからも外し、索引の行も消します。お気に入りではディスク削除も複製もせず、登録を外すのは Delete のままです。波形の一時マーカーを消す Ctrl+Delete は、波形にフォーカスがあるときだけです。名前の変更も削除も、索引を手で再構築しなくて済みます。
  • Ctrl+C でコピー、Ctrl+X で切り取り、Ctrl+V で貼り付けます。使えるのはツリーとプレイリストだけです。お気に入りではコピーも切り取りも貼り付けもしません。
  • 別の階層へはそのまま置きます。同じ階層へ貼ると、同名にならないようリネームして作ります。同じ名前のファイルやフォルダがすでにあるときは、上書き、リネーム、キャンセルを聞いてから実行します。プレイリストでコピーしたファイルをツリーへ貼ると、選択中のフォルダに入ります。
  • プレイリストの同じ場所へ貼ること、切り取ることはできません。「同じ場所なのでできません。」と表示します。黙って無視はしません。
  • フォルダをプレイリストへ貼ったとき、およびエクスプローラーなどでコピーしたものをプレイリストへ貼ったときは、中のファイルを確認なしで登録します（Enter の直下追加と同じ範囲。プレイリストは消しません）。ツリーへ外から貼ると、ファイルの複製です。切り取りをツリーへ貼ると移動です。
  • 貼り付け、移動、削除、名前の変更、フォルダの作成と複製でディスクが変わったときは、索引のフルパスをその場で書き換えます。登録だけのときは索引を触りません。これらの操作に元に戻す／やり直すはありません。
  • NAS（SMB / NFS でマウントした共有）向けの特別な分岐はありません。ローカルディスクと同じファイル操作で扱います。書き込めるかどうかは、OS がそのパスへ書けるかどうかと同じです。
  • 書き込めないときは理由を出します。権限が無ければ「書き込み権限がありません。」、空きが無ければ「ディスクの空き容量がありません。」、コピー元や貼り付け先が無いときは「見つかりません。」です。OS から取れた説明があれば、そのあとに続けて出します。
  • F5 でフォルダツリーとプレイリストの行を更新します（ツリーはディスク上の追加・削除。プレイリストは開いている曲の表示を作り直す。展開と選択はできるだけ残す）。ツリーがアクティブなときはツリーのまま、プレイリストがアクティブなときはプレイリストのままです。お気に入りや波形から押したときはツリーへ移ります。
  • Ctrl+F5（ツリーの右クリック「ライブラリを再構築」も同じ）は、登録したルート配下を、全ファイルを一度プレイリストに載せたときと同じ内容で先にキャッシュします。タグ、今の列設定で必要なジャケット、波形の棒です。プレイリスト自体には載せません。再生中なら先に停止します。進行中はすりガラスで操作を止め、Esc で中断できます。普段は押さなくて構いません。フォルダの追加・削除の取り込みは F5 だけで、ファイルの発見は常にディスクです。ファイル名と祖先フォルダ名の検索もキャッシュ無しで当たります。先に温めておく意味は、まだプレイリストに載せたことがないファイルをアーティストやビットレートなどのタグで探すことと、そのファイルを初めてリストに出したときのジャケットと波形を速くすることです。
  • もう一度 Ctrl+F5 したとき、サイズと更新日時が前回と同じファイルは、タグの読み直し・ジャケットの抽出・波形のピーク計算をしません。フォルダの走査と、キャッシュがまだ有効かの確認だけが残るので、かなり早く終わります。書き換えたファイル、波形の本数を変えたファイル、前回は列がオフで作っていなかったジャケットや波形だけ、その分は最初と同じ重さです。
  • Tab でツリー→お気に入り→プレイリスト（Shift+Tab は逆）。フォーカス中は上端に明るいグラデーションが出ます。
  • Ctrl+F で今選んでいるライブラリ／プレイリストを検索します。空白区切りは全部含む、| はどれか含む。Enter で決定して元の場所へ戻り、Esc は入力を取り消します。

ライブラリ

  • 開いたファイルはリストへ載せるだけで、全部の波形を一度に読みません。曲名や時間などの情報は載せるときに読み、列へ出します。出す列は設定の表示項目で Wave／MP3／動画用を別々に選び、見出しの並びも覚えます。見出しクリックのソート（列と昇順／降順）も同じ設定に残し、未設定のときはアルバム名の昇順です。空のときは列を全部隠し、値が無い列は自動で隠します。波形の幅も同じ表示項目です。
  • 左のツリーは既定でマイミュージック。選んだ場所・展開状況と、お気に入りとの仕切り位置を覚えます。ツリーのルートとお気に入りで、見つからない登録は赤字です。ツリーへフォルダをドロップするとルートに登録、お気に入りはエクスプローラーからファイル／フォルダをドロップして登録できます。ルートの並びは Alt+↑／↓、ツリーの右クリック「ルートを上へ／下へ」、またはツリー内ドラッグで変えられます。
  • 区切りとスクロールバーは近づけると出し、マウスが約 3 秒止まると消します。フォルダを選んでもリストへは自動で載せません。
  • ツリーの *（Shift+8）は選択フォルダ以下を全展開、/ で閉じます。ツリーの右クリック「配下をすべて展開」「配下を折りたたむ」も同じです。
  • ツリーにフォーカスがあるとき: Space は → と同じく 1 段展開（既に展開済みまたは葉なら一つ下へ）。Shift+Space は 1 段折りたたみ（既に閉じている／葉なら一つ上へ）。チェックモードはプレイリスト専用で、ツリーにはチェックボックスを出しません（ツリーの Space／Shift+Space は常に展開／折りたたみ）。いずれもタイプアヘッドの黄ハイライトを消します。再生の Space はツリー以外のペイン向けです。
  • ツリーにフォーカスがあるとき、文字キーでフォルダへジャンプできます（詳しくは フォルダ名ジャンプ）。プレイリストには載せません。Ctrl+F の絞り込み検索とは別です。

  • ツリー／お気に入りの Enter、およびリストへのフォルダドロップは、同じ修飾キーでクリアと深さを決めます。ツリーのダブルクリックはフォルダの開閉だけです（プレイリストへは載せません）。

    • （なし）…… プレイリストをクリアして、直下の対応ファイルだけ載せる
    • Ctrl …… クリアして、配下を再帰的に載せる（右クリック「配下を含めてクリアして追加」）
    • Shift …… クリアせず、直下だけ追加する
    • Ctrl+Shift …… クリアせず、配下を再帰的に追加する（右クリック「配下を含めて追加」）

    クリア系は、大量読み込みの最中でも進行中の追加を中断して差し替えます。Auto Play（Alt+P。既定オン）がオンなら先頭から再生し、オフなら追加だけです。Shift 付きの追加は再生しません。検索中は見えているフォルダだけです（ファイル名ヒットはそのファイルだけ、フォルダ名ヒットはそのフォルダ内すべて）。

ファイル名の色

ファイル名の先頭に、短い縦の色を出します。出す場所は、プレイリストのファイル名、編集タブ、タイルの見出し、動画の本再生と F8 で T が出しているファイル名です。色は Wwise と同じ 28 色です。並びは上段 14、下段 14 で、左から右です。設定の色選択と右クリックの色選択は、同じ並びの同じ盤面です。マスにポインタを置くと、その 1 色だけが明るくなります。

  • ルール …… 設定（Ctrl+Shift+O）の Wwise タブ「ファイル名の色」です。1 行が、ファイル名に含まれる文字列と色です。確定は設定の OK です。

    • 見るのはファイル名だけです。文字列が名前のどこかに含まれていれば一致します（例: _bt_ は gun_bt_fire.wav）。大文字と小文字は区別しません。
    • 上の行から見て、最初に一致した色を使います。同じ色は何度でも使えます。件数の上限はありません。
    • ▲／▼ で行の順番を変えます。削除でその行を消します。追加はリストのすぐ下に付いたままです。色のマスをクリックすると 28 色から選びます。
    • 前後の空白は除きます。空の文字列と、範囲外の色は、設定を確定したときに捨てます。ファイル名を変えて文字列が外れると、ルールの色は外れます。

  • 手動 …… そのファイルだけの色です。ルールより優先します。アプリで名前を変えて、ルールの文字列が外れても、手動色は新しいパスに残ります。

    • プレイリストの右クリック、タブの右クリック、タイルのファイル名の帯の右クリックにある カラー です。複数選択していれば、パスのある選択ファイルへ同じ色を付けます。
    • 中は 自動に戻す と、28 色の盤面です。選択の手動色が一つに揃っているときだけ、その色に印を付けます。選択中に手動色が無ければ「自動に戻す」にチェックが付きます。混ざっているときは、印もチェックも付きません。
    • 保存前でパスの無いファイルには付けられません。対象が無いときは カラー は無効です。
  • 上段の Group で カラー を選ぶと、手動は #A92D2D のような色名、ルールは一致した文字列、どちらも無いときは (なし) でまとまります。
  • プレイリストのファイル名列は、表示中の名前にマーカーの幅を足して決めます。
  • 手動の色はフルパスで設定に覚え、次回起動でも残ります。アプリで移動、名前変更したときは、新しいパスへ付け替えます。コピー、複製、別名保存、書き出しは、元に手動色があるときだけ先へ同じ色を写し、元は残します。元に手動色が無いときは、先に付いていた手動色を残します。
  • エクスプローラーなど、アプリの外で移動・改名したファイルの手動色は、移動前のパスに残ったままです。アプリがその古いパスを操作対象にしたとき、実体が無ければ消します。
  • アプリが触っていないパスの記録は、ファイルが無くても、ドライブが外れていても残します。存在を調べに行きません。アプリがそのパスを移動、コピー、削除、名前変更などの対象にしたとき、その時点でファイルもフォルダも無ければ、孤立した記録としてその場で消します。

フォルダ名ジャンプ（インクリメンタルサーチ）

エクスプローラーなどでも使われる「打ちながら探す」操作です。Ctrl+F の検索欄とは違い、ツリーの選択だけを動かします（プレイリストには載せません）。

  1. Ctrl+← などでフォルダツリーにフォーカスを置きます。

  2. 英字キーを打つと、表示名にその文字を含むフォルダへジャンプします（先頭でも途中でも可。大小・半角全角は区別しません）。

    • 例: N で namco や NINTENDO、MAY で名前の途中に May があるフォルダ。
    • 続けて打つと文字が積み上がり、条件が狭まります（D を連打すると dddd のように積まれます）。
    • ツリー中央に打った文字のトーストが出ます。入力が止まって約 1 秒でトーストは消え、打ち込み文字も忘れます。
    • ヒットした文字には黄背景が付きます。トーストが消えたあとも黄背景は残り、↑↓ でヒット同士を渡り歩けます。

  3. Esc、および Space／←／→ でも打ち込み文字と黄ハイライトを消します（Space／矢印はその後のツリー操作も行います）。プレイリストへの登録／再生開始や、ツリー以外へのフォーカスでも終わります。

ツリーにフォーカスがあるとき、N／P／R／J／K／M／I／O は前後曲・再生・一時マーカー／A-B ではなく、このフォルダ名ジャンプに使います（テンキーの再生操作はそのまま）。ランダム再生は Alt+R、次の曲の自動再生は Alt+N、Auto Play は Alt+P です。

波形

  • シークと選択だけです。ドキュメントのマーカー／リージョン／ループは出しません。
  • 音声のプレイリスト波形と動画本再生／F8 では I／O の捨て A-B と M／Ins の一時マーカーを使えます（別ファイル再生で忘れる。音声はエディタへ戻すとき既存マーカーとマージし、揃った A-B はサンプルループにして未保存のまま持ち越す。動画／PDF は持ち込まないので捨てる）。
  • 動画／PDF の暗いプレビューでは使いません。範囲は反転して半透明です。拡大しません。
  • 画面用の波形だけ作り、短いファイルは粗くしません。スペクトラムやラウドネスの曲線表示には切り替えません。波形上の右クリックでは、シーク・選択・再生まわりが中心です（ドキュメントへの破壊編集はプレイリスト側のメニューから行います。下記）。
  • 右クリック／メニューキー／Shift+F10 でメニューを開けます。表示の中は、ズーム・解析・画面（F8〜F12 と常に最前面）のあと、再生ヘッド、ソロ、映像（全画面 F、ミニ窓、オーバーレイ A、タイムコード T、PDF の固定 W、プレビューへ戻る Q、プロキシ Ctrl+Shift+P）です。タイムラインはマーカー／リージョン／ループです。再生は再生操作と、プレイリスト・端への移動に分かれ、Silent Skip もここにあります。ファイルの時間はタブ、設定と色設定はその他です。クリックした位置の再生・移動・マーカー・区間・時間のコピーは「この位置」です。再生に追加時の自動再生（Alt+P）・前の曲（P）・次の曲（N）・頭から再生（R）があります。元に戻すは捨てマーカーです。プレイリストの右クリックにも前後の曲・頭出し・Auto Play があります。

プレイリストの破壊編集

プレイヤーは再生が主です。それでもプレイリストの右クリックから、選択中の複数ファイルへノーマライズ／フェード／ピッチ／タイムストレッチ／リバース／サンプルレート・ビット深度・チャンネル変換／無音の挿入／無音・ヒット検出／ラウドネス揃えなどの破壊編集や書き出しができます（ファイル全体が対象。適用後はディスクへ保存し、アンドゥはできません）。

誤操作で破壊編集が走ると戻せないため、ショートカット・キーでは実行しません。メニューにジェスチャー表記があっても、プレイヤー中のキーでは効きません。必ず右クリック（またはメニューキー／Shift+F10）から選んでください。N／P／R は前後曲・頭出しのままです。

ジャケットと背景

  • ジャケット／サムネイルは実画像があるときだけ出します（動画・PDF のサムネ含む）。無い行は空白で、プレースホルダ画像は出しません。プレイリストに1枚も無ければ枠ごと隠します。
  • ジャケット枠へ画像ドロップで差し替えできるのは MP3 のみ（ファイルへ書き込み）。WAVE / AIFF / M4A は差し替えできません。
  • ジャケットがあるときはウィンドウ全体の背景に、縦横比を崩してエリアいっぱいに置いてから大きくぼかして使います（トランスポート・メーター・ステータスバーも含む）。

入り方と抜け方

  • 起動時に指定したファイルに mp3／m4a が 1 つでも混ざるとプレイヤーで起動し、それらのファイルをリストへ載せます。このモードでは、たくさん開くときの半透明の画面は出ません。
  • WAAPI は無効です。入る前にオンなら、抜けたときに戻します。他モードのファイルはリストへ引き継ぎます。
  • 抜けるときは再生を止めてから、選択したファイルだけをエディタのタブに残し、タブの複数選択を解除します。プレイリストは消しません。エディタからプレイヤーへ戻るときは、抜ける前の曲を戻し、エディタで開いているファイルも残します（エディタで閉じたタブは戻しません。新しく開いたファイルは末尾に足します）。未保存の編集があるときは、移る前に保存するか、破棄するか、キャンセルするかを聞きます（破棄はディスクの内容へ戻し、保存先の無いタブは残しません。キャンセルするとエディタのままです）。動画／PDF の本再生中やフレーム一時停止中に F10 を押すと、エディタへは落とさず、暗いバックグラウンド再生へ戻して前面 UI（プレイリスト）を出します（プレイヤーのまま）。プレイヤーのまま終了したときは、読み込んだファイルは覚えません。

読み込み中の表示

  • 1 件の読み込みに時間がかかるときは、中央に Now Loading ... を出します。
  • 2 件以上は半透明の画面を乗せ、全体と各ファイルの進捗を出します。Esc で中断でき、読み込み済みは残します。

時間スクロールバー

波形の下

表示範囲を左右に動かします。

タブ

1 ファイルでも表示します。

  • 閉じるは Ctrl+W。アプリ終了は Ctrl+Q。
  • 誤って閉じたタブは Ctrl+Shift+T で開き直せます（今の起動で閉じたもの。複数可）。
  • Ctrl+Shift+W でもすべてのタブを閉じられます。複数タブを閉じるとき、未保存が 2 件以上なら「すべて保存して閉じる」「すべて保存せずに閉じる」も選べます。

右クリック

  • 「このタブを閉じる(S)」「このタブ以外を閉じる(O)」「このタブを含め右側を全部閉じる(R)」「このタブを含め左側を全部閉じる(L)」「すべてのタブを閉じる(W)」
  • 「ファイル名を変更(N)」（F2、またはタブ／タイルの帯のファイル名ダブルクリックでも）
  • 「ファイルを複製(U)」（Ctrl+Shift+D）、「ファイルを削除(D)」
  • 「全部のタブを選択する(A)」「閉じたタブを再開(T)」
  • 「すべてのファイルの時間を表示(I)」（表ウィンドウ。コピー／セル範囲コピー／CSV・PDF。複数タブ選択中は「選択ファイルの時間を表示(I)」になり、選択したファイルだけ）
  • 「タブのまま(B)」「左右に並べる(1)」「上下に並べる(2)」「上下左右に並べる(3)」（タイル表示。2 タブ以上。波形エリアに収まらない配置は選べません。チェックが今の配置）
  • 「Wave で書き出す(E)」「MP3 で書き出す(M)」「マーカーでセパレートして書き出す(K)」「リージョンでセパレートして書き出す(G)」「チャンネルごとに書き出す(C)」

波形の右クリックには「タブ」カテゴリがあり、閉じる系／バウンス／全選択／再開／時間／タイル配置はタブメニューと同じ文言・同じアクセスキーです（対象はアクティブなタブ）。これに加えて「すべてのタブを Wave / MP3 で保存」（常に全タブ向け。タブ右クリックで全選択したときの「選択ファイルを〜で保存」とは別）と「次のタブ(N)／前のタブ(V)」があります。リネーム・複製・削除は波形 → ファイル、書き出し・セパレートは波形 → 書き出しにあります。

バウンス

2 つ以上のタブを選択すると「選択ファイルをバウンス(J)」で、波形を重ねて合成した新しい Wave を作り、選択の右隣のタブで開きます。Ctrl+Shift+B でも同じです。

  • 長さはいちばん長いタブ。サンプルレート、チャンネル数、ビット深度は左端の選択タブと同じものだけバウンスする。違うファイルがあると変換せず中止し、一致しないファイルを示す。
  • マーカーとリージョンは位置そのままで引き継ぎ、同じ位置で同じコメントのマーカーは 1 つにまとめます。
  • 先に保存ダイアログで保存先と名前を指定します。既定名は Bounce.wav。初期フォルダは前回バウンスした場所です。まだ無ければ、ファイルを持つ最初の選択タブ、それも無ければ前回の書き出し先です。選んだ場所は次回以降も使います。

16bit のバウンスは推奨しません。24bit 以上を推奨します。16bit でもバウンス自体はできます。

バウンス経路にはディザがありません。16bit で書くと、フェードやリバーブの余韻は単純な丸めになります。

書き出す前に、加算した float32 のサンプルを走査し、±1 を超えるものがないか調べます。超えていれば、どれだけ超えているか（例: 1 dB）を示す警告を出します。選べるのは二つです。バウンスを中止する。検出した超過分だけミックス全体を下げてからバウンスする。

書き出し

  • 今の編集内容を別ファイルへ出します（未保存のままで可）。1 件は保存ダイアログ、複数はフォルダを選びます。
  • 既存ファイルは上書き確認です。はい＝上書き、いいえ＝それらをスキップ、キャンセル＝中止。多いときは件数と先頭だけ出します。
  • セパレートはフォルダを選びます。マーカーは区間が 2 つ以上、リージョンは 1 本以上あるタブだけ出します（足りないタブは飛ばす）。名前は元名に _1（10 個以上なら _01 のように桁を合わせる）。
  • チャンネルごとは、今のスピーカー配置と Ch 割り当てで Wave を出します（ファイルのチャンネル順や名前は見ない。割り当てが無いスピーカーは出さない）。名前は元名に _L / _C / _LFE など配置のラベルを付け、フォルダを選びます。
  • 複数書き出しの名前は元ファイル名（未保存はタブ名）で、同じ名前が重なれば 2 から番号を付けます。前回の書き出しフォルダを覚えます（開くとは別）。
  • 実行中は半透明の画面で操作を止め、全体と並列中の曲すべてのプログレスバーを出します（多いときは列を増やす）。
  • Ctrl+Shift+Alt+M で全タブを MP3 で保存します（波形右クリック → タブ。今のタブは開いたまま。Wave の一括保存にキーはありません）。

複数選択

  • Ctrl+クリックで個別追加、Shift+クリックで範囲選択。タブバーまたはタイルのファイル名の帯の上の Ctrl+A で全選択できます。選択中のタブとタイルの帯はハイライトされ、Esc で解除します。
  • Ctrl+Shift+A は、ポインタの位置やタイル表示かどうかに関係なく全タブを選択します。タイル表示の検索フィルター中は、検索でヒットしたタブだけを選択します。タイル表示でも帯で同じ複数選択ができます。
  • 選択中の右クリックは、以外／右／左を残したまま次の名前になります。「選択した（すべての）タブを閉じる」「選択ファイルをバウンス」「選択ファイルを複製」「選択ファイルを削除」「選択した（すべての）タブにペーストする」「選択したタブを Wave / MP3 で書き出す」「選択したタブをマーカー／リージョンでセパレートして書き出す」「選択したタブをチャンネルごとに書き出す」。全タブ選択時はいずれも「選択ファイルを〜」表記で、Wave / MP3 は「選択ファイルを〜で保存」です。
  • Ctrl+V で、コピーした編集履歴を選択タブへ一括適用できます。適用中は半透明の画面で操作を止め、全体と各タブの進捗を出します。

幅が足りないとき

タブが増えてバーに収まらないときは、先にアクティブ以外を縮めます。タイトルが 6 文字を切るまで縮めても足りなければ、左右の ＜＞ で送ります。

タイル表示

複数のタブを 1 画面に並べて聴き比べられます。

並べ方

  • Ctrl+T で左右→上下→上下左右→解除の順に巡回します。ファイル数によって見た目が同じになる配置、波形エリアに収まらない配置は飛ばします。左右・上下が収まらなければ格子を試し、格子も無理なら動きません。
  • 波形の右クリック → タブ、またはタブの右クリックの「タブのまま(B)／左右に並べる(1)／上下に並べる(2)／上下左右に並べる(3)」で直接指定もできます。2 タブ以上。収まらない配置は選べません。チェックが今の配置です。
  • 並べるときは、いま表示しているタブの解析モード（波形／スペクトログラム／重ね／ラウドネス）に全タブを揃えます。
  • 再生中に配置を切り替えても音は止まりません。タイル中に閉じたタブは並びから外れ、1 つになると通常表示へ戻ります。
  • ウィンドウを狭くして今の左右・上下が収まらなくなると格子を試し、格子も無理ならタブ表示へ戻します。
  • 設定の一般タブ「複数ファイル」で、2 つ以上のファイルを開いたあとに自動で並べる既定配置を選べます（既定はタブのまま。左右・上下が収まらなければ格子を試し、格子も無理なら並べません）。
  • 終了時の配置は覚え、複数タブが復元されたときに次回起動でも戻します（収まらなければ格子、格子も無理なら戻しません）。

選択

  • タイルをクリックまたは再生するとアクティブが替わり、ファイル名の帯が青くなり、シアンの再生ヘッドもアクティブだけ出ます（非アクティブの帯は塗りなし）。
  • 帯の Ctrl＋クリック／Shift＋クリックはタブと同じ複数選択。Ctrl+A を帯の上で押すと全タブ選択。選んだ帯もアクティブと同じハイライトです。
  • ファイル名の帯を右クリックすると、タブと同じメニューが出ます。

検索

Ctrl+F でタブ名の検索（絞り込み）ができます。波形エリア中央に検索ボックスが出て（「全部含む／どれか含む」の書き方もボックス内に表示）、1 文字入れるたびにすぐ絞り込みます。ヒットしないタイルは暗くなり、半透明の画面で覆われます。

  • 空白区切りは AND、| 区切りは OR です（例: bgm loop|se ＝ bgm と loop の両方を含む、または se を含む。大文字小文字は区別しません）。
  • Enter で条件を確定して検索ボックスを閉じます。フィルターは残ります。もう一度 Ctrl+F を押すと、同じ条件から編集できます。
  • Esc は、開いた時点の文字列に戻して閉じるキャンセルです。解除するには検索文字を空欄にします。
  • Alt+Enter でヒット以外を閉じます。未保存の編集があるタブは残し、確認は出さず、フィルターは解除します。
  • Ctrl+Shift+F は、検索ワードが入っているときだけ、ボックスを出さずに検索ワードを空にして確定します（フィルターの即解除）。
  • 覆われたタイルは操作できません。クリックしてもアクティブにならず、Ctrl+Tab／Ctrl+PageUp・PageDown の切り替えでも飛ばされます。
  • 文字を変えて絞り込むと、ヒットした先頭（タブの並び順。タイルの左上から）の波形をアクティブにします。すでにそのファイルならそのままです。ヒットが無いときはアクティブを変えません。検索文字を空にして解除したときも、アクティブは移しません。
  • 検索の確定でタブが選択されることはありません。検索文字を変えたり確定したりすると、残っていたタブの複数選択は解除されます。選択はフィルター中の Ctrl+Shift+A で明示的に行い、検索でヒットしたタブだけを全選択します。
  • 絞り込み中にバウンスや複製で増えた新しいタブがヒットしない名前の場合は、手前に出さず、暗いまま加わります。タイル表示をやめると検索もリセットされます。

Silent Skip

ステータスバーの SPEAKER の左、Alt+S。既定オフ。

  • 再生中に無音区間を飛ばし、録音中はしきい値を超えたときだけ書き込みます。
  • 書き込んだ可聴の前後には、プチノイズだけを消す短いフェードをかけます（設定の編集タブ。既定 20 ms）。
  • 再生中の ←／→ 早送り／巻き戻し中は飛ばしません。
  • しきい値を下回った時点から無音を書き、設定の長さで止めます。音が戻ったときにまとめて挟みません。録音専用です。既定 500 ms。再生には使いません。
  • 録音開始時は毎回、Silent Skip をオンにするか確認します。チェックの初期値はステータスバー。OK するとステータスバーにも反映し、キャンセルは変えません。確認文にしきい値と無音の尺が出ます。設定から変更できます。
  • オンのときだけ「録音部分にリージョンを付加」を選べます（オフでは選べない）。付けると、無音を pad まで挟んだときの前後の録音へ付けます。無音には付けません。波形の短い谷では分けず、続きの録音は新しい区間だけです。既定オフ。状態は覚えます。リージョン付加は録音開始時に指定します。
  • しきい値とスキップ時の無音挿入時間は設定の編集タブです（しきい値の既定 -60 dB）。無音・ヒット検出（波形の右クリック → 編集 → 無音・ヒット検出／Ctrl+D）のしきい値・カット時フェードとは共有しません。

ギャップレス再生

設定 → プレイヤーの先頭。最初はオン。

もともと途切れない曲を、ファイルをまたいでつながったまま聴きたいときの設定です。ライブやクラシックを曲ごとに MP3／M4A にすると、頭と尻にごく短い無音が付いて、途切れ途切れに聞こえることがあります。オンのときは、その無音を外して次の曲へつなぎます。静かなところを全部飛ばす機能ではありません（それは Silent Skip です）。

  • 無音の長さが分からないファイル（古い作り方や、Windows で作った MP3 など）はそのまま再生します。
  • 情報と実際が違うと、曲の頭や尻が数十ミリ秒だけ欠けることがあります。すでに無音が外れているときは、もう一度切りません。
  • 取り込みのときに曲のあいだへ入れた長い無音（2 秒など）は、この設定では消えません。
  • オンでも、ほんの少し隙間が残ることがあります。CD とまったく同じつながりになるとは限りません。
  • オフにすると、頭と尻の無音も含めてそのまま再生します。波形の長さの表示はどちらでも変わりません。

Always on Top

Silent Skip の右、SPEAKER の左

ウィンドウを最前面に固定します。Alt+A で切り替えます。

スペクトラム／ラウドネス／レベルメーター／ベクタースコープ

再生出力の表示です。

ラウドネス

スペクトラムの左に出ます。Short Term / Integrated / Momentary Max、Loudness Range、True Peak。ターゲット LKFS は設定です。青＝ターゲットまで、橙＝そこから +3 LU、赤＝それより上。

  • 再生中は出力のリアルタイム計測で、数値が色づきます。
  • エディタで停止中は、波形全体のオフライン解析で5種類とも出ます。Short Term はファイル内の最大。色が数値の塗りになり、文字は通常色です。音量などの編集後は測り直します。
  • プレイヤーで停止中、選択が1ファイルのときはこの5種類を出しません。2ファイル以上を選んでいるときは、各ファイルの5種類の平均を出します（Short Term はそれぞれのファイル内の最大。単位に Avg）。
  • エディタでは、ラウドネスの左に編集履歴の一覧があります。収まる分だけ出し、古いものは切れます。クリックで U の編集履歴。ここからは選べません。プレイヤーではこの一覧は出しません。

スペクトラムとチャンネル色

  • スペクトラムは、すべてのチャンネルをまとめた帯域の表示です。
  • 波形のチャンネル名は、スピーカーに割り当てた Ch のレーンだけ配置の名前（L / C / LFE など）です。割り当てのないレーンは 1 からの番号。初期値は 1 から順です。
  • 3ch 以上では、名前は白文字で、角丸バッジの塗りがよくある登場順（Atmos 9.1.6 の 16 色）です。波形も同じ色で薄く染めます。レベルメーターのバーも同じ色です。

2ch 以下

シアングラデです。内側 2 本が Peak（上の赤ランプがクリップ）、外側 2 本が RMS（どちらもホールド線）。下の数値は Peak 行／RMS 行です。メーターにチャンネル名は出しません。

3ch 以上

  • ベクタースコープの代わりにサラウンドの絵になり、同じ割り当てで配置の位置を使います（ファイルから名前は当てません）。
  • エネルギーは波形と同じチャンネル色です。大きさはチャンネルのレベル、輪郭の凹凸はそのチャンネルの直近の波形です（先端が今、裾が少し前）。
  • 全体の広がりをひとつのダークグレーの細線で囲みます。枠はピークを少し持ってからゆっくり戻ります。
  • レベルメーターはチャンネルごとの Peak バーに、Peak ホールドと緩やかな RMS ホールドを載せます。

幅と表示の切り替え

  • 列の左端をドラッグすると幅を広げられます。既定が最小で、バーが最大の太さになるところで止まります。広げた幅は次の起動でも覚えます。
  • 停止後、表示はゆっくり消えます。レベルメーター上の WAAPI（Alt+W）でバーの表示を切り替えます。

WAAPI バー

接続状態、作成先、Play -E、Auto Active、EXPORT があります。

プロジェクト名をクリック、または Alt+Ctrl+Shift+W で Wwise を開く／前面に出します。WAAPI がオフでもバーを出してから起動します。覚えたプロジェクトが無ければバーの表示までとし、起動できない旨を出します。

ステータスバー

  • ファイル位置 …… 2 ファイル以上開いているときは、冒頭に 1 / 10 Files のように何番目／全数を表示します。
  • ファイル情報 …… サンプリングレートなど（名前はタブ側）。レート／ビット深度／チャンネルを変換すると、該当項目が保存まで赤になります。MP3／M4A はビットレートも表示します。容量は MB（MiB / B）。変換や範囲削除で変わると推測サイズが赤になります。
  • Silent Skip と Always on Top …… NOW POS の左。Silent Skip は Alt+S。Always on Top は Alt+A。無音を飛ばして再生し、録音ではしきい値超だけ書きます。しきい値は設定です。
  • SPEAKER …… その右でスピーカー配置を切り替えます。一覧は表示項目タブと同じです。今使っている定義は外しても、切り替えるまで残ります。自動スピーカー選択がオンなら、ファイルの本数に合う定義へ切り替えます。既定オフ。
  • 時間 …… 現在時間／選択開始／選択範囲／選択終了／トータル。トータル以外は入力・ホイール／↑↓で調整します。時間は 1 秒／Shift 10 秒／Ctrl 1 分／Ctrl+Shift 10 分、サンプルは 1／Shift 10／Ctrl 100／Ctrl+Shift 1000。右クリックで時間とサンプル数を切り替えます。

選んだタブの音を重ねて、新しい Wave を作ります。プラグインやエフェクトは通りません。速い代わりに、大きい音を重ねると割れやすいので、重ねる前に音量を下げるか、できたあとにピークを確認してください。長さが違うファイルは揃えてから重ねます。

4. 再生

  • Space …… 再生／停止。停止すると開始位置へ戻します。動画本再生中は開始位置へ戻して静止する（即再開しない）（プレイリストは出さない）し、暗いプレビューへは落としません（バックグラウンドの 1/3 速へ戻すのは Escape／Q。F8／引数起動ミニでは Escape／Q でプレイリストへ戻る（動画の In／Out がある Escape は解除して留まる）。途中で本再生へ戻すと今の位置から続けます）。プレイヤーモードでは選択曲だけ再生し、終わったら停止します（連続再生しません。同じ動画の暗いプレビューから戻すときは今の位置から。PDF の明るい表示モード中の抜けは Escape／Q）。トランスポートの再生も同じです。
  • Enter …… その場停止。停止中の動画／PDF では Space と同じく本再生／明るい表示へ。本再生中の動画はその場で止まり、プレイリストは出しません。
  • ←／→ …… 停止中はシーク（表示の約 1 px。点が見えるときは 1 サンプル）。再生中は押しっぱなしで、ピッチ据え置きの 3 倍早送り／巻き戻し（推移中は -4 dB）。離すと元の速さと音量。その間 Silent Skip は動きません。プレイヤーモードでは左右キーの早送り／巻き戻しはしません（,／.）。動画の本再生中またはフレーム一時停止中は、一時停止して 1 フレーム戻し／送ります（押しっぱなしは最初だけ待ってから繰り返します）。
  • Ctrl+Space …… 波形にフォーカスがあるときだけ 3 秒前から（プリロール）。プレイリストでは使わない。
  • Shift+Space …… プレイリストのチェックモードのオン／オフ（初期オフ。オン時だけ行頭にチェックボックス。ツリーには出さない。モード中の Space でチェック。右クリック等はチェック行が対象。オフ時は列を隠し、チェック済み行の選択は残す。再オンは空のチェックから）。ツリーにフォーカスがあるときは折りたたみのまま。
  • Alt+Enter …… 再生開始位置からやり直し（タイル検索ボックスにフォーカスがあるときはヒット以外を閉じる）。
  • Alt+S …… Silent Skip。無音区間を飛ばして再生し、録音中はしきい値を超えたときだけ書く（既定オフ。しきい値は設定、既定 -60 dB）。再生中の ←／→ 早送り／巻き戻し中は飛ばしません。録音開始時は毎回、Silent Skip をオンにするか確認します（チェックの初期値はステータスバー。OK すると反映。確認文にしきい値と無音の尺。設定から変更可）。オンのときだけリージョン付加を指定します（既定オフ。前回の指定を初期値にする）。
  • 次の曲を自動再生がオンのとき、プレイヤーの連続再生は次の曲を先に用意します。MP3／M4A の頭と尻のごく短い無音は ギャップレス再生（設定のプレイヤー。最初はオン）で減らします。オンでもわずかな隙間は残ることがあります。
  • Ctrl+ドラッグ …… つまんで聴く（スクラブ）。すべてのチャンネルを左右にまとめます（レベルメーターも左右だけ動きます）。
  • G …… ステータスバーの NOW POS を入力。Enter で移動。コピー／貼り付け可。右クリックで時間／サンプル数。
  • Z またはテンキーの .…… 中央寄せ。再生中はセンターロックの切替、停止で解除（キーボードの . は早送り）。
  • L …… 選択（無ければサンプルループ／-L）の末尾 3 秒前からループ再生。
  • J …… 5 秒戻し、K …… 5 秒送り（0.75 秒クロスフェード。押しっぱなしは少し待ってから繰り返す）
  • Ctrl++／Ctrl+- …… 再生中のピッチを半音上げる／下げる（キーボードとテンキー。キーボードの + は Shift 付きでも可）。Ctrl+0（キーボードとテンキー）で 0 に戻す。中央に半音のトーストを出す。エディタとプレイヤーで同じ。長さと再生位置はそのまま。範囲は ±2 オクターブ。別の曲を再生し始めると忘れる。
  • , …… 早戻し、. …… 早送り（±3 倍・ピッチ据え置き。推移中は -4 dB。停止中でも可。離すとその位置で停止のまま）
  • Q …… エディタではマーカークリック。マーカー／リージョン端の位置でクリックを鳴らす（選択があればその範囲、なければファイル全体）。ボタンまたは Q でオン／オフ（既定オフ。自動ではオンにならない）。波形の右クリック → 再生でも切り替え可。プレイヤーの動画本再生／フレーム一時停止／PDF 明るい表示では Escape と同じく暗いプレビューへ戻す（F8／引数起動ミニではプレイリストへ戻る（動画の In／Out がある Escape は解除して留まる）。マーカークリックはプレイヤーでは効かない）。
  • Tab …… チャンネルをソロ。他のレーンはグレーでミュート。繰り返すと次のチャンネルへ。Shift+Tab で逆順。最後の次で解除。左端のチャンネル名をクリックでもソロ（同じ名前をもう一度で解除。Ctrl＋クリックで追加。Shift＋クリックでミュート／解除）。波形の時間選択は変えない。波形操作はそのチャンネルだけ。再生中でも停止中でも可。
  • Ctrl+N …… 新規。空のタブを作る。フォーマットは都度選ぶ（前回を覚える）。チャンネルは表示項目で有効にしたスピーカーと Mono（常に選べる）。
  • Ctrl+R …… 録音。
    • 開始前に毎回、Silent Skip をオンにするか確認します。チェックの初期値はステータスバー。OK すると反映。確認文にしきい値と無音の尺。設定から変更可。オンのときだけリージョン付加を選べます。既定オフ。状態は覚えます。
    • 今開いているファイルのフォーマットで、シークバーの位置から録ります。それ以降の波形は上書きします（Undo で戻せる。take より後ろは残す。take が長ければ伸ばす）。
    • ファイルが無いときは始まりません（先に Ctrl+N または開く）。録音は Wave のままです。MP3 になるのは保存／書き出しのときです。
    • 未保存のまま終了しても作業コピーが残り、開いたままだったタブは再起動で戻ります。閉じてしまったタブは、今の起動のうちなら Ctrl+Shift+T で再開できます。
    • もう一度、または Space / Enter / Esc で停止します。録音中は波形の背景が赤系になり、新しい区間はすぐ粗い波形で出し、少し遅れて通常の描画に整えます。
    • Silent Skip をオンにすると、しきい値を超えたときだけ書き込み、下回った時点から無音を挟んで設定の長さ（既定 500 ms）で止めます。可聴の前後には設定の短いフェード（既定 20 ms）をかけます。リージョンを付けると、停止時に今回書いた可聴／無音それぞれへ付けます。
    • 録音ポート・再生ポート・Ch は、その配置の中で割り当てます（Ch は録音と再生で共通。なしはそのスピーカーを使いません）。
  • 左右 2 本の機器で再生ポートを決めていないときは、スピーカーの音を左右にまとめます。モノラルはポートが 2 つ以上あれば、左右へ同じ音を出します。

5. 選択と編集

ドラッグで選択。ダブルクリックは区間（マーカー間）、トリプルクリックは必ず全選択。Esc または Shift なし移動で解除。未選択のフェード／音量／ピッチ／ノーマライズ／リバース／タイムストレッチは時間方向は全体です。チャンネルソロ中は聞こえているレーンだけが対象です。ステータスバーの選択開始／範囲／終了に値を入れることでも選択できます。選択範囲への処理（フェード／ノーマライズ／削除など）のあと、再生位置は選択の先頭へ戻ります。

  • FADE IN I／FADE OUT O …… カーブを選び Space で試聴、Enter で実行。1–9 でカーブ。
  • X …… シークバー前後をフェード。シークを境に、今見えている前だけアウト／後ろだけイン（リニア）。
  • V …… 単一タブではラウドネス曲線を表示して音量。dB を直接入力、または ↑↓／ホイールで 0.1 dB（Shift 1／Ctrl 3／Ctrl+Shift 6）。Space で試聴、Enter で実行。メニューに波形全体の Integrated LKFS／RMS／Peak の変化を先に出します。Short Term 曲線と停止中メーターも同じ dB で追従します。Esc または Shift+V で曲線を閉じます。
  • ラウドネスを揃える（プレイヤーのプレイリスト右クリック、またはエディタでタブを複数選択して V）…… 選択中の Wave／AIFF を指定 LKFS（既定は設定のラウドネスターゲット）へファイル全体のゲインで揃える簡易調整です。曲線ベースの音量（単一ファイルの V）とは別です。プレイヤーでは揃え後に既存パスへ保存し、この編集は元に戻せません。V ショートカットはプレイヤーでは無効です。MP3 など非対応はスキップ／対象なしなら案内します。
  • P …… ピッチ。↑↓／ホイールで半音（Shift または Ctrl で 1 オクターブ）。Space で試聴、Enter で実行。±2 オクターブ。長さを保つのは既定オン（Tab でチェックへ）。オフは再生速度と同じく長さも変わります。実行中は半透明の画面で進捗を出します。
  • T …… タイムストレッチ（ピッチ据え置き）。選択があればその時間、無ければ全体。伸ばした時間と割合（％）が連動。↑↓／ホイール（時間は 1 秒／Shift 10 秒／Ctrl 1 分／Ctrl+Shift 10 分。割合は 0.1／Shift 1／Ctrl 10／Ctrl+Shift 25％）。Tab で時間と割合。Space で試聴、Enter で実行。10–1000％。実行中は半透明の画面。
  • NORMALIZE N …… ピークを -0.1 dB に合わせる。
  • R …… リバース。選択があればその範囲、無ければ全体の波形だけを時間方向に反転。マーカー／リージョン／ループは動かさない。
  • 波形の右クリック → オーディオ → リージョン毎に波形をノーマライズ …… 各リージョンのピークを -0.1 dB に合わせる。先頭と終端に、プチノイズだけを消す短いフェード（設定の編集タブ。既定 20 ms。0 交差）をかける。
  • DELETE …… 選択を詰めて削除。選択中のマーカー／リージョンもまとめて削除。
  • Shift+Delete …… 選択範囲を無音にする。長さは変わらず、マーカー／リージョン／ループも動かさない。実行前のダイアログは無音の挿入と同じ体裁で、選択範囲の秒数と「前後に既定のフェード」を出します（既定オン。設定のプチノイズ防止。範囲の直前は 0 へ、直後は 0 から。Enter で実行、Esc で取消）。右クリック → 編集 → 選択範囲を無音化。選択が無いと案内。すでに無音なら何もしない。チャンネルソロ中は聞こえているレーンだけ。
  • 波形の右クリック → 編集 → 無音を挿入（Ctrl+Ins）…… クリックした位置、またはキーのときは再生位置に、指定秒数の無音を足します（既存の音は後ろへずれ、マーカー／リージョン／ループも一緒にずれます）。秒数は直接入力、または ↑↓／ホイールで 0.1 秒（Shift 1 秒／Ctrl 10 秒／Ctrl+Shift 60 秒）。Enter で挿入。0.001〜600 秒。「前後に既定のフェード」は既定オンで、設定のプチノイズ防止フェード（既定 20 ms）を挿入点の直前は 0 へ、直後は 0 から掛けます。タブを複数選択しているときは、クリックしたファイルはその位置（キーのときは再生位置）、ほかの選択ファイルはそれぞれの再生位置へ同じ秒数を挿入します。
  • 波形の右クリック → 編集 → 無音・ヒット検出（Ctrl+D）…… 選択があればその範囲、なければファイル全体。ダイアログでオープン／クローズスレッショルド（リンク可。最初は -5 dB。以後は前回の値。Silent Skip とは独立）、次のゲートまでの最小時間、クローズまでの最小時間、プリ／ポストロール、カット時フェードイン／アウトを指定します。動作は「無音を削除」「音があるところへリージョン付加」「音があるところへマーカー付与」「ヒットポイントにマーカー」。リンクは Alt+L、動作は Alt+D／R／M／H、範囲は Alt+S／A。実行ボタンは OK。「リージョン付加」「マーカー付与」は無音ゲートで区切った可聴区間への自動付与です。「ヒットポイントにマーカー」は、しきい値を超えて手前の谷から持ち上がった打点へマーカーを打ちます（平坦な持続音には打ちません）。このとき有効なのはヒットのスレッショルドとヒット間隔の最小時間だけです（間隔の下限は 10 ms。解析範囲内の既存マーカーは置き換わります）。範囲は「冒頭＆末尾のみ」または「全体」（ヒットポイントでは範囲指定は無効）。波形の赤い ±しきい値線をドラッグ、または数値欄でホイール（0.1 dB、Shift で 1 dB。↑↓も同じ）。波形上のホイールは、カーソル位置を基準に時間方向へ拡縮します。波形エリアにフォーカスがあるときは、移動についてエディタ側と同じことができます。ウィンドウは縦横にサイズを変えられ、追従するのは波形エリアだけで、下の設定は動きません。無音削除時だけカット時フェードが有効（設定のプチノイズ防止フェードとは独立。既定 20 ms）。リージョン付加／マーカー付与／ヒットポイントではフェードは無効。「冒頭＆末尾のみ」では次のゲートまでの最小時間は無効（ヒットポイントではヒット間隔として有効）。タブを複数選択しているときはダイアログを出さず、現在の設定で選択ファイル全体へ一括適用するか確認だけします。ファイル全体が無音だけの削除はしません。MP3 などリージョン非対応ではリージョン付加は選べません。
  • Ctrl+X／C／V …… カット・コピー・ペースト（範囲内マーカー含む。選択がリージョンと一致すればリージョンも）。
  • U …… 編集履歴。↑↓ で移動、Enter 確定、Esc キャンセル。背景はサンプルレート変換の候補リストと同じ塗り。ラウドネス左の一覧をクリックしても開きます。
  • 履歴のコピー＆ペースト
    • 履歴内で Ctrl+クリック（Shift+クリックや Shift+↑↓ で範囲、Ctrl+A で全選択）して Ctrl+C。別ファイルで Ctrl+V すると同じ処理を再適用します（履歴を開いていなくても可）。
    • コピーは次に何かをコピーするまで残るので、タブを切り替えて Ctrl+V を繰り返せば複数ファイルへ反映できます。
    • タブを複数選んで一括適用するときや、ピッチなど重い処理のときは、半透明の画面で全体と各タブの進捗を出します。
    • 選択なしの Ctrl+C は現在位置までの全操作です。範囲は再生時間が同じ位置に合わせ、音量をそろえる操作は貼り付け先でやり直します。
    • コピーできないのは「初期状態」だけです（操作ではない。Ctrl+A でも色が付きません）。
  • 履歴を貼っても効かない／意図と違う例
    • 貼り付けは 1 件ずつ試し、適用先に合わないものはスキップします（「3 / 5 件適用しました」）。
    • スキップされる例: 同じ時刻にすでにマーカーがある追加、先方が短くて範囲がはみ出す削除／フェード、無音が無い先への無音削除、すでに同じレート／ビット／ch への変換、先方に無いマーカーへのコメント、MP3 へのリージョン／ループ。
    • ドラッグや ←→ でのマーカー／リージョン／ループ移動と、押しっぱなしの等分は、その時点の配置を丸ごと写します。移動だけをコピーして別テイクへ貼ると、先方のマーカーが置き換わります。追加から移動まで含めてコピーすると意図どおりになりやすいです。
    • 適用先が短いと時間は末尾に寄ります。チャンネルソロ中の編集は同じチャンネル番号だけに効きます。
    • 録音／波形ペーストの履歴は、そのとき入った音そのものを持ちます。波形を Ctrl+C したあとの Ctrl+V は履歴ではなく音声の貼り付けです。
  • 選択ファイルへの一括適用。タブを複数選択（Ctrl＋クリック／Shift＋クリック／Ctrl+Shift+A）していると、次は選択したファイル全部に実行します（それぞれのファイル全体。各ファイルのチャンネルソロを尊重）。
    • 対象: フェードイン／フェードアウト、ノーマライズ、リージョン毎のノーマライズ、音量（単一は曲線、複数選択時はラウドネス揃えの簡易調整）、ピッチ、タイムストレッチ、リバース、無音を挿入、無音・ヒット検出、サンプルレート／ビット深度／チャンネルの変換、保存（Ctrl+S）、名前を付けて保存（Ctrl+Shift+S）。無音・ヒット検出は確認だけ出し、保存済みの設定で一括適用します。無音の挿入はクリックしたファイルではその位置（Ctrl+Ins のときは再生位置）、ほかの選択ファイルでは再生位置です。
    • 右クリックメニューの名前も「選択ファイルをノーマライズ(N)」「選択ファイルを保存(S)／名前を付けて保存(A)」のように変わります。
    • 保存はパスがあるものを上書きし、未保存や AIFF は保存先フォルダへ Wave。名前を付けて保存は保存先フォルダを選び、Wave で書いてタブのパスを付け替えます（書き出しとは違い、保存後のファイルが今のタブになります）。
    • カーブや dB などの試聴はアクティブなファイルで行い、Enter で選択したファイル全部へ適用します。タイムストレッチは割合（％）に換算して各ファイルへかけます。
    • 適用できないファイル（リージョンが無い、無音が無い、すでに同じフォーマットなど）はスキップし、全部スキップならその旨を出します。
    • 実行中は半透明の画面で全体と各ファイルの進捗を出して操作を抑制します。タイル検索フィルターの半透明の画面は解除せず、その上に重なります。
    • 書き出しと履歴ペーストも同様です。波形右クリック → 書き出しの「Wave／MP3 で書き出す」「マーカー／リージョンでセパレート」「チャンネルごとに書き出す」は、タブ選択中「選択したタブを〜」となり、選択タブを一括で書き出します。
    • 編集 → 「編集データをペーストする」は「選択したタブにペーストする」（全選択なら「編集データを全てにペーストする」）として選択タブへ貼ります（Ctrl+V と同じ）。
    • 複製とファイルの削除も、選択中は「選択ファイルを複製(U)」（Ctrl+Shift+D も同じ）「選択ファイルを削除(D)」になり、選択したファイル全部に行います。確認は 1 回にまとめます。複製はそれぞれ元のタブの隣で開き、削除で消せなかったファイルは最後にまとめて表示します。
    • 波形右クリック → タブには「全部のタブを選択する(A)」もあります（Ctrl+Shift+A と同じ）。
    • シークバー前後をフェード（X）とカット／コピー／ペースト／削除は、アクティブなファイルだけです。
  • Ctrl+Z／Ctrl+Y（Ctrl+Shift+Z でもやり直し）…… 編集を元に戻す／やり直す。プレイヤーでは捨て A-B と一時マーカーだけです。

6. マーカー／リージョン／ループ

  • M／Ins …… 選択が無ければ再生位置にマーカー。同じフレームには打てない。選択中は開始と終了を置き、両端にマーカーがあればすぐ中央→3 等分→4…と打ち直す（押しっぱなしはマーカー移動と同じ間隔。離すまで 1 つの履歴）。
  • Shift+L …… 選択をサンプルループに（同じ範囲でもう一度で解除）。
  • Shift+R …… 選択をリージョンに。両端にリージョンがあればすぐ 2 等分。同じ範囲で続けて打つと 3…と打ち直す（解除は右クリック／Delete。押しっぱなしは同じ間隔で、離すまで 1 つの履歴）。
  • Ctrl+上段数字、または Ctrl＋テンキー数字 …… フラッグのリージョン番号の先頭へ（リージョンは 1 から。マーカー番号とは別。二桁可。プレイヤーでもファイルにリージョンがあれば同じ。無修飾のテンキーは再生のまま）。
  • フラッグをクリックで端を選択。Shift+クリックで範囲、Ctrl+クリックで追加。ドラッグまたは ←→ で移動（Shift で 3 倍）。
  • ダブルクリックでコメント／リージョン名。-A ライム、-L ブルー、-E 赤（書いたときだけ。ループやサンプルループの後ろは自動では赤くしません）。-R はグレー。EXPORT での意味は 9-3。
  • Ctrl+Shift+R …… リネーム。
  • 右クリック、または Ctrl+Del でマーカー削除。すべてのマーカーを削除と、すべてのリージョンを削除はタイムラインにあります。

Wave に保存すると、マーカー・リージョン・ループもファイルへ入ります。MP3 にはリージョンとループを付けられません。マーカーは置けますが、MP3 へ保存しても書きません。

7. スペクトログラム／ラウドネス解析

切り替え

  • A でスペクトログラム／重ね表示を切り替えます。
  • V でラウドネス解析（Short Term 曲線）を出して音量入力を開きます。
  • 抜けるのは Esc、Shift+A、または Shift+V です。今の表示にかかわらず通常の波形へ戻ります。Esc は入力、選択、ペンカーソルを先に解除します。音量の入力を閉じただけでは曲線は残ります。
  • VIEW のラウドネスボタンは表示だけ切り替えます。
  • L は選択（無ければサンプルループ／-L）の末尾 3 秒前からループ再生です。

ラウドネス曲線

  • Short Term LKFS の曲線です。白い幅は曲線の上下 ±1 LU（1 LU ＝ 1 LKFS の差）で、半透明です。
  • 波形は Mid 合成のピーク dBFS を線でつなぎ、LKFS と同じ縦軸に載せます（0 dBFS ＝ 目盛の 0）。拡大してサンプルが見えるときは、通常の波形と同じく各サンプルを線でつなぎます。
  • dBFS と LKFS は別物ですが、ピークとラウドネスを同じ高さで比べられます。
  • 背景の帯はメーターと同じ青／橙／赤です（ターゲットまでが青、そこから +3 LU が橙、それより上が赤）。曲線は原色のシアン／橙／赤で、赤だけ少し太くします。
  • 左目盛は LKFS です（通常の波形では dB）。白い線は設定のターゲットです。
  • 曲線の右上のペンボタン、E、または曲線上の右クリックでペンに切り替えます。もう一度で戻します。ペンのあいだ、曲線上のドラッグは範囲選択にならず、元の曲線は残ります。マウスを離すと、描いた線から読み取った意図を音量へ反映します。時刻を戻すと先に描いた部分は消え、同じ時刻に音量は一つだけです。一筆の両端は短いフェードで元の音量へ繋がります。0 dBFS を超えるときは、範囲全体を下げるか、その一筆を取り消して描き直すか選べます。取り消しは Ctrl+Z（描いている最中の一筆も、確定した一筆も）。音量の入力をキャンセルしたあとも曲線は残るので、その状態から描けます。マーカー・リージョン・ループ上の右クリックはメニューのままです。

ペンで描いた線は、その高さへラウドネスをぴったり合わせるためのものではありません。山や谷の一つ一つまで線の通りに動かすと、変化が強くなりすぎて、音楽として不自然に聞こえることがあります。ペンは、いまの鳴り方を読んだうえで、描いた線から「ここを上げたい」「ここを下げたい」という意図を汲み、音量へ反映します。

厳密に音量を合わせたいときは、範囲を選んで音量（V）で指定する方が向いています。その場合も、極端な dB を入れると、わずかなスムージングは入るものの、やはり不自然に聞こえることがあります。

重ね表示

  • スペクトログラムの上に波形の形だけを載せます（半透明のベールはかけません）。
  • -A／-L／-E とループ／リージョンの下塗りは重ねません。フラッグとラインはそのままです。スペクトログラム単体とラウドネス解析でも下塗りは出しません。
  • 重ね波形も Mid 合成の 1 本です。拡大してサンプルが見えるときは、通常の波形と同じく点と線でつなぎます。振幅ズームが 1 のときは中央半分、拡大すると縦いっぱいに伸びます。
  • 色は、いちばん大きいところを基準に見やすく塗ります（音そのものは変えません）。

描き方

  • 暗いところは、明るい部分を潰さない範囲で少し持ち上げて見やすくします。スペクトログラム／重ねでは、左端のバーか Alt+↑／↓ で持ち上げ量を変えられます（押しっぱなしで連続）。
  • 低い音ほど縦に詰めます（100 Hz 以下はほぼ見えません）。上限は 24 kHz です。
  • ファイル全体が画面に収まっているときは、くっきり描きます。
  • 拡大しているときはなめらかに描き、スクロールやズームが重くならないようにします。

8. フォーマット変換

  • S …… サンプリングレート
  • B …… ビット深度
  • C …… ファイルのチャンネル数（Mono／Stereo。スピーカー配置の切替ではない）

プリセットと操作

  • プリセットは 8 / 11.025 / 16 / 22.05 / 32 / 44.1 / 48 / 96 kHz、ビットは 4 / 8 / 16 / 24、チャンネルは Mono / Stereo です。
  • 任意 Hz は 1000–384000 で、↑↓／ホイールで 1Hz（Shift 10／Ctrl 100／Ctrl+Shift 1000）。
  • メニューはカーソルの直下を避けます。項目を選んだ時点で、ステータスの容量が推測サイズに更新されます。
  • 変換中は半透明の画面で操作を止めます。確定した項目は保存まで赤のままです。

元の音から作り直す

  • サンプリングレートとビット深度は、最初に読んだ音（またはフェードなどの編集後の音）から毎回作り直します。48 kHz → 24 kHz のあと 11 kHz にしても、24 kHz 経由ではなく 48 kHz から作り直します。
  • Space で試聴できるのはレートとビットです（チャンネルは Enter のみ。1–2）。
  • 4 bit は聴き比べ用です。Wave に書くビットは 8 / 16 / 24、および元が 32 bit のときはそのままで書けます。4 bit のままでは出さず 16 bit で書きます。変換メニューに 32 はありません。

9. WAAPI EXPORT（Wave 単体）

1 本の Wave の上で、ワンショットとループの区切りを決めて Wwise へ渡します。 あらかじめファイルを分けなくても構いません。EXPORT は元の波形を 1 ファイルのまま Originals へ書き、区間はクリップのトリムで合わせます。Interactive Music のプレイリストを 1 つ作ります。-A / -L / -E は区間と入り口／出口の目印に使い、マーカーは Custom Cue にしません。小節やテンポの管理、複数波形の切り替え、XML のマーカートラックはありません。

フェードや削除などの編集は、渡す前に波形へ確定します。マーカーとサンプルループは、保存するときに Wave へ埋め込みます。

9-1. 手順

  1. Wwise Authoring を起動します。
  2. レベルメーター上の WAAPI をオンにします（Alt+W）。
  3. Wwise で作成先オブジェクトを選びます。Keep Target でパスを固定できます。
  4. 書き出し先は接続中プロジェクトの Originals 配下である必要があります。
  5. EXPORT または Ctrl+Shift+E。WAAPI 接続中だけ有効です。
  • Play -E（Alt+E。WAAPI オン時）…… 出口のあとも鳴らします。アプリ内ではループの折り返しでその部分を二重に再生し、再生位置が 2 本になります。EXPORT すると、つなぎのときも出口のあとを鳴らします。
  • Auto Active …… EXPORT 後に Wwise を前面へ出します。
  • プロジェクト名 …… クリック、または Alt+Ctrl+Shift+W で Wwise を開く／前面に出します。WAAPI がオフでもバーを出してから起動します。覚えたプロジェクトが無ければ起動せず、その旨を出します。

9-2. リージョンの組み立て

上にあるものほど優先します。

  1. サンプルループ（Wave に付いているループ、または Shift+L）…… ループ前が Intro、ループが -L。後ろに余りがあれば EXPORT では -E（波形は赤くしない）。マーカーより優先します。
  2. 末尾が -A／-L／-E のマーカー…… その位置から次の同じ種類のマーカー（無ければ終端）までが区間になります。名前のないマーカーや、末尾が付いていない名前付きマーカーは区間を切りません。EXPORT では -L の直後で末尾が無いマーカーを -E として扱います（波形上の文字は変えず、赤にもしません。-A／-L／-E／-R は上書きしません）。
  3. 末尾の無いマーカーがちょうど 2 点…… その間をループとして扱います。
  4. リージョン（Shift+R）…… 特殊マーカーもサンプルループも無いとき、名前付き区間をそのまま通します。
  5. どれも無ければ、ファイル全体を 1 区間として渡します。

9-3. 名前の末尾

末尾意味
-Lループ。プレビューでループし、Wwise では無限ループの Music Segment になります。
-EExit Cue 以降（余韻）。直前の -L と同じ Music Segment に束ね、遷移時に次と重なって鳴らせます。
-AEntry Cue 前（アウフタクト）。次の区間と同じ Music Segment に束ねます。
-R別の取り込みツール向けの印です。このアプリでは使いません。

マーカーは Wwise の Custom Cue にはしません。-A / -L / -E は区間と入り口／出口にだけ使います。

9-4. Wwise に作られるもの

  • 音楽プレイリストを 1 つ（名前はファイル名）。中は順番再生で、各区間が 1 項目です。
  • 音楽セグメント。1 区間ならファイル名のまま、複数なら _a／_b…。ループ区間は無限ループです。-A と -E は隣の区間と同じセグメントに入り、入り口／出口だけがずれます。マーカーは Custom Cue にしません。
  • 元の波形は分割せず 1 本の WAV。各クリップは同じファイルを指し、始まりと終わりのトリムで区間を合わせます。
  • 先頭の区間は遅延を小さくし、先読みは設定の Wwise タブ（最初は 500 ms）。2 本目以降も同じタブの値です。ストリーム再生はいつもオンです。
  • テンポ 120、4/4 を上書きします（小節管理はしません）。
  • Play -E オンのとき、プレイリストの既定ルールで出口のあとも鳴らします。

同名の Container があれば中身を置き換えます。Originals に同名 WAV があれば確認なしで上書きします。最終確認は必ず Wwise 上で行ってください。

11. 設定と言語

設定は左上の歯車、または Ctrl+Shift+O です。タブは一般／表示項目／オーディオ／プレイヤー／編集／書き出し・パス／Wwise。各項目の内容は 画面の見方 → 設定 にあります。Esc で閉じます。

  • 表示言語は一般タブです。最初は Auto（パソコンが日本語なら Japanese、それ以外は English）。日本語の画面でも、ボタン名などに英語が残ることがあります。
  • 壁紙も一般タブです。最初は無し。動的背景の上に、比率を保ったまま画面全体を覆うように重ねます。くわしくは 画面の見方 → 設定 です。
  • マニュアルは画面の ?、またはブラウザで開きます。表示言語に合わせて日本語／英語になります。
  • 設定や、開いていたタブは、このパソコンのユーザー用フォルダ（%LocalAppData%\MGA\MGA Sonic Anvil\）に残ります。アプリの横には書きません。
  • MP3 は、設定で LAME の場所が正しければそれを使い、空欄や無効なら Windows で書き出します（128〜320 kbps。最初は 192）。今聴いている左右 2 本にまとめた音になります（くわしく）。書き出した MP3 は今のタブへは開きません。LAME はこのアプリには入っていません。
  • アプリを閉じると、開いていたタブとウィンドウの位置を覚えます。プレイヤーとふつうの画面は別々です。保存していない編集も残し、次に起動したときに戻します。プレイヤーのまま終了したときは、リストの曲は覚えません。
  • 同時に起動できるのは 1 つです。2 回目は今のウィンドウを前面にし、渡したファイルを開きます（mp3／m4a が混ざるとプレイヤー）。
  • 起動時に、新しい版があれば知らせます。はい＝案内ページを開く（自動ではダウンロードしません）。いいえ＝その版では再通知しません。ネットが無いときはそのまま続けます。

11-1. 自動スピーカー選択

設定のオーディオタブ、既定 Wave フォーマットの下です。最初はオフです。オンにすると、今のファイルのチャンネル数に合わせて、有効にした配置へ切り替えます。ファイルを開く、タブを前面にする、新規、チャンネル数の変換のときに動きます。ファイルの種類名から 5.1 などを当てるのではなく、本数だけを見ます。

  • 便利なとき …… 1〜2 本は Stereo。6 本なら有効な配置のうち 5.1 を選びます。同じ本数が 1 つだけ有効ならそれを使います。Stereo だけ有効なら、6 本のファイルでも何も変わりません。
  • 注意 …… 今の配置がすでに同じ本数なら維持します。切替は再生と録音を止め、その配置の機器に載せ替えます。Stereo をヘッドホン、5.1 を別の機器にしていると、タブを変えるたびに出力先が飛びます。6 本を Stereo のまままとめて聴きたいときはオフにしてください。

11-2. MP3 のダウンミックス

MP3 に保存／書き出すとき、今聴いている配置の音を左右 2 本にまとめます。ファイルのチャンネル番号の順ではありません。Wave 書き出しはチャンネル数を変えません。確認は出しません。

スピーカー順行き先混ぜ方
1 本目Lそのまま
2 本目Rそのまま
3 本目L と R少し小さめ（センター扱い）
4 本目L と R少し小さめ（LFE も足す）
5〜8 本目奇数は L、偶数は R少し小さめ
9 本目以降奇数は L、偶数は Rさらに小さめ

5.1（L / R / C / LFE / Ls / Rs）と同じ並びです。Atmos の上のスピーカーや、特殊な並びのファイルは、意図しないバランスになることがあります。

12. 対応範囲と位置づけ

  • Wwise の Interactive Music でできることをすべてカバーするものではありません。EXPORT は 1 本の Wave（マーカー／サンプルループ）に限っています。
  • アプリ内のプレビューは目安です。最終確認は EXPORT のあと、Wwise 上で行ってください。
  • AIFF では書き出せません。Wave または MP3 を選んでください。Wave に書くビットは 8 / 16 / 24、および元が 32 bit のときはそのままです（4 bit は試聴用で、保存時は 16 bit）。
  • チャンネルが多い MP3 は、今聴いている左右 2 本にまとめた音です。
  • EXPORT は Wwise のプロジェクトを変更します。実行前にバックアップをおすすめします。
